## D2338. 【選べる操作】には、場面に出ていない引数の候補だけを、できる・できないを分けずに並べる

**何を**: 【現在選べる対象引数】を【選べる操作】に改める。並べるのは、ツールの定義だけでは分からず、【現在地と周囲】にも出ていない引数の候補 (対象ごとの操作・区画の出入り・投票) だけにする。できる・できないとその理由は書かない (#2338、ユーザーが決めた)。D2268-14 と D2271-4 を改める。

ハルの tick 0 (スタブの run の prompt_dataset から):
```
【選べる操作】
"カンテラ": "油を足して灯す"
"ミオ": "殴りかかる", "荷から何かを抜き取る", "倒れている相手の持ち物を奪う" (details.item に奪う品の名前を書く)
※ 行き先・人・品物・物は、【現在地と周囲】の "" の中の文字をそのまま引数に書く。
```

| | 新しい形 | 前の形 (D2271-4) と理由 |
|---|---|---|
| 並べる引数 | 世界が `ArgumentOutline.listed` を付けた引数 (interact.how・set_sub_location.move・vote.decision・vote.choice) | 前は候補のある引数をすべて並べていた。行き先・人・品物・物は【現在地と周囲】に "" つきで出ているので、並べると同じ名前が引数の数だけ繰り返された |
| 操作の行 | `"対象": "操作", "操作"` を対象ごとに 1 行 | 前は `- interact.how ("対象"):` の段の形 |
| いまできない候補 | いまできる候補のあとに、理由を付けずに並べる | 前は「いまできない:」に理由つき。やる前から断られる理由が分かってしまう。選べば、世界がそのとき理由を付けて断る |
| 操作が求める値 | 操作のあとに `(details.code に金庫の番号を書く)`。品物の引数も候補を並べず `(details.item に奪う品の名前を書く)` | details のキーの名前は表にしか出ないので、操作の行の中に残す。何を書くかの言葉はシナリオの宣言 (`{ text: … }` / `{ item: … }`) から作る |
| 区画の出入り | `"昇降機の籠": "籠に乗り込む" (set_sub_location)` | 頭に区画の名前を置き、どのツールの引数かを後ろに添える (ユーザーが決めた) |
| 投票 | `vote "誰を残すか": "ミオ", "ゲン"` | 決めごとと選び先を 1 行にまとめる |
| 話し方 (speak.reach) | ツールの定義の `enum` | どのターンも同じ 3 つなので、プレフィックスキャッシュは切れない |
| 行動ごといまできないもの (探す・待つ) | 出さない | 前は `- explore: いまできない（手が離せない…）`。今していることは身体の状態の「いましていること」の行で伝える (別の PR を先にマージする) |
| 並べるものが無いターン | 「なし」の 1 行と注記 | 注記が、並べない引数の書き方を伝えるため |
| 同じ見た目の人 | 【現在地と周囲】も【選べる操作】と同じ「 #1」「 #2」で呼ぶ | 前は番号が候補表にだけ付いていた。人を表に並べなくなったので、場面から書き写した名前を同じ人に戻せるよう、場面と表で同じ呼び分けを使う |

### 決めたこと

- **どの引数を並べるかは世界が決める**。Being は引数の意味 (destination が場所であること) を知らない。世界は、場面に "" つきで出していない引数に `listed` を付ける
- **注記の文は世界が渡す** (`ActionChoices.note`)。【現在地と周囲】の見出しは世界の言葉なので、Being は書かない。シナリオの共通の部品 `choice_descriptions.listing_note` に置く
- **候補の木 (`values`・`unavailable`) は今までどおり全部渡す**。並べない引数の名前合わせ (表記の崩れを直す・選び直す) と、いまできない名前を選び直さずに渡す扱い (D2271-4) が、候補の木を使うため
- いまできない操作が求める値は、`UnavailableAction.asks` で渡す。いまできない「奪う」にも何を書くかを添え、選んだときに断られる理由だけが返るようにする
- 区画の名前は `Candidate.shown_under` と `UnavailableAction.shown_under` で渡す。道筋の最初の段の候補にだけ付けられる
