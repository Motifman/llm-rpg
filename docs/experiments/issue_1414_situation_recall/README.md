# 状況の欄で引いた信念と、いまの cue で選んだ信念を並べる (#1414)

過去 run の想起の場面を組み直し、実 Jev に「次のターンの想起で残す欄」と「体の帯」を問い、
状況の欄で引いた 3 件 (新) と、いまの cue で選んだ 3 件 (旧) を並べた。

- 素材: `var/runs/v4coop_reasonfirst_003` (4 人、プロンプト 639 回)
- 場面: 人ごとに、連続 10 回のプロンプトを 1 窓。信念が 10 件以上ある場面のうち、体の危険を表す語が
  観測に多く出る窓を選んだ。計 40 場面
- Jev: 本番の清算と同じ state と問い (残す欄 5 問 + 体の帯 1 問) で、1 場面 1 回。同じ場面を 3 回問うて、
  計 120 回
- 引く側: 本番と同じ `SituationBeliefRecall` (2 字組の BM25) を手元で回した
- 再現: `uv run python scripts/situation_recall_probe.py --run-dir <run> --out results.json`

## 結果

| 見たもの | 結果 |
|---|---|
| Jev の答え | 120 回すべて返った。縮退 0 回。1 回 0.2 秒ほど |
| 欄の選択の安定性 | 40 場面すべてで、3 回とも同じ欄を選んだ (確率は回ごとに少し違う) |
| 欄を残した割合 | 相手 105/120、自分の状態・やろうとしていること・いま起きたこと・未解決のこと はすべて 120/120 |
| 体の帯 | 平常 24、注意 33、危機 15、分からない 48 (回数)。40 場面すべてで 3 回とも同じ |
| 続けての想起で同じ 3 件が並んだ割合 | 旧 16/36、新 0/36 |
| 旧と新で重なった件数 | 1 場面あたり平均 0.42 件 (3 件中) |
| 欄を 1 つ抜くと 3 件が変わった場面 | いま起きたこと 40/40、やろうとしていること 15/40、相手 5/40、自分の状態 0/40、未解決のこと 0/40 |
| 危機・注意の 16 場面で、体に関わる信念 (食・空腹・怪我・治療など) が載った件数 | 旧 16、新 13 |
| 「いま起きたこと」にメモ機能の応答や【心の声】が混ざった場面 | 14/40 |

## 分かったこと

1. **Jev は欄をほとんど捨てない**。残す確率は 0.6〜0.8 に集まり、捨てたのは「相手」の 5 場面だけ。
   値が空の「未解決のこと」(この run には予期が無い) も 0.7 前後で残した。清算の state に欄の値が
   入っていないので、Jev は欄の中身を見ずに選んでいる。いまの形では、欄を選ぶ仕組みが実質的に
   「全部の欄で引く」と変わらない
2. **新しい引き方は「いま起きたこと」に強く引っ張られる**。同じ 3 件が続けて並ぶことは無くなったが、
   主な理由は、毎ターン変わる「いま起きたこと」で引くから。この欄を抜くと 40 場面すべてで 3 件が変わる
3. **「いま起きたこと」に雑音が入っている**。メモ機能の応答 (「メモを追加しました（ID: ccd325…）」) や
   「【心の声】」が、自分の行動の結果や観測として入る。環境の出来事ではなく、ID のような文字列も含む
4. **体の帯は読めている**。カイがメモに書いた「空腹 82/100 (危険域)」から「危機」と読み、他人の空腹の
   話しか無いノアの場面では「分からない」と答えた。ただ、いまの信念の文に帯の語が無いので、帯の文で
   体に関わる信念は引けていない。#1454 の書き込み時のキーに帯の語が入ってから効く想定どおり

## 実例

### 1. 体が危ない: カイ (プロンプト 102、観測拠点跡)

直前のターン: カイがメモに「HP84/100、空腹82/100（危険域）」と書いた。

| 欄 | 値 |
|---|---|
| 場所 | 観測拠点跡 (廃屋) |
| 相手 | ノア / リオ / エイダ |
| 自分の状態 | 体の状態は危機 |
| いま起きたこと | 昼になった。/ メモを追加しました（ID: ccd325…）… / (写真の描写) |

Jev: 5 欄すべて残す、帯は危機。

| 旧の 3 件 | 新の 3 件 |
|---|---|
| 山頂へのルートは川沿いと沼経由の2つがある | 観測拠点跡の廃屋に祖父の手記があるかもしれない |
| 隠し入江から山頂へは川沿いと沼経由の二ルートがある | エイダは廃屋に関心があり手記や地図を探している |
| エイダは仲間と食料を分け合う思いやりのある人物だ | この島の廃屋は観測点だった |

帯は危機と読めたが、新の 3 件は廃屋の知識に寄った。空腹に効く信念は載らない。旧の 3 件目
(食料を分け合う) のほうが、まだ空腹に近い。

### 2. 相手を捨てた: ノア (プロンプト 100、観測拠点跡)

直前のターン: 昼になり、ノアがメモを 3 件完了にした。カイが「ここの探索はもう出し尽くした」と言った。

Jev: 相手を捨て、残り 4 欄を残す。帯は「分からない」(ノアの体のことは書かれていない)。

| 旧の 3 件 | 新の 3 件 |
|---|---|
| 隠し入江への移動が安全を確保する | 隠し入江への移動が安全を確保する |
| カイの祖父はS.E.-7の観測員で行方不明になった | 山頂へのルートは川沿いと沼東の二つある |
| 行動が救助につながっていない | カイの祖父はS.E.-7の観測員で行方不明になった |

探索を出し尽くして次の行き先を考える場面で、新は山頂へのルートを引いた。

### 3. 他人の体の話: ノア (プロンプト 102、観測拠点跡)

直前のターン: 探索で新しい発見は無かった。エイダが来て「カイの空腹が 88 で危険域。隠し入江に戻って
貝を焼いて食べるのが賢明」と言った。

Jev: 5 欄すべて残す。帯は「分からない」(空腹なのはカイで、ノアではない)。

| 旧の 3 件 | 新の 3 件 |
|---|---|
| エイダはシステムに制限されて直接治療できない | 動いている相手には治療をinteractできない |
| エイダは治療しようとするが行動が阻まれることが多い | 隠し入江への移動が安全を確保する |
| 山頂へのルートは川沿いと沼東の二つある | 狼煙台を使うには北西の風の日に焚く |

## 次にやること (提案)

1. **欄の問いに、いまの欄の値を見せる**。清算の state に、そのターンの終わりの状況の欄を足す。
   値が空の欄を残すことも防げる
2. **欄を選ばせる形を変えるかを比べる**。「残す / 捨てる」を 5 問並べると、どれも「残す」に寄る。
   「次の判断にいちばん効く欄を 1〜2 つ選ぶ」形 (確率の高い順に上位を採る。閾値ではない) と比べる
3. **「いま起きたこと」から、記憶とメモの tool の応答と【心の声】を外す**。環境の出来事ではない
4. 体の帯は、#1454 で書き込み時のキーに帯の語が入ってから、効くかを見直す

## 近似と限界

- 場面の時点の信念は、run の終わりの snapshot の信念のうち、trace に ID が最初に現れた時刻
  (または `created_at`) が場面より前のもの。snapshot の `created_at` は信念を改めると更新されるため
- この run には予期の仕組みが無いので、「未解決のこと」は空。目的も入れていない
- 旧の 3 件は trace の `semantic_passive_recall` の記録そのもの。新の 3 件は手元で計算したもの
- 費用: Jev の decision API は課金額を返さないので、金額は測れていない。120 回、state は平均 1,760 文字
