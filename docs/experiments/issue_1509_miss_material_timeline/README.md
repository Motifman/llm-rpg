# 外れた予期の信念の材料に、実際に起きたことを付けて比べ直す (#1509)

> 信念をまとめる固着 (`BeliefConsolidationCoordinator`) は #1631 の #1790 で消した。`probe.py` と `baseline_probe.py` は、いまのコードでは動かない。

実 run `var/runs/memory_jev_e2e_v4_001` の外れ 30 件を、#1509 で実装した渡し方 (C) で信念をまとめる LLM に問い直し、#1491 の比較 (A、B1) と並べた。

当否は Claude が読んで付けた。人は確かめていない。人の当否は [labels_human.json](labels_human.json) に書くと、[table.md](table.md) の「人」の列と集計に出る。

## 渡し方

- **A**: いまの渡し方。「たぶんと思っていた予期『…』は外れた。」だけ
- **B1**: A に、清算のときに Jev に見せた時系列のうち、予期を書いたターンから確定したターンまでを足す (#1491)
- **C**: #1509 の実装。B1 との違いは 3 つ
  - 行動と観測の文から tool の名前と ID を外す。小文字で始まる語は「操作」に置き換え、数字と a〜f だけの 6 文字以上の語 (メモの ID) は消す。発言は触らない
  - 材料の時系列に上限 (1500 字) を置く。30 件の最長は 1193 字で、切り詰めは 0 件
  - 信念をまとめる LLM のシステムプロンプトに、時系列の説明と【外れた予期から学ぶ】の指示を足す。予期と関係の無い出来事から学ばない、理由が書かれていないときは 1 回の観測で言い切らない、操作の名前や案内を信念に書かない

B2 (B1 に書き方の指示を足したもの) は [baseline.json](baseline.json) に残っているが、表には並べていない。

## 結果

| 渡し方 | 作られた信念 | 理由や次の行動が分かる | 予期と関係の無い学び | ゲームの用語 | 1 回の観測で言い切る |
|---|---|---|---|---|---|
| A | 21 | 0 | 0 | 0 | 0 |
| B1 | 27 | 9 | 4 | 0 | 4 |
| C | 22 | 8 | 1 | 0 | 4 |

数は信念ごとに数えた。1 つの信念が複数に当たることがある。

- 理由や次の行動が分かる信念は、時系列を足したことで 0 から 8〜9 件に増えた。C は B1 と同じ水準を保った
- 予期と関係の無い学びは 4 件から 1 件に減った。B1 の「カイが枯れ葉の場所について答える」から山の道順を学んだ件は、C では捨てた。残った 1 件は大型カニの信念 (#14)
- ゲームの用語は B1 も C も 0 件。#1491 の B2 で `travel_to` が入った件は、C では時系列に tool の名前が無い
- 言い切りは減らなかった。C の 4 件のうち 2 件 (#4、#5) は、他の人の「浜はもう打ち止めだ」「一通り確認した」を理由として読み、「残っていない」「見つからない」と言い切った。#28 は、隠し入江の空の箱を廃屋のことと取り違えた。B1 も同じ取り違えをしている

## C で失ったもの

- 「大樫の樹は登る対象ではなく、移動先の場所である」(B1、#13) を C は作らなかった。時系列で理由を告げていたのが「そこへ行くなら操作を使う」という操作の案内で、指示どおり世界の出来事ではないとして捨てた。#12 も同じ理由で捨てた。案内の文が世界の事実 (大樫の樹は隣の場所) を含むときに、それを学べない
- 「探して何も無かった」型の外れは、A と同じく「〜かもしれない」になる。学ぶ中身がもともと無い

## 同じ入力でも結果が揺れる

C は 2 回問うた。1 回目は時系列にメモの ID が残っていたので (`774c5e` が残り、`a8cbc3` が「操作」になった)、ID を消す形に直して問い直した。この表は 2 回目の結果。そのあとセルフレビューで、発言と数と単位を外さない形に狭めたが、30 件の時系列は変わらないことを確かめたので、問い直していない。時系列が変わったのはメモの ID を含む 8 件だけだった。temperature は 0 だが、時系列が同じ 22 件のうち 6 件で作るか捨てるかが変わり、ほかの多くでも文面が変わった。B1 と C の差 (理由の 9 件と 8 件、関係の無い学びの 4 件と 1 件) は、この揺れと同じくらいの大きさにある。1 回目の C でも、関係の無い学びは 2 件 (大型カニと、拠点の予期から学んだ流木) で、B1 の 4 件より少なかった。

## 関係の無い出来事を除く方法

Issue は、Jev に問う案と、信念をまとめる LLM への指示で扱う案を比べて決めることを求めていた。指示の案だけを試した。Jev に問う案は試していない。

- Jev に問うなら、時系列の行ごとに「この外れに関係するか」を問う。30 件の時系列は 6〜22 行あり、清算の呼び出しに外れ 1 件あたり最大 22 問が足される。根拠の問いの上限 (12) と同じ上限を置くと、長い時系列では行を問わずに落とすことになる
- 指示の案は、関係の無い学びを 4 件から 1 件に減らし、呼び出しは増えなかった

指示の案で足りなくなったら (関係の無い学びが run で目立ったら)、Jev に問う案を比べる。

## 当否の付け方

- 理由や次の行動が分かる: 外れた理由 (尽きた、時間がたつと戻る、場所であって物ではない、相手は別の所へ行く) か、代わりに何があるか・どうするかが分かる。「〜とは限らない」「〜は無いかもしれない」のように予期を打ち消すだけのものは数えない
- 予期と関係の無い学び: 予期の外れと結びつかない出来事から作った
- ゲームの用語: tool の名前、操作の手順など、世界の言葉でないものを含む
- 1 回の観測で言い切る: 確かめていない、または 1 回だけ見たことを「無い」「見つからない」と言い切る。実際に見ていない場所のことを言い切ったものも含む
