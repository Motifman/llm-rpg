## D2268-2. 【この場所の造り】を世界のドメインの地図 (`WorldMap`) から書く

**何を**: 古い run のシステムプロンプトにあった【この場所の造り】を、新しい世界の案内 (`BriefEnteringPerson` の orientation) に載せる (#2268 の 2 本目)。

| | 決まり | 例 (廃坑の山村 v2、1 日 48 tick) |
|---|---|---|
| 置き場所 | 地図は世界のドメインの `WorldMap` が、宣言された場所と通路から作る。言い回し (行の形・明るさの言葉・分と tick の単位) は共通の部品の `world_map` (`WorldMapWording`) に置く。見出しは、ほかの案内の見出しと重ならないことを一緒に確かめるため、`briefing_headings.world_map` に置く | `  北の竪坑口 (明るい) → 北の竪坑の底 まで 30 分 / 集会所 まで 30 分 / 雪の峠道 まで 60 分` |
| 出すかどうか | シナリオの導入の `show_world_map` で決める。書かなければ出さない | 山村 v2 は出す |
| 載せる通路 | 始まった時点で隠れていない通路だけ。双方向の通路は両端の行に載せ、同じ相手へ何本もあれば短いほうを載せる | |
| 並び | 場所は宣言の順。行き先は近い順、同じ時間なら名前の順 | |
| 時間の単位 | 昼夜のある世界は、時計と同じく `通路の tick 数 × 1440 ÷ 1 日の tick 数` (切り捨て) 分と書く。先に割ると、1 日の tick 数で 1440 が割り切れない世界で地図と時計がずれる。昼夜の無い世界は tick の数を「N 手ぶん」と書く | 1 tick = 30 分 |
| 置く位置 | 案内の「この世界の前提」と「あなたが知っていること」のあいだ | |

### 古い run との違い

- 古い run (mine_v1_002) の地図は、1 tick を 5 分として書いていた。時計は 1 tick を 30 分として進んでいたので、地図と時計が食い違っていた。古い run の `_minutes_per_tick` が昼夜の設定の `ticks_per_day` を、実際の置き場所 (`cycle.ticks_per_day`) ではなく設定の直下から読もうとして、いつも 5 分に落ちていたため。新しい世界は、時計と同じ割り出しで書く
- 廃坑の山村 v2 の通路の tick 数は、古い run の時点の v1 (2〜7 tick) から 1〜3 tick に変わっている (#2239 で書き直した)。地図の時間は、この 2 つが重なって古い run と違う
- 場所と行き先の組み合わせは、古い run と同じ (21 の場所、同じ行き先)。山村 v2 には隠れた通路が無いので、隠れた通路を載せない決まり (D2268 の 2 節) は、山村 v2 の地図を変えない
