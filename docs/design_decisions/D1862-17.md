## D1862-17. 発言の場所はスポットで持ち、タイルの仮座標を要求しない

**何を**: `PlayerSpokeEvent` と `PlayerStatusAggregate.speak` から発言者の座標を外す。発言サービスはスポットの有無を確かめ、本番のプレイヤー初期化で仮の座標を置かない。旧タイル距離の配信戦略と再公開を削除し、音の届き方は既存の `SpotGraphSpeechRecipientStrategy` と `SpeechAudienceResolver` に任せる。

**なぜ**: 本番の音伝播はスポット間のつながりと遮音で決まる。読む人のいない仮座標を入れる案は、発言の前提を実在しないタイル位置に結びつけ続ける。座標を任意のイベント項目として残す案も、唯一の利用側である旧配信戦略を消すため採らない。

**どうしないと壊れるか**: グラフを渡さない観測の構築は、取引など休眠文脈の利用側があるので禁止しない。その構築では発言の配信先を解決せず、旧タイル距離への代替経路を持たない。グラフに話者がいない場合もタイル距離へ戻さない。本番は必ずグラフを渡す。離脱者の発言では離脱前の場所を使う既存経路、宛先検証、ダウン時の拒否、発行後のイベント消去と発行失敗時の保持を維持する。

**保存との関係**: `PlayerSpokeEvent` は本番で `PipelineEventPublisher` から観測へ渡り、観測文と構造化情報が記録される。生の発言イベントを永続化・復元する登録や変換器はない。SQLiteのイベント保存は明示登録した取引4種だけが対象である。プレイヤー状態と追跡の保存形式、古いSQLiteの表・migrationは変更しない。

Issue #1862。質感の確認は [speech_without_tile_coordinate.md](../quality_checks/speech_without_tile_coordinate.md)。
