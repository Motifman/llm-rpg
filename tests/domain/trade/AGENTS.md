# 取引試験の所有権

- `test_trade_aggregate.py` の出品・受託・取消・辞退イベントは、既存の `contains_all_fields` が発行件数と内容を一緒に守る。同一準備・操作・引数の「発行された」だけの宣言を追加しない
- イベント主試験を統合するときは、型・集約ID・件数・投影用情報・操作固有の当事者を、削除前に統合先が守ることを確認する
- 状態遷移、拒否、複数操作のイベント蓄積順序は別の契約。単発イベントの確認があることを削除理由にしない
- ハンドラやJSON試験で直接作ったイベントは、集約によるイベント生成の代替証拠にはしない。配送・保存・復元にはその層固有の責務がある
- 同じ拒否例外が別のガードから出るだけの変更を、検出すべき契約変更と数えない
- 今回の統合と保全根拠は `docs/test_audits/trade_event_contracts.md` を参照する
