# 主体の識別・接続の試験所有

以下は Being、BeingId、BeingIdentity、BeingAttachment、
unique_attached_being の試験に適用する。

- 接続・解除・宣言集合の保持は `aggregate/test_being.py` が所有する。拒否は例外だけでなく、元の接続が残ることも確かめる。不正型の接続は未接続・既接続の両方を使う
- 解除前の戻り値と解除後の状態は、同じ解除操作の試験で守る。乗換え試験は主体ID・人格・非空宣言の継続を守り、同じ戻り値だけの試験を増やさない
- 外から渡した集合や取得した集合への更新が主体へ波及しないことは、値の等価比較だけで済ませない
- 値の検証・等価性は各値オブジェクトの試験が所有する。2項目なら他方を正常・同値に保ち、各項目を独立に変える。単純な既定値・型・ID・hashの試験を一律に削除しない
- `unique_attached_being` は取得済み列の0件・1件・2件以上を判定する。検索条件はこの関数へ持ち込まず、実取得との接続はアプリケーション側で守る
- 接続先を世界・プレイヤーとも変える入力へ置き換えて、世界だけ変える既存入力を落とさない。新しい境界は元の行を残して表へ加える
