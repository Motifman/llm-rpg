## D2025. 行為の型と共通の前提を作る

**何を**: 行為の型 (`action/built_in_attempts.py`、`action/interaction_attempts.py`) と共通の前提 (`ActionPrerequisiteCheck`) を作った (#2025、#1978)。行為の型は性質を自分で答え、共通の前提は種類を見分けずに尋ねる。文書から決まらなかったことは、ユーザーと次のように決めた。

| 型・振る舞い | 決めたこと |
|---|---|
| 段階の許可 | `WorldStageDeclaration.allows(ActionKind)` と `allows_interaction(InteractionId)` の 2 つ。作者の操作は `INTERACT_WITH_*` の `ActionKind` では許さない |
| 段階と物の宣言を ID で引く | `DeclaredNouns.world_stage_of(WorldStageId)` と `object_of(ObjectId)` を足した。宣言に無い ID は `UndeclaredNounException` |
| 区画の出入りの体の使い方 | 出入りの宣言の欄 (`section`、`exertion`) だけを持つ Protocol `DeclaredSectionAccess` を `action/` に置き、入る・出る行為が受け取る。出るときは外側が、本人のいる区画の出入りの宣言を渡す |
| 地面の品物 | `are_together` は居場所を持つものどうしの問いなので、本人の居場所の地面に品物があるかで確かめる。移動の途中なら `NotTogether` |
| 性質に答える振る舞い | `UsesBody` / `DoesNotUseBody` が疲れの限界で断るかを、`LivingOnly` / `LivingOrDeparted` が去った人を許すかを、`WithPerson` / `WithObject` / `WithGroundItem` が近くにいないときの理由を答える |
| `RefusalTexts` の文 | 書ける人は `{actor}` だけ。`common_rules` はすべての種類を作るときに求める。`world_state` が揃っているかは compose が確かめる |

**実装で決めたこと**:

- 去った人として動くのは、`departed_persons_act` の世界で死んだ人 (world_state.md の「Died の人は去った人として動く」)。届くかは `DepartedPerson` の居場所で確かめる
- 生きて動けるのは、`can_act()` が真で、結末がまだ決まっていない人
- 確かめる順番は、動けるか → 段階 → 行っている最中か → 疲れ → 同じ場所にいるか・届くか
- `SomeoneInTheDark` に向けた操作は、相手が決まっていないので近くにいる必要を答えず、`person_as(TARGET)` は `SubjectNotInTriggerException`
- 操作の引数は、作るときに宣言の `arguments` と名前と種類で合わなければ `ArgumentsDoNotMatchDeclarationException`
