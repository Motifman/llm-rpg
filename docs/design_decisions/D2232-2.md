## D2232-2. 自分の行動は結果として本人に返し、目撃の文と体の観測では届けない

**何を**: 遊びの進行が Being に返す行動の結果 (`OwnActionResult`、D2232 の 8 節) の本文と、世界が本人に届ける知らせを決め直した (#2232、親 #2212)。調整役を通してユーザーと決めた。

それまでの並び (ゲンの【直近の出来事】、1 回目に候補に無い「北の坑道」へ行こうとし、2 回目にカンテラを灯した):

```
- [1 日目 00:00] 「行く」の「行き先」に「北の坑道」は選べない。
- [1 日目 00:30] できた。
- [1 日目 00:30] ゲンがカンテラに火を入れた。
```

結果の「できた。」だけでは何ができたか分からず、自分の行為の目撃の文と 2 行に分かれていた。断られたときは、理由が結果と体の観測で 2 回並んでいた。

| | 決まり | 例 |
|---|---|---|
| 結果の本文 | シナリオの操作で作者が成功の文 (`success_text`) を書いていれば、それを使う。組み込みの行為 (移動・耳を澄ますなど) は、行為ごとの文に差し替えるまでのつなぎとして、共通の文面の「できた。」(`RefusalTexts.done`) | 金庫を「1907」で開けると「ダイヤルが噛み合う音がして、金庫の扉が開いた。…昇降機の起動鍵だ。」、耳を澄ますと (つなぎのあいだは)「できた。」 |
| 自分の行為の目撃の文 | 行う人には届けない。見聞きした人にだけ届ける | ゲンがカンテラを灯しても、ゲンには「ゲンがカンテラに火を入れた。」が届かない。隣にいたサヨには届く |
| 断られた理由 | 行動の結果にだけ書き、体の観測としては届けない | ゲンが金庫を「0000」で開けようとすると、結果に「扉はびくともしない…」が 1 回だけ並ぶ |

【直近の出来事】の自分の行動の行は、古い run と同じ `[行動] {行動の要約} → [結果] {結果の文}` にする。行を組むのは Being の側 (#2240) で、組み込みの行為ごとの結果の文と行動の要約を世界が持って渡すのは、次の PR で行う (調整役を通してユーザーと決めた)。

### 世界の側の置き場所

- 成功の文は、行為を確定するとき (`CarryOutAction`) に、効果の前の世界から引き、返事 (`ActionDone.done_text`) に持たせる。品物を使い切る操作は、効果のあとでは品物の種類を引けないため。引き方は試みに問う (`ActionAttempt.done_text_in`)。組み込みの行為は共通の「できた。」、シナリオの操作は作者の成功の文を返す
- 成功の文に書ける人の穴は、失敗の文と同じ (`{actor}`、操作に相手がいれば `{target}` など)。それまで成功の文はどこでも読まれておらず、人の穴を確かめていなかったので、世界の設計の点検 (`WorldDesignReview.interaction`) で読み込みのときに確かめる。使えない名前は `UnknownPersonPlaceholderException` で断り、相手のいない操作に `{target}` を書くと設計の欠け (`DesignFlaw`) になる
- 行為の知らせ (`WitnessedAct.stimuli_at`) は、見える刺激と音の刺激に「行う人には届けない」(`withheld_from`) を付ける。届かなかった理由は記録に「自分の行為」(`NotPerceivedReason.OWN_ACT`) で残る
  - 到着の知らせは同じ知覚の宣言 (`PerceptionDeclaration.seen_at`) を通るが、行為の知らせではないので、着いた本人にも届けたままにする
  - 断られた行為を見ていた人への失敗の文 (`failure_seen_at`) も、行う人には届けない
- 断られた行為の体の刺激 (`ActionRefusal.stimuli_at` の本人への刺激) は作らない。共通の規則で断られたときは、周りから見て何も起きていないので、刺激を 1 つも作らない

これで D2216 の「動かない行為では、もとから本人に自分の行為の文が届いている」「動く行為も同じ扱いにする」を改めた (D2216 を直した)。

**採らなかった案**:

- 目撃の文を本人に届けたまま、結果を「できた。」だけにする (それまでのまま): 同じ行為が 2 行に分かれ、行動と結果の対応が読めない
- 結果に目撃の文を使う: 目撃の文は見ていた人に向けた三人称の文 (「ゲンがカンテラに火を入れた。」) で、本人の結果としては読みにくい
- 断られた理由を体の観測に残し、結果は「断られた」だけにする: 理由が試みから離れた別の行になる
