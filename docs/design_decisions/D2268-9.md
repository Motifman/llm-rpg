## D2268-9. 自分の持ち物と身体の状態を、古い run と同じ段階の言葉で場面に書く

**何を**: 古い run の【現在地と周囲】の末尾にあった「所持アイテム:」と「身体の状態:」の節を再現する (#2268 の 4 本目の 2 本目)。前回からの増減 (「、前回 +N」) は保存の形を変えるので、次の PR に分ける。

古い run (mine_v1_002、ゲン、最初の場面):
```
所持アイテム:
  - "カンテラ" — 油を足して灯す手提げのカンテラ。 [油を足して灯す → "light_lamp"]
  - "カンテラの油" x3 — カンテラに足す油の小瓶。
身体の状態:
  HP: 良好（100/100）
  空腹: 問題なし（0/100）
  疲労: 問題なし（0/100）
```

| | 決まり | 古い run との違いと理由 |
|---|---|---|
| 所持アイテムの行 | `  - "{名前}" x{数} — {説明}`。数は 2 以上のときだけ | 同じ |
| まとめ方 | 同じ種類をまとめる。ただし手に持っている物と荷の中の物は別の行にする | 古い run は種類と腐敗でまとめていた。新しい世界は手に持つかでそのまま使えるかが変わるので、手で分ける |
| 手に持っている物 | 説明のあとに ` (手に持っている)` | 違う。古い run は手と荷を分けていなかった (ユーザーが決めた) |
| 何も持っていないとき | 節ごと出さない | 同じ |
| 品物の操作 `[油を足して灯す → "light_lamp"]` と、その下の「いまできない」 | 出さない | 違う。【行動の候補】に寄せる (ユーザーが決めた) |
| 種類の印・使い方の一言・腐敗 | 出さない | 新しい世界の品物の宣言に、分類・使い方の一言・腐敗が無い |
| HP の段階 | 最大に対して 15% 以下は瀕死、35% 以下は危険、60% 以下は消耗、それより上は良好 | 同じ (古い run の `Hp.describe`) |
| 空腹・疲労の段階 | 上限に対して 0・20・40・60・80% から、問題なし・少し・やや感じる・高い・危険 | 同じ (古い run の `AgentNeed.describe`)。上限は古い run の 100 固定ではなく、世界の空腹と疲れの規則の上限 |
| 並び | HP、空腹、疲労の順 | 同じ |
| 自分の疲れの一言 `  → …` | 疲れの段階の宣言 (`FatigueLevel.felt_as`) に置き、その段階にいるとき疲労の行のすぐ下に出す。`ja_default.yaml` では限界 (100) の段階にだけ「疲労が限界。体を使う行動ができない。」と書き、60 と 85 の段階では何も出さない | 違う (ユーザーが決めた案 A)。古い run は 3 段階に「動きが鈍くなっている。重い行動は控えめに。」「判断が鈍ってきた。発話も呂律が回らない。早めに休むこと。」「疲労が限界。移動も、物への働きかけも、争いもできない。休むか食べるかしないと戻らない。」と書いていた。新しい世界で疲れが効くのは限界のときに体を使う行動 (`exertion: uses_body`) が断られることだけで、60 と 85 では動きも話し方も変わらず、食べても疲れは戻らない。事実に合わない文は、エージェントが当てにしてしまう |
| 状態異常・行動中・停滞の一言 | 出さない | 新しい世界の場面に、それに当たる仕組みがまだ無い |
| 前回からの増減 | 出さない (次の PR) | 身体の状態の保存の形を変えるので分ける |

- 疲れの一言を、人の行の見た目 (`seen_as`) と並べて疲れの段階に置いた。段階と一言が別の表にあると、段階を書き換えたときにずれるため
- 自分の持ち物と身体は、場所の中身 (`SpotContents`) ではないので、別の値 (`Oneself`) にした。`Oneself.of` が持ち物と身体の状態と規則を読み、場面の文はその行を末尾に足す
- 段階の区切りと名前は `ja_default.yaml` の `scene.need_tiers` / `scene.hit_points_tiers` に置いた。区切りは表示の言葉の一部で、疲れの規則の段階 (行動を断る 100 など) とは別の梯子なので、規則には混ぜない
- 梯子が 0 から始まらない (空腹・疲労) か、100 で終わらない (HP) か、並びが上がっていないと、読み込みで断る (`BodyTierLadderException`)
