## D2211. 結末が決まって世界から外れた人は、体も持ち物も時間が止まる

**何を**: 作者の結末 (`DeclaredOutcome`) が決まって世界から外れた人について、世界の時間 (`PassWorldTime`) が進んでも、体の時間 (`PersonVitals.pass_time`) と荷の品物の時間 (`ItemsRunningOut.run_out_carried_by`) を進めないことにした (#2211、親 #2212)。それまでは外れた後も空腹や怪我が進み、外れた人が死んでいた。

例: アキが気を失ったまま「取り残された」に決まって外れる。それまでは時間が進むたびに猶予が減り、アキは死んでいた。すると死の反応が 2 つとも壊れる。死んだ結末を決める `DecideDeathOutcomeHandler` は、結末がもう決まっているので `OutcomeAlreadyDecidedException` で断られる。去った人が動く世界 (`departed_persons_act` が真) では、`PlaceDepartedPersonHandler` が居場所の無いアキを置き直そうとして `OccupantNotPlacedException` で止まる。廃坑の山村 v2 では全員の結末が同時に決まって世界が終わるので起きないが、1 人だけ先に外へ出るシナリオでは起きる。

| | 決まり | 例 |
|---|---|---|
| 体の時間 | 外れた人には進めない。空腹・怪我・死ぬまでの猶予が止まり、死なない | 気を失ったまま外れたアキは、倒れたままで死なない。起きたまま外れたハルは、腹が減らない |
| 荷の品物の時間 | 外れた人の荷の品物は時間が進まず、切れない | 油が 5 tick もつランプを持ったまま外へ出たハルのランプは、何 tick 経っても切れず、`ItemRanOutEvent` も出ない |
| 外れたかの見分け | `PersonOutcomes.has_left_the_world` の 1 か所で見分ける。時間を進める人は `PersonOutcomes.people_in_world` が返す。知覚 (`perceiver_in_world`) と時間帯の知らせの相手 (`DayPhaseDeclaration.addressees`) も同じ見分けを使う | `Died` の人は外れないので、時間が進む (死んだ体には何も起きない) |
| ほかの人から外れた人への行為 | 扱わない。外れた人には居場所が無く、対象に選べない | 外へ出たハルを、坑道の人が手当てすることはできない |

世界の時間を進める処理 (`PassWorldTime`) は、`people_in_world` の人について順に呼ぶだけで、外れたかどうかを自分では見ない。

**採らなかった案**:

- 荷の品物の時間は進める (体の時間とは別の時間とする): world_state.md の「体と持ち物ごと世界から外れる」に合わない。外れた人の荷から品物が消え、その人の名で `ItemRanOutEvent` が出る
- 体の時間を `PersonVitals.pass_time` の中で止める: 体は結末を知らない。結末を渡すと、体が世界から外れたかを自分で見分ける 2 か所目になる
