# アイテム用途ヒントの設計メモ (#794 D)

## 目的

所持品欄に、アイテムが「何のためのもので、どういう種類の場所が要るか」を短く出す。材料を持っているだけで「今いる場所で使えるはず」と誤信するのを減らすための補助であり、具体的な使用場所を全て教える機能ではない。

## 実装済みの範囲

- `item_specs[].usage_hint` を任意フィールドとして追加する。
- `usage_hint` は作者が書いた文字列だけを所持品欄に表示する。
- `usage_hint` 未設定のアイテムは従来どおり表示する。
- プロンプトにはアイテム名と用途文だけを出し、`item_spec_id` / `spot_id` / `object_id` は出さない。

## 全知化を避ける制約

`HAS_ITEM` 条件から、使える具体的な場所やオブジェクトを機械導出してプロンプトに出してはいけない。たとえば `driftwood` が `campsite` の `fire_pit` と `summit` の `signal_fire_pit` で使えるとしても、所持品欄に「拠点」「山頂」「campsite」「summit」などの具体場所は出さない。

この PR の D は、一般常識としての用途だけを出す。

- 良い例: 「火を起こす材料。焚き火跡や狼煙台のような場所で interact の材料になる」
- 避ける例: 「拠点の焚き火跡、山頂の狼煙台で使える」

## 今回やらないこと

- B: 発見済みの使用場所だけを名指しする機能。
- C: 使用可能性の発見イベントをエピソード記憶 / 意味記憶に流す機能。
- B 用の trace 集計。候補数、発見済み数、抑制数などは今回扱わない。

発見済み場所を出す場合は、将来 #794 の続きとして発見ガードを設計してから足す。今回の `usage_hint` を、後から全 spot 索引に置き換えない。
