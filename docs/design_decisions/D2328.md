## D2328. ターンの結果の振り分けと止める理由を巡り (TurnRounds) に置く

**何を**: 遊びの進行の application が決めていた 2 つの規則を、巡り (`TurnRounds`) に移した (#2328、調整役と決めた)。D2232 の 7 節の決まりそのものは変えていない。

### 1. 世界に渡す行動を選ばなかったターン (`ChoseNoAction`)

ターンの結果 (`TurnOutcome`) は `Acted` / `Waited` / `ChoiceFailed` / `ChoseNoAction` の 4 つ。LLM は答えたが世界に渡す行動が無いとき (ツールを呼ばない、無いツール、思い出すだけ、目次を直すだけ) は `ChoseNoAction` で終える。

- 失敗の続きを切り、待つ人にはしない (D2232 の 7 節と同じ)。この扱いを `TurnRounds.finish_turn` が決める
- それまでは application が `Acted` として返していて、記録 (`TurnFinishedEvent.outcome`) から「行動した」と「行動しなかった」を見分けられなかった

例: ミオが 2 回続けて落ち、思い出すだけのターンを挟み、また 1 回落ちても、ミオは待ちに入らない。

### 2. 止める理由と優先順位

止める理由 (`RoundLimitReached` / `ChoosingKeptFailing`) をドメインに置き、`TurnRounds.reason_to_stop()` で問う。世界の終わり (`WorldEnded`) だけは game_world に問うので application に置く。

| 重なり | 止める理由 | なぜ |
|---|---|---|
| 選び続けた失敗と巡りの上限 | `ChoosingKeptFailing` | 上限は正常な終わり。上限で覆うと、壊れた run が正常に終わったように記録される |

止まった結果は、理由と捨てた選択を持つ 1 つの型 (`PlayStopped(reason, discarded)`) にした。捨てた選択は LLM とのやりとり (Being の application の型) を持つのでドメインに置けない。理由ごとに捨てた選択を持つ型を application に残すと、ドメインの理由と型が 2 組になる。run の終わりの記録 (`run_end`) の値は変えていない。

### 3. 失敗が続いて待ちに入った人の飛ばす理由

同じ人が 3 回続けて選べずに待ちに入ったときは、`TurnSkipReason.WAITING_AFTER_CHOICES_KEPT_FAILING` で飛ばす。自分から待った人 (`WAITING`) と起こす規則は同じ (目立つ知らせか、起こすまでの長さ)。

例: ミオが巡り 4・5・6 で落ち、ゲンが巡り 6 で待つを選ぶと、巡り 7 の `RoundOpenedEvent.skipped` は (ミオ, `WAITING_AFTER_CHOICES_KEPT_FAILING`)、(ゲン, `WAITING`) になる。

### 4. 巡りの中の分け方

`TurnRounds` は 1 つの集約のまま、中を値の変わらない値オブジェクトに分けた。集約は値を差し替えるだけで、閾値はそれぞれの値オブジェクトが持つ。

| 値オブジェクト | 受け持つこと |
|---|---|
| `OpenRound` | 開いている巡りの番号、ターンのある人、終えた人とその順 |
| `WaitingPeople` | 待っている人ごとの、待ち始めた巡りと待つ理由。呼びかけと決めた巡りの数で起こす |
| `AddressedPeople` | 自分に向けた観測を受けた人 (D2268-19) |
| `FailuresByPerson` | 人ごとの続けて選べなかった数。3 回で待たせる |
| `ChoiceFailureStreak` | 人を問わない失敗の続きと、またがった巡り。8 件・2 巡りで止めると決め、その理由を残す |
| `ObservationsHeldWhileChoosing` | 選んでいる人と、そのあいだに預かった観測 (D2232 の 10 節) |

`finish_turn` は、自分に向けた観測の記録を消してから、預かった観測を渡す。この順は `finish_turn` の中で確定させ、値オブジェクトをまたいで呼び手に任せない。逆にすると、選んでいるあいだに届いた呼びかけが、ターンを終えた時点で消える。
