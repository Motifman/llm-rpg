## D2330. 時間帯の知らせの相手は、その tick を進め終えた世界から選ぶ

**何を**: 時間帯の知らせ (`DayPhaseDeclaration.announcement`) の相手を選ぶ時点を、時計を進めたときから、その tick を進め終えたあとに改めた (#2330)。時計の集約 (`WorldClock`) は時間帯が変わった事実だけを `TimeOfDayChangedEvent` にためる。相手は、刺激に変える役 (`StimulusTranslator`) が確定後の世界 (`WorldFacts`) を読み、宣言の `DayPhaseDeclaration.addressees` で選ぶ。

例の場面: 夜明けの tick に、ハルが飢えで倒れる。

| | 前 (D2203) | 後 |
|---|---|---|
| 相手を選ぶ時点 | `PassWorldTime` が時計を進めた直後。飢えで倒れる前 | `PassWorldTime` を確定したあと。飢えで倒れたあと |
| ハル | 相手に入る。倒れているので、届けるときに捨てられる (`kept_while_fainted`) | 相手に入らない |
| ハルに届くもの | どちらも無い。目が覚めても「朝になった」は来ない | 同じ |

エージェントに届く文は変わらない。変わるのは、知らせの相手の集合 (`AnnouncementStimulus.audience`) だけ。

**なぜ**: 時計の集約が `WorldFacts` を受け取り、知らせを誰に送るかまで決めていた。誰に知らせるかは宣言の決まりで、時計の決まりではない。tick を進め終えた世界で選べば、同じ tick に倒れた人・死んだ人を相手に入れずに済み、D2203 の「倒れている人には届けない」に沿う。

**どこで世界を読むか**: 確定後の知覚を配る受け手 (`DeliverPerceptionOfCommittedEvents`) が、1 回の確定の出来事ごとに読み取りの `CommandScope` を開き、その `WorldFacts` を翻訳に渡す。世界を読む翻訳は時間帯の知らせだけで、ほかの翻訳は今までどおり宣言とイベントだけで刺激を作る。

**採らなかった案**:

- `PassWorldTime` が時計を進めた直後に相手を選び、イベントに載せたまま集約から `WorldFacts` を外す: 時計は相手を決めなくなるが、同じ tick に倒れた人が相手に入るのは変わらない
- 刺激の相手を、届けるとき (`DeliverPerception`) に宣言の選び方から決める: 刺激の型に「まだ決まっていない相手」を足すことになり、変更が大きい

**関連**: Issue #2330、D2203。
