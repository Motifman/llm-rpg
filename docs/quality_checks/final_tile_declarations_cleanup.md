# タイル専用の残存定義の整理

Issue #1862の独立監査で見つかった、発生元が退役済みの定義だけを整理する。
基準は`6c4d37dc48744dc7284f41df9aec187dabc8e938`。

## テストリスト

- [x] 旧採食イベント、追跡例外、環境区分、システム例外が存在しない。
- [x] 発生元のない失敗コード10件は専用対処文を持たず、汎用案内になる。
- [x] 保持するクラスと対処文を変更しない。
- [x] 観測登録・配信・整形、モンスター、追跡、天候、スキル装備の関連試験が通る。
- [x] スタブと山村・避難訓練の各3シード40tickの記録を前後比較する。
- [x] 独立レビューで削除範囲と保持する経路を確認する。

全体試験はCIへ任せ、最新HEADの結果をPR本文へ記録する。

## 削除と保持の根拠

| 定義 | 退役した利用側 | 現在の利用 |
| --- | --- | --- |
| `MonsterFedEvent` | 旧物体の採食処理 | 型を動的に取得する否定観測試験だけ |
| `MonsterPursuitException` | 旧`fail_pursuit` | 定義だけ |
| `EnvironmentTypeEnum` | 物理マップ、旧天候効果、旧物理マップの変換処理 | 定義だけ |
| `WorldSystemErrorException` | 旧タイルの問い合わせ・移動・物置き等 | 定義だけ |
| 移動・ゲート・相互作用・設置・追跡の旧失敗コード10件 | 旧ツール実行・移動等の専用例外 | 対処文の辞書だけ |

削除前のソースをASTと文字列で調べ、実行時・型・再公開・動的文字列・保存復元に読者がないことを確認した。旧イベントだけは試験が型を要求していたため、観測されないことの3件を、型そのものの不在保証1件へ置き換えた。マップイベントの不在と現役の天候イベントを確かめる既存試験は維持する。

`WorldApplicationException`は消耗品例外の基底として残す。`SYSTEM_ERROR`は他の現行処理も使うため、対処文を残す。保持する4モジュールの全クラス定義は基準と構文木が一致し、残る対処文80件も全文一致した。追跡の領域と保存形式、天候・時刻、スキル装備、クエスト・ショップ・SNS・取引の対処文は変更しない。

定義を互換用に残す案では発行元がなく使えない経路を維持するため、既存の削除方針に沿って除去する。新しいドメインの規則や保存形式は導入しない。歴史と明示された`domain_events_observation_spec.md`等の本文は当時の記録として維持する。

## 検証

- 不在保証は変更前に14件失敗し、既存のマップイベント確認1件は成功した。
- 削除後の関連試験3,907件が成功（最大4並列）。変更Pythonのruff、mypyの1,272ファイル、空白検査も成功した。
- 独立側の不在保証・観測・例外整形の28件も成功した。
- 独立レビューは全重大度で指摘0件。検証文書も実装と一致することを確認した。
- 比較と静的検査の出力先は`/tmp/llm-rpg-1862-final/`。変更前は基準コミットの追跡ファイルを展開し、`PYTHONPATH`で変更前のソースを明示して実行した。変更後も自分のソースを明示する。`.env`は置かず、実験時のdotenv読込は検証用`sitecustomize.py`で無効化する。実LLMを呼ばない。
- 変更前の展開先にはGitの管理情報がないため、実験設定のGit欄は空になる。展開元は上記の基準コミットであり、変更前のイベント型がその展開先から読み込まれることも確認した。
- `make experiment EXPERIMENT_PROFILE=smoke_stub`は既定の島シナリオ・2tick・stubを確認し、全98記録の種別別件数が前後一致した。行動・観測は出ないため、この試行だけを同等性の根拠にしない。
- `make fuzz-scenario`を山村・避難訓練で各シード0〜2・40tick実行し、前後とも全6試行が成功、例外・検出事項0件。同じ実行関数の記録も採取し、全記録種別・観測種別・ツール別行動件数が一致した（合計1,990観測・1,205行動）。

## 前後の振る舞いと質感

本番の発行元を持たない型と対処文を削除するため、スポットの世界でできる行動と見聞きする内容は維持する。旧失敗コードを直接問い合わせる場合だけ、専用の助言から汎用の案内に変わる。型を直接読み込む外部コードとの互換は維持しない。今回の調査で、そのような利用側は確認されなかった。

スタブでの記録の種類と件数の一致を確認するが、文章の自然さや長期間の判断の質は評価しない。質感の改善も主張しない。
