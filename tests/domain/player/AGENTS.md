# HP差分・表示の試験

この節は `tests/domain/player/test_player_hp_delta.py` だけを対象とする。
他のプレイヤー試験へ今回の監査判断を一般化しない。

- 差分算出・基準更新・照会の非消費はPlayerStatusAggregate、現在値と増減の併記はHp.describeで直接検査する。
- 初回未取得は満タンだけでなく非満タンでも確認する。元の入力は追加行に置き換えず残す。
- 正負の差分付き表示では、接尾文だけでなく現在値/最大値も同じ戻り文字列にあることを確認する。
- 完成済み文字列を注入するUI試験は配置の証明であり、Hp.describeの値生成の代替にしない。
- 連続照会は独立した数値との比較を残す。明示0と省略Noneも両方保持する。
- 危険表示の意味を確認し、不要な句読点の完全一致や内部オブジェクトの同一性を要求しない。

背景と元10宣言の保持先は `docs/test_audits/player_hp_trajectory_contracts.md` を参照する。
