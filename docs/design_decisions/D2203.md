## D2203. 結末の知らせは本人に、時間帯の知らせは作者が書いた相手に届ける

**何を**: 作者が書く結末の知らせ (`OutcomeDeclaration.announcement`) と時間帯の知らせ (`DayPhaseDeclaration.announcement`) を、誰に、どの刺激として届けるかを決めた (#2203、親 #1978)。どちらも `PersonOutcomeDecidedEvent` と `TimeOfDayChangedEvent` が知覚に流さない一覧 (`NOT_PERCEIVED_EVENT_KINDS`) に入っていて、誰にも届いていなかった。廃坑の山村 v2 では、「ハルは昇降機で外へ出た」も「日が落ち、夜になった」も本人に届かない。実装は #2204 で行う。

例の場面: 夕方、ハルとサヨが籠に乗って昇降機が上がる。ゲンは坑道の奥にいて、アキは倒れて気を失っている。

| | 決まり | 例 |
|---|---|---|
| 1. 結末の知らせの受け手 | 結末が決まった本人だけに届ける | ハルには「ハルは昇降機で外へ出た」、ゲンには「ゲンは坑道に取り残された」が届く。ゲンに、ハルの結末は届かない。籠が上がる様子は、作者が出来事の知らせに書いて周りに伝える |
| 2. 気を失っている人の結末 | 目が覚めたときに、ほかのたまった知らせと同じく届ける (#2195 の `MissedNotices`) | アキは起きたときに「アキは坑道に取り残された」を知る |
| 3. 時間帯の知らせの受け手 | 作者が知らせごとに届く相手を書く。書き方は出来事の知らせ (`announcement_to`) の人の選び方 (`audience`、`PeopleSelection`) と同じ。書かなければ、起きている全員に届ける | 廃坑の山村 v2 では「空が白み、朝になった」に「屋外の場所にいる人」と書き、坑道の奥のゲンには届かない。「鐘が鳴り、夕刻を告げた」なら書かずに全員へ届ける |
| 4. 気を失っている人の時間帯 | 届けず、ためもしない。目が覚めたときの場面で分かれば足りる | アキが朝に目覚めても、「夜になった」は届かない |
| 5. すぐに動き直させるか | 結末は `Notable` (すぐに手番が来て動き直せる)。時間帯は `Background` (記憶に入るだけ) | ハルは外へ出たことをすぐ受け取る。夜になったことは次の手番で目に入る |

**どの刺激として届けるか**:

- どちらも世界の知らせ (`AnnouncementStimulus`) にする。居場所に関わらず届き、倒れている人の扱いが今の世界の知らせの決まり (`NoticedLater` でためる) に乗るため。本人の体の刺激 (`BodilyStimulus`) にすると、倒れていても届いてしまい 2. と食い違う
- 結末の知らせの相手は、結末が決まった本人 1 人。文の人のプレースホルダー (`{each_person}`) にも本人を当てる
- 時間帯の知らせの相手は、宣言の `audience` で選ぶ。倒れている人は、選ばれていても相手から外す。ためると、何時間も後に「夜になった」が届き、目覚めたときの時刻と食い違うため
- 目立ち方は作者が書かない。結末は `Notable`、時間帯は `Background` に決まっている (5.)

**採らなかった案**:

- 結末を世界の全員に届ける: 坑道の奥のゲンが、見ていない籠の中のことを知ってしまう
- 時間帯を屋外の場所にいる人に限る決まり: 空の様子を書いた文に合わせた決まりで、「鐘が鳴った」のような屋内でも聞こえる知らせに合わない。どこまで届くかはシナリオによるので、作者が書く
- 気を失っている人に時間帯をためておく: 目覚めたときに古い時間帯が届き、いまの時刻と食い違う
