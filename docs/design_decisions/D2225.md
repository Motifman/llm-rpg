## D2225. 1 tick を 1 巡りとし、動ける人には毎 tick 全員にターンを回す

**何を**: 遊びの進行 (`play_session`) が、誰にいつターンを回し、いつ時間を進めるかを決めた (#2225、親 #2212)。ユーザーと例つきで決めた。

例の場面: 廃坑の山村 v2。ハルは北の坑道へ移動中 (3 tick かかる)、サヨは気を失っている、ゲンは前のターンで「待つ」を選んだ。

| | 決まり | 場面で |
|---|---|---|
| 1. 時間をいつ進めるか | 1 tick を 1 巡りとし、その tick にターンのある人が全員動き終えたら、時間を 1 進める (古い run と同じ) | この tick はミオだけが動き、ミオの行為が確定したら 1 tick 進む |
| 2. 誰にターンを回すか | 毎 tick、動ける人には全員に回す。回さないのは、行っているあいだの人・気を失っている人・死んだ人・世界から外れた人・「待つ」を選んだ人。「待つ」を選んだ人は、目立つ知らせ (`Notable`) が届くか、しばらく経てば起きる。行っているあいだは話すことだけできるので、話しかけられたときにだけターンを回す | ミオにターンが来る。ハル・サヨ・ゲンには来ない |
| 3. 同じ tick の中で誰の行為から確定させるか | LLM の返事が返ってきた順に、世界の入口へ送る。順番は記録に残す | 籠に残る席が 1 つで、ミオとゲンが同じ tick に乗ろうとしたら、先に返事が返ったほうが乗れる |
| 4. いつ止めるか | 世界が終わったら (`WorldHasEnded`) 止める。決めた tick 数でも止める | |

**採らなかった案**:

- 決まった実時間ごとに時間を進める (MMO の実時間): LLM の返事が遅い人がターンを逃し、run ごとに結果がぶれやすい。**今後の選択肢として残す** (ユーザー)。遊びの進行の進め方は差し替えられる形にしておく
- 1 人ずつ順番に動き、1 人動くたびに時間を進める: 人数が増えるほど遅い
- 古い run と同じく、出来事で起こす人にだけターンを回す: 何も起きない人が動かない
- 同じ tick の中を決まった順 (登場人物の並び順) で確定させる: 並び順の早い人がいつも得をする

**決めていない細部**: 「待つ」を選んだ人を起こすまでの長さ、LLM の呼び出しが続けて失敗した人の扱いは、実装の #2232 で決める (D2232)。
