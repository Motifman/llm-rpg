## D2268-17. 耳を澄ます行為を、Being に出す行動の種類から外す

**何を**: 耳を澄ます (`listen`) を、Being に出す行動の種類 (`ActionChoiceKind`) と候補 (`ActionCandidates`) から外す。世界の行為 (`ListeningAttempt`、`Listen`、`ActionKind.LISTEN`) と、シナリオの値 (`action_durations.listen`、`attentive_allowance`、`attentive_bonus`、`action_texts.listen`、`built_in_action_perceptions.listen`) は残す (#2268)。

| | 古い run (`764beb875`) | 新しい世界 |
|---|---|---|
| ツールの一覧 | `listen` がある | 無い。違う (下の理由) |
| 選んだときに起きること | その場と隣の場所の環境音を、本人にだけ観測として届ける (`spot_graph_tool_executor.py` の `_listen`) | 選べない。世界の行為は時間が進むだけで、聞こえ方は変わらない |

- 外す理由: 新しい世界で耳を澄ましても、決まった時間が進むだけで聞こえ方は変わらない。知覚する人はいつも耳を澄ましていない (`attentive=False`) として作られるため。待つのと見分けのつかない行為を「耳を澄ます」と説明して出すと、エージェントは聞こえるものが増えると信じて選ぶ (静かな失敗)
- 世界から消さない理由: 耳を澄ますと聞こえ方が変わる仕組みは、ドメイン (`Perceiver.attentive`、`SoundLoss` の `attentive_allowance`、`StealthRule` の `attentive_bonus`) とシナリオの値まで揃っていて、足りないのは入口だけ。入口をつなぐ作業は #2305 で行い、そのときに行動の種類へ戻す
- ツールの一覧は、毎ターン同じ顔ぶれのまま (D2226)。`listen` は一度も出ない
- 誰も呼ばない `ListeningAttempt` を行動の選択肢にしようとすると、`ActionNotOfferedException` で断る。候補に並べないので、ふだんは通らない

**関連**: Issue #2268、#2305、D2226。
