## D2241. 見えているものを、行動の選択肢の候補と同じ名前で場面の文にする

**何を**: 世界が毎ターン Being に渡す場面 (`Scene`) の文を決めた (#2241、親 #2212)。並び・見出し・言い回しは、エージェントが読む文なのでユーザーと決めた。場面を組むユースケースは `DescribeScene`。ターンごとに呼んで Being に渡す配線は遊びの進行 (#2232) で行い、#2241 の時点では古い run の場面 (`prompt_builder`) は変わらない。

事務所にいるゲンに渡る場面:

```
【現在地と周囲】
鉱山会社の事務所
鉱山会社の事務所。机と帳簿棚が並び、奥の壁際に重そうな金庫が据えてある。屋根の上に古い鐘が吊るされている。
物:
- 金庫: 扉は固く閉じている
- 事務机
行き先:
- 井戸
- 鍛冶場
- 南の横坑口
ここにはサヨがいる。
```

| | 決まり |
|---|---|
| 並び | 見出し「現在地と周囲」の説明 1 つに、場所の名前と説明、「物:」「行き先:」「落ちている品物:」、人の行の順に並べる。無い節は見出しごと出さない |
| 名前 | 行動の選択肢の候補と同じ名前を使う (D2226)。行き先は `VisibleSurroundings.destinations` を場面と候補の両方が使う。物は物の名前、行き先は通路の向こうの場所の名前 (同じ場所へ続く通路が 2 本でも 1 行)、品物は品物の種類の名前で、同じ名前は 1 行にまとめて「×2」と数を添える (`Candidate.count` と同じ)。物は見た目があれば「金庫: 扉は固く閉じている」 |
| 人 | 人の名前を文字にせず、人の穴 (`TextWithPeople`) で渡す。契約の `Description.text` が人の穴を持てるようにした。人の行は `SurroundingsTexts.scene_as_seen` の文 (「ここには{people}がいる。」「{people}が倒れている。」) をそのまま使う |
| 呼び名 | Being が `being/application/names_for_people.py` で埋める。見えている名前 → 見た目 → 「誰か」。呼び方が重なったときの番号は #2240 が上に足す |
| 見え方 | `VisibleSurroundings` の規則 (明るさ・暗がり・見分けられるか) だけで決まる。場面の文の部品はもう一度判断しない。真っ暗 (`SeesNothing`) では場所の説明の代わりに「真っ暗で、何も見えない。」を出す。`NothingInView` (倒れている・移動中など) では「現在地と周囲」を出さない |
| 言い回し | 見出しと決まった言い回しは、シナリオの共通の部品 (`ja_default.yaml` の `surroundings_texts.scene`) に置く |
| 知らせ | `Scene.notices` は空のまま渡す。中身は要るものが出たときに別の Issue で決める |

**採らなかった案**:

- 通路の名前 (「井戸と鉱山会社の事務所の道」) と通路の状態 (「開いている」) を出す (古い run の形): 行き先の候補は場所の名前なので、通路の名前を並べると選ぶ名前と違う名前が増える。閉じた道は、行動の選択肢の「いまはできない」で理由つきで世界から渡る (Being の候補表には出さず、理由は世界の【現在地と周囲】が出す。D2267)
- 世界が人の名前を文字にして渡す: 世界が人の呼び方を決めることになり、Being が呼び名を持つ決まり (D1928) と合わない
- 真っ暗なときに場所の名前も出さない: 自分がどこにいるかは暗くても分かる。行き先も手探りで分かる (`VisibleSurroundings` は通路を明るさで絞らない)

**関連**: Issue #2241、#2212、#2226、#2240、D2226、D1928、#2154。
