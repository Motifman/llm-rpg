## D2271-3. 遊びの進行は Being のターンを毎回終え、終わりに Being を環境から離す。目次と思い出す道具を出す

**何を**: D2271-2 の部品を新しい世界の遊びの進行につなぎ、【思い出せる出来事】と `episode_recall` を古い run と同じく出す (#2271)。調整役とユーザーと決めた。

### 古い run との違い

| | 古い run | 新しい世界 |
|---|---|---|
| 【思い出せる出来事】と `episode_recall` | あり | あり (この変更の前は、目次の区画だけが空のまま出ていて、道具と読み方の行が無かった) |
| ターンの終わり | エージェントの 1 手を処理し終えたときに終える | 遊びの進行が、1 人のターンを終えるたびに終える。LLM の呼び出しが落ちたターンも終える |
| 環境を離れる | run の終わりに、全員の残りを書く | 遊びの進行の `EndPlaySession` が、全員を `LeaveEnvironment` で離す |

### 決めたこと

- **遊びの進行が呼ぶ Being の入口は 2 つ足すだけ**: `end_being_turn` と `leave_environment`。書き起こしの始まりと記憶への取り込みは Being の中で閉じる (D2271-2)
- **ターンは結果を問わず毎回終える**。LLM の呼び出しが落ちたターンや行動を返さなかったターンでは記憶の時計が進まないので、同じターンをもう一度終えることになる。範囲はもう埋まったと記録されているので、二重に書き起こしは始まらない。世界の側の失敗など、ターンの途中で例外が出たときは終えずに例外を上へ伝え、run ごと止まる
- **終わりは `EndPlaySession` で、遊びの進行の外 (run を回す側) が `PlayRounds` のあとに呼ぶ**。世界が終わったか、巡りの上限に届いたか、選べなくなったかを問わず、Being は環境を離れて残りを書く。待ちきれなかった書き起こしは、`MemoryWritingOnThreads.failures()` の `wait_limit_passed` に数える
- **【思い出せる出来事】の区画も、目次を出すとき (`episode_index_shown`) だけ出す**。【メモ】と同じく、作法の文とツールはすでに出し入れしていて、区画だけが見ていなかった (D2271)
