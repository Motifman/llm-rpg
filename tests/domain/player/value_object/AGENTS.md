# 成長値4所有者の試験

この節は `test_base_stats.py`、`test_exp_table.py`、`test_growth.py`、
`test_stat_growth_factor.py` だけを対象とする。他の値型の監査判断を一般化しない。

- 数値成長はBaseStatsとStatGrowthFactor、累積曲線・逆算はExpTable、
  経験値加算・曲線保持・元状態保持はGrowthで直接確認する。
  集約の「増えた」という確認は、正確な値の証明の代替にしない。
- 構築拒否は同じ所有者の表へ追加する。対象以外は正常にし、元の全入力値・型・
  固有例外型・文言を保持する。別のガードで通る拒否行を作らない。
- 元状態の比較には独立した値を使う。同じオブジェクト参照を保存するだけの自己比較を避ける。
- 指定曲線や係数の保持は非既定値でも確認する。戻り値の検査が構築時の別ガードに
  阻まれない入力を選び、内部オブジェクトの同一性を新たに要求しない。
- 公開構築子、公開逆算、数学的な不変条件、意味のある境界は、短いことを理由に削除しない。
  似た値型を共通準備へまとめる前に、所有者・既定値・検証境界の違いを確認する。

判断と元76宣言の保持先は `docs/test_audits/player_growth_value_contracts.md` を参照する。
