## D2268-18. ツールの説明文を、古い run に合わせて世界の宣言に書く

**何を**: Being に渡すツールの説明文を、古い run (mine_v1_002、`764beb875`) の説明に合わせる (#2268)。文は世界の宣言 (`ChoiceDescriptions`) が持ち、`ja_default.yaml` の `choice_descriptions` に書く。【この世界の決まり】の say_inline の行も、ふつうの声の届き方に合わせて直す。

- 説明文は世界が書き、行動の選択肢 (`ActionChoice.description`) で Being に渡す。Being は、そのあとに【現在選べる対象引数】の読み方の一文を足すだけにする。説明は世界の規則 (介抱で戻る HP、倒れてから死ぬまで) を言うので、世界の外の Being に書かせない
- 介抱の説明は、規則の値から埋める。戻る HP は `TendRule` の割合、死ぬまでは `DeathRule.grace` を時間に直した値。tick の数は書かない。昼夜の無い世界は、世界地図と同じく「{turns} ターンぶんほど」と書く。古い run の `world_briefing.py` は「手ぶん」と書いていたが、「手」はこのリポジトリで使わない語なので「ターン」にした (ユーザー)。介抱の無い世界は、介抱できないと書く
- 書けない言い回しは、ツールを組むときではなく、読み込みのときに断る (全種類の説明が揃っていること、埋める名前が合っていること)
- 古い run の説明のうち、新しい世界で偽になる主張は写さない (下の表)

| ツール | 古い run | 新しい世界 |
|---|---|---|
| `travel_to` | スポットグラフ上で接続先へ移動を開始する。say_inline に一言を書ける | 同じ。「スポットグラフ上で」だけ外した (世界の内側の言葉でないため) |
| `set_sub_location` | 現在のスポット内のサブロケーションを変更する (mine_v1_002 には無い) | 違う。区画 (籠など) に出入りする。新しい世界の区画は出入りの宣言で動くため |
| `explore` | 現在のスポットを探索する (シナリオ依存)。say_inline | 同じ。「シナリオ依存」を「世界による」にした |
| `interact` | オブジェクトに操作名で働きかける。前提条件と例。action_name は【現在地と周囲】の各オブジェクト行から読む。追加入力は parameters | 違う。相手に人・持ち物も入る。選べる操作と、いまできない操作は【現在選べる対象引数】に出る (D2268-14)。自分で書く値は details。エラーコード名は書かない |
| `wait` | その場で短く待機し、環境変化や出来事を観測する。say_inline | 違う。気になる出来事が起きるか、しばらく経つまで次の行動を選ばない。新しい世界の待つは、次の巡りを飛ばすため (ユーザー) |
| `listen` | 耳を澄まして環境音を観測する | 出さない (D2268-17) |
| `speak` | whisper / say / shout。say は同じスポットと隣接スポットに届く。発話だけに 1 手を使う | 違う。ふつうの声は同じ場所に中身が届き (D2268-20 で、見える文に押しのけられず届くようにした)、隣には話し声がしたことだけが届く。届け方の名前は新しい世界の候補 (ささやく / ふつうの声で話す / 叫ぶ)。「1 手」は「1 回の行動」にした |
| `use_item` | 消耗品のみ。パン・ポーションの例。say_inline | 同じ。「使い方が決まっている品物だけ」、例は食べ物と薬にした |
| `drop_item` | 地面に置く。スポットを離れても残る。stealth=true でこっそり (mine_v1_002 には無い) | 違う。こっそりの引数は Being に出していないので書かない。燃え尽きる品物は地面でも燃え尽きる。置くところは見られる |
| `pickup_item` | 拾ってインベントリに加える。満杯だと拾えない。stealth=true でこっそり | 違う。こっそりは書かない (同上)。拾うところは見られる。say_inline |
| `give_item` | 1 tick で複数のペアをまとめて渡せる。gives 配列。部分成功 | 違う。1 回に 1 つを、倒れていない人へ渡す。新しい世界の渡すは 1 品ずつのため |
| `tend_to_player` | ダウン状態の仲間を蘇生。HP は最大値の 60%。第三者に SAY として届く | 同じ (HP の割合は規則から埋める)。死ぬまでの時間を足した (ユーザー)。「SAY として届く」は「見られる」にした (新しい世界では見えるものとして届くため) |
| `vote` | 追放する相手に 1 票。会議中だけ。誰が誰に入れたかまで全員に伝わる (mine_v1_002 には無い) | 違う。決めごと一般に 1 票。誰が誰に入れたかが伝わるとは書かない (新しい世界では、同じ場所の人に票を入れたことが見えるだけで、誰に入れたかは伝わらないため) |
| `hold_item` / `put_away_item` | 無い | 新しく書いた。灯りは手に持っているときだけ照らす。手は 2 つ |
| 【この世界の決まり】の say_inline | 同じスポットと隣接スポットに届く | 同じ場所の人に届き、隣の場所には話し声がしたことだけが届く (ユーザー) |
