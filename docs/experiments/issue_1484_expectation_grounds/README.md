# 実 Jev が予期の根拠に選ぶもの (#1484)

過去 run `v4coop_0731_006` (遭難の島、4 人) から、予期とそのとき頭にあった信念・エピソードの組を組み直した。実 Jev に、それぞれが予期の根拠かを問い、その当否を読んで記録した。

当否はまず Claude が付け、清算に回る予期の 142 問のうち 140 問を人が確かめた。23 問で人が当否を直した。数字は人の当否 ([labels_human.json](labels_human.json)) で数える。確かめには [review.html](review.html) を使った (ローカルで開く。結果はブラウザに残る)。

## 組み直し方

- 場面: #1443 の比較 (`docs/experiments/issue_1443_expectation_material/`) と同じ 8 窓、64 手。4 人それぞれの 1〜8 手目と 41〜48 手目
- 予期: 各手の `expected_result` を、その手のターンに書いた予期とした。49 件
- 頭にあったもの: その手の直前の `semantic_passive_recall` / `episodic_recall` の候補から取った。信念 74 件、エピソード 91 件、合わせて 165 問
- 本文: trace に残った抜粋を使った。信念は 60 字まで、エピソードは 120 字まで
- 呼び出し: 予期を書いたターンの清算の呼び出しだけ (形・根拠・場面の問いを 1 回)。49 回で、縮退は 0 回。上限 (12) で外した問いも 0 件
- 閾値: 0.5 (既定)。ちょうどは採らない

```bash
uv run python scripts/expectation_grounds_probe.py judge \
    --run-dir ../../../var/runs/v4coop_0731_006 --port jev \
    --out docs/experiments/issue_1484_expectation_grounds/judgments.json
uv run python scripts/expectation_grounds_probe.py show \
    --judgments docs/experiments/issue_1484_expectation_grounds/judgments.json \
    --labels docs/experiments/issue_1484_expectation_grounds/labels.json \
    --labels docs/experiments/issue_1484_expectation_grounds/labels_human.json
```

当否は問いの通し番号 (予期の並び、予期の中は問うた順) で判定に結びつく。`judge` をやり直すと並びと確率が変わるので、既存の `judgments.json` は `--overwrite` を付けない限り上書きしない。

## 当否の付け方

「この信念やこの出来事がなければ、この予期は持たなかったか」で 3 つに分けた。

- Y: 根拠である。予期の文が、信念の文や出来事の内容をそのまま前提にしている
- N: 根拠でない
- ?: どちらとも言えない。予期の理由になりうるが、無くても同じ予期を持てた

Claude の当否は 165 問すべてで Y が 30、? が 24、N が 111 ([labels.json](labels.json))。人の当否は清算に回る予期の 140 問だけ ([labels_human.json](labels_human.json))。表 [table.md](table.md) に両方を列で並べた。

## 清算に回る予期だけで数える

根拠は確定した予期の当否を返す先なので、清算に回らない予期の根拠は使われない。形の問いで「本人の行動」(3 件) と「予期ではない」(1 件) と判定された予期の 23 問を除き、「清算できる」45 件の 142 問だけで数える。人の当否は Y が 22、? が 3、N が 115、未確認が 2。

| 閾値 | 選ばれた | うち Y | うち ? | うち N | うち未確認 | 拾えた Y |
|---|---|---|---|---|---|---|
| 0.3 | 48 | 22 | 3 | 21 | 2 | 22/22 |
| 0.4 | 33 | 20 | 1 | 11 | 1 | 20/22 |
| **0.5 (既定)** | **19** | **16** | **1** | **2** | **0** | **16/22** |
| 0.6 | 13 | 12 | 0 | 1 | 0 | 12/22 |

未確認は #16 (確率 0.39) と #46 (0.49) で、「選ばれた」には入るが当否の内訳には入らない。

既定の 0.5 で選んだ 19 件のうち、根拠でないものは 2 件だった。根拠である 22 件のうち 6 件を取りこぼし、6 件とも確率 0.33〜0.47 にある。閾値を 0.4 に下げると Y を 4 件多く拾えるが、根拠でないものが 9 件増える。

Claude の当否 (Y 25、? 17、N 100) と比べると、人は「?」のほとんどを N にした。0.5 で選んだ 19 件の内訳は Claude の当否でも Y 15、? 3、N 1 で、閾値の判断は変わらない。

## いつも頭に載るものは選ばれない

Issue が心配していた形は、選ばれていなかった。清算できる予期で、頭に載った回数が 5 回以上の信念・出来事をすべて並べる。回数は ID ごとに数えた。本文が同じでも ID の違う信念は別に数える。比べるため、4 回のうち選ばれた回数が最も多いものを最後に添える。

| 頭に載った | 選ばれた | 誰 | 信念・出来事 |
|---|---|---|---|
| 7 | 0 | リオ | (信念) 干潟で貝を採るのは大型カニの襲撃が危険だ |
| 7 | 0 | リオ | (信念) 山頂への道は川沿いの本道の他に南東から回り込む登り口がある |
| 6 | 0 | リオ | (出来事) 小屋の床板は刃物がなければ開けられない… |
| 5 | 0 | ノア | (信念) エイダは川を遡れば山頂に近づけるかもしれないと言う。 |
| 5 | 0 | ノア | (信念) 救助には山頂の狼煙台で火を上げ、同時に自分も山頂に居る必要がある |
| 5 | 0 | リオ | (出来事) あの廃屋は、机も写真も梁の下も… |
| 4 | 3 | エイダ | (信念) 狼煙台は山頂にあり、点火には流木3本が必要である |

リオの「干潟は大型カニがいて危険だ」は、山頂や狼煙台の予期を書いたときにも頭に載り続けていた。確率はどれも 0.03 で、一度も根拠にならなかった。#1443 までの作りなら、7 回とも当否が返っていた。エイダの「流木 3 本」は、流木の予期のときにだけ選ばれた。

## 清算できると判定された予期にも、予期と言いにくいものが混ざる

「清算できる」45 件を読み直すと、15 件は当たり外れを決める中身を持たなかった。

| 型 | 件数 | 例 |
|---|---|---|
| 確認するだけ | 12 | 「山頂に着き、狼煙台やエイダの状態、流木の配置を確認できる」(ノア)、「エイダの所持品と状況を確認し、流木の受け渡しや協力の条件が整理できる」(リオ) |
| 行動の言い直し | 2 | 「蔓の茂みを詳しく調べて、何かナイフ代わりになるものや手がかりがないか確認する」(カイ) |
| どちらでも当たる | 1 | 「ノアが流木を持って戻ってくるか、あるいは夜明け前の海の様子に変化がないかを観測できる」(エイダ) |

確認するだけの予期は、何が分かるかを述べていないので、行けばほぼ必ず当たる。形の問いの「清算できる」の説明に「できる」が入っているので (design_decisions D1440。行動の結果を落とさないため)、「確認できる」が通る。

15 件は次のとおり。どれに入れるかは Claude の読みで、エイダ tick 110 (「点火できないことを再確認する」) のように、外れうる中身を持つものも含めている。

- 確認するだけ: エイダ tick 6 / 110 / 111、ノア tick 7 / 110 / 112、リオ tick 103 / 106 / 107 / 110、カイ tick 6 / 8
- 行動の言い直し: ノア tick 104、カイ tick 132
- どちらでも当たる: エイダ tick 104

この 15 件のうち 5 件が根拠を持ち、選ばれた根拠は合わせて 8 件だった。清算できる予期で選ばれた 19 件の根拠のうち、半分近くがここにある。たとえばエイダの「リオが流木を何本持っているかを確認し、点火に必要な流木 3 本が揃うかどうかを把握できる」には、「点火には流木 3 本が必要」の信念が 2 件とも根拠に選ばれた。この予期が中身の無い当たりで確定すると、根拠の信念に支持が積まれる。根拠を絞っても、形の判定が甘いと別の経路で水増しが残る。形の問いの見直しは #1489 で扱う。

## 決めたこと

- 閾値は既定の 0.5 のままにする。取りこぼしは、その予期の当否が返らないだけで済む。誤って選ぶと、関係の無い信念に材料が積まれ、悪循環の入口になる。拾える Y の数より、誤って選ばないことを優先する。ただしエピソードを全文で問うた結果ではないので、暫定とする (「限り」を参照)
- 問いの上限は 12 のままにする。この 64 手では、1 回の呼び出しの問いは最大 7 件だった

## 限り

- 当否は清算に回る予期の 140 問を人が確かめた。予期と言いにくいものの型分けは Claude だけが付けた
- 人が確かめた感想: 予期でないもの、予期でも何のために書いたのか分からないものが多い。過去の出来事から立てた仮説を確かめる予期 (「道 A は大型カニが出て危険だった。道 B は安全かもしれない」) はほとんど無く、根拠に選ばれたエピソードも、同じことの繰り返しを予期する材料になっているだけだった
- 予期は昔の `expected_result` (行動の結果を書く欄) から作った。#1441 の `expectations` 引数の書かせ方で書いた予期ではないので、いまの run では予期と言いにくいものの割合が変わりうる
- 本文は trace の抜粋を使った。エピソード 91 件はすべて 120 字で切れていた。信念は最長 34 字で、60 字の切り詰めは効いていない。0.5 で選ばれた 19 件のうち 12 件がエピソードで、根拠でない 2 件もどちらもエピソードだった。本番は全文で問うので確率は動き、どちらに動くかは分からない。人の当否も切り詰めた文を読んで付けた
- 確からしさは trace に無いので、すべて「たぶん」で問うた
