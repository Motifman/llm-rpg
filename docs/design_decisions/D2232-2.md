## D2232-2. 自分の行動は結果として本人に返し、目撃の文と体の観測では届けない

**何を**: 遊びの進行が Being に返す行動の結果 (`OwnActionResult`、D2232 の 8 節) の本文と、世界が本人に届ける知らせを決め直した (#2232、親 #2212)。調整役を通してユーザーと決めた。

それまでの並び (ゲンの【直近の出来事】、1 回目に候補に無い「北の坑道」へ行こうとし、2 回目にカンテラを灯した):

```
- [1 日目 00:00] 「行く」の「行き先」に「北の坑道」は選べない。
- [1 日目 00:30] できた。
- [1 日目 00:30] ゲンがカンテラに火を入れた。
```

結果の「できた。」だけでは何ができたか分からず、自分の行為の目撃の文と 2 行に分かれていた。断られたときは、理由が結果と体の観測で 2 回並んでいた。

| | 決まり | 例 |
|---|---|---|
| 結果の本文 | シナリオの操作で作者が成功の文 (`success_text`) を書いていれば、それを使う。区画の出入りは作者の出入りの文 (`enter_text` / `leave_text`)。組み込みの行為 (移動・耳を澄ますなど) は、共通の部品 (ja_default.yaml の `action_texts`) に行為ごとに書いた文 | 金庫を「1907」で開けると「ダイヤルが噛み合う音がして、金庫の扉が開いた。…昇降機の起動鍵だ。」、耳を澄ますと「耳を澄まし、周囲の音や人の気配を確かめた。」 |
| 行動の要約 | 共通の部品 (`action_texts`) に行為ごとに書き、結果 (`OwnActionResult.action_summary`) に載せる | 金庫を開けると「「金庫」で番号を合わせて金庫を開ける」、井戸へ行くと「「井戸」へ移動した」 |
| 自分の行為の目撃の文 | 行う人には届けない。見聞きした人にだけ届ける | ゲンがカンテラを灯しても、ゲンには「ゲンがカンテラに火を入れた。」が届かない。隣にいたサヨには届く |
| 断られた理由 | 行動の結果にだけ書き、体の観測としては届けない | ゲンが金庫を「0000」で開けようとすると、結果に「扉はびくともしない…」が 1 回だけ並ぶ |

【直近の出来事】の自分の行動の行は、古い run と同じ `[行動] {行動の要約} → [結果] {結果の文}` にする (調整役を通してユーザーと決めた)。行を組むのは Being の側 (#2240) で、世界は行動の要約と結果の文を材料として渡す。

### 古い run に合わせた文面と、合わせられなかったもの

組み込みの行為の文面は、古い run の文 (`action_summary_format.py` の行動の要約と、各ツールの成功の文) に合わせた。古い run に無い行為 (手に持つ・しまう) は同じ調子で書いた。次の 5 つは、世界が持っていない情報が要るので合わせず、application で組み立てることもしない (ユーザーが決めた)。

| 行為 | 古い run | 新しい世界 | 合わせない理由 |
|---|---|---|---|
| 探す | 見つけた物の一覧か「新しい発見はなかった。」 | 「辺りを探した。」 | 結果の文は確定の前に引くので、見つけた物を知らない。見つけた物は観測の行で届く |
| 話す | 届いた人数 (「2 名に届いた」) | 「「…」と言った。」 | 誰に届いたかは、観測を配ったあとにしか分からない |
| 使う (腐った食べ物) | 害を結果の文に書く | 「{item}を使った。」 | 腐り具合と害は効果の側にある。害は体の観測で届く |
| 介抱する | 相手の HP を結果に書く | 「{target}を介抱した。」 | 介抱は数 tick かかり、確定の時点では意識が戻っていない |
| 失敗の対処 (修正のヒント) | 理由ごとの直し方の文 | 付けない | 新しい世界は断りの理由を持つが、直し方の文を持たない。古い run の表は古いエラーコードに付いたもので対応しない |

なお、古い run の「失敗。{理由} 対処: {直し方}」(`result_summary_builder.py`) は本番からは呼ばれておらず、本番の失敗の行は `[行動] … → [失敗] | error_code=… | {理由}` だった。失敗の印を付けるのは Being の行の組み立てで、世界は `OwnActionResult.succeeded` を渡す。

### 世界の側の置き場所 (行為の文)

- 行為の文の宣言 (`ActionTexts`) は、知覚の行と同じ区切りの行 (`ActionTextKey`) ごとに、要約と成功の文を持つ。話す行為は、ささやく・ふつう・叫ぶの 3 行に分ける。区画の出入りと操作の行は、成功の文を作者が書くので、要約だけを持つ。書ける名前 (`{destination}`・`{item}`・`{speech}` など) は行ごとに決まっていて、読み込みのときに確かめる
- 試みが、自分の要約 (`ActionAttempt.summary_in`) と成功の文 (`done_text_in`) を答える。確定した行為は、成功の文と同じく効果の前に要約を引いて返事 (`ActionDone.summary`) に持たせる。断られた行為は、巻き戻した世界で要約を引く
- 世界の案内 (`TurnGuidance`、行為にならなかった) には要約が無い。契約の `action_summary` は None を許す。Being 自身が作る失敗や、要約を足す前の snapshot の結果も None で、Being はそのときいまの形 (結果の文だけ) で出す
- 要約に人の穴があるときは、本文と一緒に、Being が受け取るときの呼び名で埋める (`Observation.with_people_named`)
- 共通の「できた。」(`RefusalTexts.done`) は消した
- 投票は、投票先がある行 (`vote_for`、「「{target}」へ投票した」) と棄権の行 (`cast_ballot`、「投票した」) に分ける (古い run と同じ)。投票先は本人の要約にだけ書き、見ていた人への知らせには出さない。伏せた投票があるため
- 暗がりの誰かに向けた操作が、相手を選ぶ前に断られたときは、相手の名前が無いので、暗がりの相手の行 (`interact_with_someone_in_the_dark`) の要約にする
- 断られたあいだに品物が世界から無くなっていると、品物の名前を引けないので、要約を出さない (None)
- 区画の出入りの作者の文 (`enter_text` / `leave_text`) も、それまで読まれていなかったので、書ける名前 (`{actor}`・`{section}`) を世界の設計の点検で確かめる
- 区画から出る要約は「{section}から出た」とした。古い run は出入りが 1 つのツールで、出入りとも「{行き先の区画}へ位置を移した」だったが、新しい世界は出る先の区画の名前を持たない

### 世界の側の置き場所

- 成功の文は、行為を確定するとき (`CarryOutAction`) に、効果の前の世界から引き、返事 (`ActionDone.done_text`) に持たせる。品物を使い切る操作は、効果のあとでは品物の種類を引けないため。引き方は試みに問う (`ActionAttempt.done_text_in`)。組み込みの行為は共通の「できた。」、シナリオの操作は作者の成功の文を返す
- 成功の文に書ける人の穴は、失敗の文と同じ (`{actor}`、操作に相手がいれば `{target}` など)。それまで成功の文はどこでも読まれておらず、人の穴を確かめていなかったので、世界の設計の点検 (`WorldDesignReview.interaction`) で読み込みのときに確かめる。使えない名前は `UnknownPersonPlaceholderException` で断り、相手のいない操作に `{target}` を書くと設計の欠け (`DesignFlaw`) になる
- 行為の知らせ (`WitnessedAct.stimuli_at`) は、見える刺激と音の刺激に「行う人には届けない」(`withheld_from`) を付ける。届かなかった理由は記録に「自分の行為」(`NotPerceivedReason.OWN_ACT`) で残る
  - 到着の知らせは同じ知覚の宣言 (`PerceptionDeclaration.seen_at`) を通るが、行為の知らせではないので、着いた本人にも届けたままにする
  - 断られた行為を見ていた人への失敗の文 (`failure_seen_at`) も、行う人には届けない
- 断られた行為の体の刺激 (`ActionRefusal.stimuli_at` の本人への刺激) は作らない。共通の規則で断られたときは、周りから見て何も起きていないので、刺激を 1 つも作らない

これで D2216 の「動かない行為では、もとから本人に自分の行為の文が届いている」「動く行為も同じ扱いにする」を改めた (D2216 を直した)。

**採らなかった案**:

- 目撃の文を本人に届けたまま、結果を「できた。」だけにする (それまでのまま): 同じ行為が 2 行に分かれ、行動と結果の対応が読めない
- 結果に目撃の文を使う: 目撃の文は見ていた人に向けた三人称の文 (「ゲンがカンテラに火を入れた。」) で、本人の結果としては読みにくい
- 断られた理由を体の観測に残し、結果は「断られた」だけにする: 理由が試みから離れた別の行になる
