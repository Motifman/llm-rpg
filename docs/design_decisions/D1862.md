## D1862. 本番のプロンプトからタイル用の問い合わせと整形への参照を外す

**何を**: `PromptLimits` と `GetPlayerCurrentStateQuery` からタイル用の設定を外し、
`SpotGraphCurrentStateFormatter` は `spot_graph_snapshot` が無ければ例外で止める。
未使用の `WorldQueryService` の import も外す。タイルマップを消す作業の PR 1。

**なぜ**: 本番は `WorldRuntimeQueryAdapter` を使い、スポットの状態が無ければ
DTO を作らず `None` を返す。タイル用の整形への予備の分岐は使われず、残すと
後続の削除後に存在しないモジュールを読み込む。空の文面で隠すよりも、入口で
不足を知らせる。削除待ちの旧問い合わせは、従来の既定距離 5 で組み立てる。

**どうしないと壊れるか**: この段階では旧問い合わせや整形のモジュール自体は
消さない。パッケージの再公開や旧タイル用の利用側がまだ残るため、後続の PR で
参照と一緒に消す。本番の実行時に使わないことと、起動時に間接的に読み込まれない
ことは区別する。前後のスタブ実験で観測と行動の件数を比較してから進める。
