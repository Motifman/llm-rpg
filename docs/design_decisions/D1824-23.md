## D1824-23. 環境を離れるときのエピソードを、Being の短期記憶から書く

**何を**: run の終わり (`WorldRuntime.write_episodes_on_leaving`) のエピソードの書き起こしを、今の短期記憶のまだ畳んでいない出来事 (`SummarizingShortTermMemory.uncompacted_entries`) からではなく、Being の短期記憶から書く。

| 置き場所 | すること |
|---|---|
| `ShortTermMemory.unsummarized` | 範囲が埋まったときに、いきさつとエピソードの材料として渡していない出来事を返す問い合わせ。いきさつを待っていれば待っている範囲より後、待っていなければ全部。結果を待っている 1 手も、結果の分からない試みとして含める |
| `being/application/write_episodes_on_leaving.py` | `WriteEpisodesOnLeavingCommand` / `WriteEpisodesOnLeaving`。`unsummarized` の出来事を `WriteEpisodes` で書き、`AddEpisodesToMemory` で記憶に加える。行になる出来事が無ければ書き手を呼ばない |
| `application/being/player_episode_writing.py` の `PlayerEpisodeWriting` | プレイヤーの Being と、名前・人格の文・環境を引いて `WriteEpisodesOnLeaving` を呼び、trace `episode_writing` を 1 件残す。今の短期記憶を読む処理は消した |

**なぜ**:

- 範囲が埋まったときの書き起こし (design_decisions D1824-19) と同じ材料から書くため。今の短期記憶は次の段で消す
- 範囲が埋まったときに書いた範囲は、二重に書かない。待っている範囲のエピソードは、範囲が埋まったときに書いている (#1824 で決めた)
- `PlayerEpisodeWriting` は残した。プレイヤーから Being を引くことと、`episode_writing` の trace を残すことは、ゲームの側の仕事で、Being のパッケージには置けない。欄は同じにして、前の run と比べられるようにした

**注意**:

- 待っている範囲のエピソードを書く非同期の処理が、run の終わりまでに記憶に入らなければ、その範囲のエピソードは無い。今の短期記憶から書いていたころは、まだ畳んでいない出来事を全部書いていたので、ここは前より落ちる
  - run の終わりは「離れるときの書き起こし → 非同期の処理を待つ → 結果を反映する → snapshot」の順 (`scripts/run_scenario_experiment.py`)。離れるときは待っている範囲より後しか書かないので、待っている範囲のエピソードは、待って反映するときに入る
  - 入らないのは、待ちが期限に間に合わなかったとき (`async_event_delivery_failed` の `shutdown_timeout`) と、書き起こしそのものが失敗したとき (`handler_failed`、`prepare_failed`、`capacity`) だけ。どれも `async_event_delivery_failed` に残る
  - `episode_writing` に `awaited_until_turn` (まだいきさつを待っている範囲の終わり) を足した。同じ Being の `being_episode_written` と突き合わせると、終わりまでに記憶に入らなかった範囲が分かる
- `episode_writing` の `event_count` の意味が変わった。前は今の短期記憶の出来事の数で、今は Being の短期記憶のまだまとめていない出来事の数。Being を引けないときと失敗したときは None
- `skip_reason: no_events` は、行になる出来事が無かったとき。結果の来ない 1 手だけが残っていれば、`event_count` は 0 でない
- 行になる出来事があるかの判定は、`WriteEpisodesOnLeaving` と `WriteEpisodes` の両方にある。`WriteEpisodes` は行が無いとき空の中身を返すので、書き手が 0 件を返したときと見分けられず、`no_events` を残せないため

**関連**: Issue #1824、#1626、design_decisions D1626、D1824-19、D1824-21、D1824-22。
