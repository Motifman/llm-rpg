# SNSの参照先を作り直した人物へ付け替えない

投稿・返信に作者、返信に親、通知に発信者・受信者・対象の不変識別子を保存する。
同じ整数で別の人物や投稿を作っても、古い内容の意味を変えないための準備である。
表示と現在の閲覧権限の検査は、後続の公開読取へ分ける。

SQLite移行は作者と親をその時点で存在する対象へ一度だけ束縛する。以前の通知は
現在の整数から過去の意味を安全に復元できないため、未束縛のまま保持する。
履歴や既存通知を消して整合したように見せる処理は追加しない。

試験は参照先の整数再利用、欠損時の停止、SQLiteの再接続と移行を検査する。
これはエージェントがSNSを適切に使えたという実モデル評価ではない。
