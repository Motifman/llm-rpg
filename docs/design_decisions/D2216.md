## D2216. 行為の知らせは、効果の前の居場所で、効果の後の場所の様子で知覚する

**何を**: 行為の知らせ (`PersonActedEvent` から作る見える刺激と音の刺激、#2161) にも D2207 の決まりを当てる (#2216、親 #2212)。行為を行った場所 (`at_spot`) は、それまでも効果の前に読んでいた。受け手の居場所だけは効果の後の世界で決めていたので、行為の効果が人を動かすと、その場で見ていたはずの人に知らせが届かなかった。

| 例: 崖の上でハルがゲンを突き落とす (`TeleportEffect(who=Target)` でゲンを下の谷へ移す) | 決まりのもとで |
|---|---|
| 崖の上にいたゲン | 突き落とされた様子 (相手への文) が届く |
| 崖の上にいたサヨ | 突き落とす様子 (見ていた人への文) が届く |
| 下の谷にもともといたアキ | 崖の上の知らせとしては届かず、記録にも並ばない |
| 突き落とされて世界から外れたゲン (`SetOutcomeEffect(who=Target)` も当てる) | 知らせは届かず、記録に「世界から外れた」で残る |

**どこで読むか**: `CarryOutAction` が世界を変える前に、行う人の状況 (`ActorSituation.of`) とは別の値として人ごとの居場所 (`PeopleWhoWereThere.before_the_effect`) を読み、`LatestActions.note` に渡して `PersonActedEvent.present` に載せる。`ActorSituation` は行う人のことだけを持ち、その場にいたほかの人を混ぜない。置き直しの決まり (生きている人・去った人は効果の前の居場所へ。効果で死んだ人・外れた人は `PersonGoneFromThePlace`。効果の前から居場所の無かった人はそのまま) は D2207 のものをそのまま使う。

**行う人自身** (D2232-2 で改めた): 行う人には、自分の行為の知らせを届けない。自分の行為は、遊びの進行が行動の結果として本人に返し、Being の【直近の出来事】に「選んだ行動 → 結果」の 1 行として残るためである。目撃の文も届けると、同じ行為が 2 行並ぶ。動く行為 (移動を始める、崖から飛び降りる) も動かない行為 (ゲンを突き落とす) も同じ扱いで、届かなかった理由は記録に「自分の行為」(`OWN_ACT`) で残る。

それまでは、行う人も効果の前の居場所で自分の行為を知覚していた (崖の上のハルが山道へ移動を始めると、ハルに出発の文が届く。ハルがゲンを突き落とすと、ハルにも「ハルがゲンを崖から突き落とした」が届く)。

**断られた行為** (`ActionAttemptFailedEvent`): `present` を載せない。断られた行為は巻き戻してから別の範囲で記録するので、記録するときの居場所が効果の前の居場所と同じになる。

**到着の知らせ** (`OccupantEnteredSpotEvent`): 届けるときの居場所のまま (`WhoeverIsThere`) にする。着いた先にいる人に届ける知らせで、着いた後の世界で選ぶのが正しい。

**採らなかった案**:

- `ActorSituation` に人ごとの居場所を入れる: 行う人の状況に、行う人でない人の居場所が混ざる (調整役と決めた)
- 受け手を効果の後の世界で選んだままにする (それまでのまま): 突き落とされたゲンに、突き落とされたことが届かない
- 行う人だけは効果の後の居場所のままにする (移動する本人に出発の文を届けない): 自分で崖から飛び降りた人に、飛び降りた文が届かなくなる。のちに D2232-2 で、行う人には自分の行為の知らせを届けないと改めた。飛び降りたことは行動の結果として本人に返る

**決めていないこと**:

- 行為の効果で死んだ人に届かなかったとき、記録に「死んでいる」で残ることは確かめていない。いまの効果には、その場で死なせるものが無い。`DamageEffect` は HP が 0 になると倒れた状態にするだけで、死ぬのは時間が経ってから (`PersonVitals.pass_time`) になる。置き直しは D2207 と同じ部品 (`DeadPerceiver.placed_at`) を通る。効果でその場で死なせられるようになったら、同じテストを足す
