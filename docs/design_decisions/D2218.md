## D2218. 行為と時間を届いた順に 1 つずつ確定させ、世界が終わったあとに届いたものは断る

**何を**: 届いた行為を受け付ける入口 `AcceptAction` と、時間を進める要求を受け付ける入口 `AcceptWorldTimePassage` を作った。世界が終わったかを外側が問う `WorldHasEnded` も作った (#2218、親 #2212)。どの入口も、1 回の呼び出しで 1 つを同期で確定させる。世界が終わったあとに届いた行為と時間を進める要求は、どちらも断る。断っても、世界の状態は変わらない。

例: 廃坑の山村 v2 で全員の結末が決まり、世界が終わった。その直後に、ゲンの「ランプを拾う」が届く。ゲンには、`ActionRefused` の返事が返る。理由は `WorldStateRefusal(GAME_WORLD.WORLD_ALREADY_ENDED)`、文は「世界はもう終わった。」。ランプは地面に残る。断られた試みの記録 (`ActionAttemptFailedEvent`) も残らず、何も配られない。続いて時間を進める要求が届くと、`WorldTimePassageRefused(GAME_WORLD.WORLD_ALREADY_ENDED)` が返る。時計は進まない。

| | 決まり | 例 |
|---|---|---|
| 確定の順 | 入口は 1 回に 1 つを同期で確定させる。届いた順に 1 つずつ呼ぶのも、同時に呼ばないのも、外側が守る | 定員 1 の籠に乗り込む行為がアリス、ボブの順に届くと、アリスが乗り、ボブは `SECTION_FULL` で断られる |
| 行為の流れ | `AcceptAction` は、世界が終わっていないかを確かめる → 行為のユースケースを呼ぶ (その中で確定し、イベントを配る) → `SettleWorldConditions` (コマンドのあと) を呼ぶ → 返事を返す。それぞれ自分の `CommandScope` で動き、範囲は入れ子にならない | アリスが籠に乗ると、「アリスが籠にいる」で鳴る鐘の出来事が発火する |
| 時間の流れ | `AcceptWorldTimePassage` は、世界が終わっていないかを確かめる → `PassWorldTime` → `SettleWorldConditions` (時間のあと) → `WorldTimePassed` | 時間のあとにだけ確かめる偶然の出来事は、時間を進めたときに発火する |
| 断られた行為のあと | `SettleWorldConditions` を回す。断られた試みも `LatestActions.note_failed_attempt` で世界を変えており、条件がそれを見ることがある | 満員で断られたボブの試みのあとにも、条件のそろった出来事は発火する |
| 終わったあとの規則 | `WorldEnding.admit_change` が持つ。終わっていれば `WorldAlreadyEndedException` (`WorldRefusal`) を投げる。入口はそれを受けて返事にするだけ | |
| 終わったあとに断った行為 | 試みを `LatestActions` に記録しない。`CarryOutAction` の断りの経路を通さない。終わった世界を変えないため | ゲンの記憶にも、断られた体の刺激は届かない。返事だけが返る |
| 断りの文 | `RefusalTexts.world_state` から引く。共通の部品 (ja_default.yaml) では「世界はもう終わった。」 | |
| 外側への知らせ | 外側は、断りの返事か `WorldHasEnded` で終わりを知る。行為で世界が終わったときの返事は `ActionDone` のままなので、返事を受けるたびに `WorldHasEnded` を問う | |

**採らなかった案**:

- 終わったあとに届いた行為は受け付け、結末だけ決めない: 結末が決まって世界から外れた人の行為が、記録に紛れ込む
- 終わったあとは時間だけ止め、行為は受け付ける: 行為で世界が変わり、記録と結末が食い違いうる
- 世界の側に待ち行列 (deque) を持つ: 入口は返事を、呼んだ人に直接返せなくなる。返事を受け取る口が別に要る。同期で 1 つずつ呼べば、呼んだ順がそのまま確定の順になる
- 終わったあとに断った行為を `CarryOutAction` の断りの経路に通す: 断られた試みが `LatestActions` に残り、終わった世界が変わる
- 規則を、ドメインの自由関数 (`has_ended()` を問うて投げる) に置く: 規則を外から当てる形になり、tell, don't ask に反する
- `admit_change` に値を返させる: 返す値に意味が無い。`tests/architecture/test_world_aggregates_emit_events.py` の「None を返す公開メソッドは状態を変える」という見分けを避けるためだけの形になる。代わりに、そのテストに `_ADMISSION_CHECKS` の表を足した。表に挙げた呼び方は、断るときに `WorldRefusal` を投げ、中身もイベントも変えないことを確かめる
