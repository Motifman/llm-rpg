## D2207. 出来事の場所の知らせは、効果の前の居場所で、効果の後の場所の様子で知覚する

**何を**: 作者が出来事・二人で合わせる操作に付ける場所の知らせ (`SightAt` / `SoundFrom`) では、どこにいたかを効果の前の世界で決め、場所の様子 (明るさ、通路が開いているか) を効果の後の世界で決める (#2207、親 #2212・#1978)。効果を当てる前に、人ごとの居場所 (`PeopleWhoWereThere`) を発火のイベント (`HappeningFiredEvent.present`、`JointActionCompletedEvent.present`、`JointActionTimedOutEvent.present`) に載せ、知覚するときはその居場所に置き直して刺激に聞く。それまでは受け手を確定した後の世界で選んでいたので、効果が人を動かすと、その場で見たはずの人に知らせが届かなかった (#2195 のテストで確かめた)。

| 例 | 決まりのもとで |
|---|---|
| 崩落: 北の坑道の天井が崩れ、中にいたゲンとアキが入口へ押し出される。北の坑道に「天井が崩れ落ちた」の見える知らせ | 効果の前に北の坑道にいたゲンとアキに届く |
| 同じ崩落の、北の坑道で鳴る音の知らせ | ゲンとアキは北の坑道で聞いたことになり、崩れる音がくぐもらずに届く。入口に元からいたハルには、入口からの聞こえ方で届く |
| 灯り: 真っ暗な発電機室で発電機が回り、灯りがともる。発電機室に「発電機が唸りを上げ、灯りがともった」の見える知らせ | 灯りがともった後の明るさで見るので、その場にいたサヨに見える |
| 崩落で、道のつながらない坑道の奥にいたナツが北の坑道へ押し込まれる | 坑道の奥にいたことになるので、見える知らせは届かず記録にも並ばない。音の知らせは届かず、記録に「遠い」で残る |
| 崩落で、北の坑道にいたケンが埋もれて世界から外れる | 見える知らせでも音の知らせでも、記録に「世界から外れた」で残る |

**居場所の置き直し** (`PeopleWhoWereThere.position`):

- 生きている人・去った人は、効果の前の居場所に置き直す。明るさ・音の届き方・倒れているかは、効果の後の世界のまま
- 効果の前に居場所があり、効果で死んだ人・世界から外れた人は、効果の前の居場所にいたが、知覚できなくなった人 (`PersonGoneFromThePlace`) にする。見える知らせの場所にいた、または音が届いたなら、記録に「死んでいる」「世界から外れた」で残る。音が届かなかったなら「遠い」で残る
- 効果の前から居場所の無かった人 (もう死んでいた人、もう外れていた人) は置き直さない。D2206 のとおり「その場にいない」になり、記録に並ばない
- 記録に残す人の決まり (D2206 の 5.) の「その場にいた」も、効果の前の居場所で判断する

**刺激の側**: 見える刺激 (`SightStimulus`) と聞こえる刺激 (`SoundStimulus`) は、居合わせた人の決め方 (`present`) を持つ。作者の場所の知らせから作る刺激は `PeopleWhoWereThere` を持ち、到着から作る刺激は、届けるときの居場所のまま (`WhoeverIsThere`) にする。行為から作る刺激も `PeopleWhoWereThere` を持つ (D2216)。

**採らなかった案**:

- すべて効果の後の世界で決める (それまでのまま): 崩落の例で、押し出されたゲンとアキに届かない
- すべて効果の前の世界で決める: 灯りの例で、まだ暗いのでサヨに見えない
- 居合わせたかだけを効果の前で決め、聞く人の居場所は効果の後にする: 崩落の真下にいたゲンに、入口からのくぐもった音が届く
- 効果で死んだ人・外れた人は、効果の後に居場所が無いので「その場にいない」として記録に並べない (D2206 のまま): 「その場にいた」の判断が、生きている人は効果の前、死んだ人・外れた人は効果の後、と分かれる

**決めていないこと**:

- 効果で別の場所から入ってきた人 (崩落で北の坑道へ押し込まれた人) を受け手に含めるか。この決まりでは含めない。要るシナリオが出たら決める
- 行為のイベント (`PersonActedEvent`、#2161) の受け手も、効果の後の世界で選んでいたのでずれていた。同じ決まりで直した (D2216)
