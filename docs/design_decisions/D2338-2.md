## D2338-2. 行為の最中は、身体の状態に「いましていること」を終わる時刻つきで出す

**何を**: 行為を始めたときに進行形の文を確定させ、終わる tick と一緒に `PersonVitals` に持たせる (`Busy(until, doing)`)。行っているあいだは、【現在地と周囲】の身体の状態の最後に、その文と終わる時刻を出す (#2338、ユーザーが決めた)。行為の最中に出していた「手が離せない」の行 (D2271-4) の代わり。

探している最中にささやかれて呼ばれたゲン (遊びの進行のテストで作ったプロンプトの全文から):
```
身体の状態:
  HP: 良好（100/100）
  空腹: 問題なし（1/100）、前回 +1
  疲労: 問題なし（2/100）、前回 +2
  いましていること: この場所を探している (Day 1 深夜 1:30 ごろまで)
```

### 決めたこと

- **進行形の文は、行為の種類ごとに 1 つ** (案 A)。共通の部品の `action_texts` に `ongoing` を足す。操作は表示名をそのまま入れる (`「{object}」で「{how}」`)。操作ごとにシナリオへ書かせる案 (B) は、作者の手間が増えるので採らなかった。操作の名前が【選べる操作】の文字とそろう利点もある
- 着いた (arrival) は行為ではないので `ongoing` を持たない。書くと読み込みで断る
- **文は行為を始めるときに確定させて保存する**。行為の要約を効果の前に確定させた `ActionFixedBeforeEffect` (#2327) と同じ考え方で、`ActionFixedBeforeEffect.ongoing` に持たせる。行為の試みそのものは保存されないので、あとから文を作れない
- 行っている最中に始めた行為 (ささやくなど) は、終わりを早めず、していることの文も変えない
- `person_vitals` の保存を版 3 にした。版 2 以前の保存は、読み込みで止める (#2084 の persistence.md「版が合わなければ止め、古い形を直す変換は作らない」)
- 終わる時刻は、場面の現在時刻と同じ `ClockWording` で書く。昼夜の無い世界では時刻を書かず、していることだけを出す
- していることの文に出る人は、場面のほかの人と同じ人の穴 (`doing_<名前>`) で渡す。Being が場面と表で同じ呼び分けを使う (D2338)

### 出ないところ

- 移動中は、世界が場面 (【現在地と周囲】) をまるごと渡さない (`NothingInView`) ので、この行も出ない。移動中の文 (`「{destination}」へ向かっている`) は保存されるが、見せる場所が無い
