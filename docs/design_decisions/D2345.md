## D2345. 行動の「結果」という概念をやめ、【直近の出来事】に行動と観測だけを並べる

**何を**: 自分の行為について本人が知ること (作者の文、断られたこと、着いたこと) を、ほかと同じ 1 行の観測にした (#2345、ユーザーが決めた)。自分の行動は「[行動] 要約」の行だけで出し、`[結果]`・`[失敗] |` は出さない。この節は Being と契約の 1 本目で、世界が本人に渡す文 (言い直しを出さない、断りの文の見直し、着いた文) は続く PR で決める。

ゲンの 1 手 (台本で選ばせた run の抜粋):
```
- [Day 1 深夜 0:30] [行動] 「金庫」で番号を合わせて金庫を開ける
  心の声: 番号を試す。
- [Day 1 深夜 0:30] ダイヤルを合わせて把手を引いたが、扉はびくともしない。
- [Day 1 深夜 1:00] [行動] 「事務机」で引き出しを探る
  呼び出し: interact(target="事務机", how="引き出しを探る")
- [Day 1 深夜 1:00] 引き出しの奥に、黄ばんだ紙切れが挟まっていた。「金庫 1907」と鉛筆で走り書きがある。
```

| | 決まり |
|---|---|
| 契約 | 呼び出し 1 つへの環境の返事は、観測ではなく `ActionTaken(call_id, action_summary, accepted, time, order)`。[行動] の行を描くための「その行動をどう行ったか」で、本人が知ったことは持たない |
| 本人が知ったこと | 経路 `OwnAction` のふつうの `Observation` で届く。`OwnActionResult` と `OwnActionCompleted` の経路は消した |
| 並び | 本人が知ったことは、遊びの進行が行動の返事のすぐ後に渡すので、ほかの観測と同じ並べ方 (ターン → 起きた順) で行動のすぐ後に来る。1 手を選んでいる間に届いた観測は、ターンを終えてから渡される (#2313) ので、その後ろに並ぶ |
| 畳むとき | 短期記憶は、`OwnAction` の観測を、答えのあった 1 手と同じターンに入れる。いきさつに畳むとき、行動とそれについて知ったことが別々の範囲に分かれないようにするため |
| 呼び出しの行 | 通った行動にだけ付ける (#2273)。断られたかは `accepted` で分かる |
| Being の道具 | 思い出した本文、目次を直した文、出していないツールを呼んだ文も、Being が作る `OwnAction` の観測にする |
| 古い世界 | 「[行動] 要約 → [結果] 文」に組み終えた 1 本の本文を、`OldWorldPreformattedLine` (`being/domain/old_world_preformatted_line.py`) で今と同じ行に出す。古い世界を消すとき (#2236) に一緒に消す |
| snapshot | 行動の結果を持っていたころの短期記憶は、読む前に `legacy_action_results.py` が今の形に書き換え、件数を `snapshot_load` の `removed_memory_keys` に `being_short_term_memory.own_action_result` などのキーで残す。要約のある結果は返事と観測に分け、要約の無い結果は古い世界の行にする。あとから届いた結果の要約とツールの名前は捨てる |

- 試みと返事の組 (call_id で 1 対 1、返事を待つ) は残した。返事の型の名前から「結果」を外した (`AttemptResponse`、`AttemptTaken`、`AttemptNotAnsweredYet`)
- 本人が知ったことを返事の欄に持たせる案は採らなかった。名前を変えて結果を残すことになるため (調整役が決めた)
- 本人が知ったことは `TurnRounds` に預けず、遊びの進行が Being に直接渡す。自分の行為に返ってきた知らせで、ターンを回させないため
- 世界は返事と観測に、行為を確定させた tick を起きた順として付ける。これまで結果には起きた順が無く、同じ tick のほかの観測と並べ直されなかった
- 環境が要約を組み立てられなかった 1 手は「[行動]」だけの行になる。これまでは結果の文だけの行だった
