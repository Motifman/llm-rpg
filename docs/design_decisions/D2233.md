## D2233. 新しい世界で起きたことを、受け取って書くだけの trace に残す

**何を**: 新しい世界 (`game_world`) の run で、遊びの進行・世界・Being に起きたことを `trace.jsonl` に書き出す (#2233、親 #2212)。調整役と決めた。

### 書き方の決まり

| | 決まり |
|---|---|
| 誰が書くか | experiment (`src/ai_rpg_world/experiment/`)。遊びの進行・世界・Being は記録のことを知らない (D2226) |
| 取り方 | ドメインの事実がドメインイベントとして出ているものは、そのイベントを受け取って書く。ドメインの事実でないもの (LLM とのやりとり) と、世界に断られて巻き戻された行為は、組み立てるときに差し込んだ口で受け取る |
| kind | `game_world.` を頭に付け、古い世界の kind と混ぜない |
| payload | 名前つきの値だけにする。人は `{"person_id": "gen", "name": "ゲン"}` で書く (古い世界の `player_id` の整数は使わない) |
| 行の tick | 書いたときの世界の tick |

### 1 本目: 遊びの進行

| kind | 元 | payload |
|---|---|---|
| `game_world.round_opened` | `RoundOpenedEvent` | `round`、ターンのある人 (`due`)、飛ばした人と理由 (`skipped`、`TurnSkipReason` の値) |
| `game_world.turn_finished` | `TurnFinishedEvent` | `round`、`person`、終えた順 (`order`)、`outcome` (`acted` / `waited` / `choice_failed`) と `reason` |
| `game_world.round_closed` | `RoundClosedEvent` | `round`。閉じたら時間を 1 進める (D2232) |
| `game_world.observation_passed_on` | `ObservationPassedOnEvent` | `person`、名前を埋めた本文、`route`、`subject_is_self`、`wants_wake`、`addressed_to_self` (分からなければ `unknown`)、時刻の札。考えているあいだに預かった観測は、ターンを終えたあとに出る (D2232 の 10 節) |
| `game_world.choice_discarded` | `WorldEnded.discarded` / `ChoosingKeptFailing.discarded` | `person`、考え始めていたか、落ちた理由、選んだツールと引数 |

- 誰がなぜ起こされたかは、`observation_passed_on` の `wants_wake` と `addressed_to_self` を、次の巡りの `round_opened` と突き合わせて読む
- 同じ tick の中の順番は `turn_finished` の `order` からしか分からない

### 2 本目: 世界の側

| kind | 元 | payload |
|---|---|---|
| `game_world.perception_delivered` | `DeliverPerception` に渡す知らせの届いた記録 (`PerceptionDeliveryReport`) | 原因 (`cause` の型と値)、刺激ごとの感覚・本文・場所・向けた相手、`perceived_by`・`kept_for`・`missed_by` と理由 (`NotPerceivedReason` の値) |
| `game_world.world_event` | 世界が確定させた出来事の配り口 (`CommittedEventsDistributor.register_receiver`) | 出来事の型の名前 (`event_type`) と値。人は名前つき、値が 1 つの値オブジェクトは中の値だけ、数を値にした列挙は名前で書く。通し番号と時刻のスタンプは書かない |

- どちらも登録するだけで、game_world の中は変えていない
- 知らせの届いた記録は、受け取ったらすぐ書いて手放す。run のあいだためると、長い run でメモリが増え続ける
- 世界の出来事を書く口は、知らせを配る口より先に登録する。後にすると、出来事より先に、それが届いた記録が並ぶ
- `ALREADY_PERCEIVED` には、より多くを伝える刺激に差し替えられた場合と、後ろの刺激を試さなかった場合がある (D2268-20)。差し替えかどうかは、同じ行の別の刺激の `perceived_by` に同じ人がいるかで読む
- 世界に断られた行為は巻き戻されて出来事が残らないので、3 本目で Being に結果を渡す口から書く
