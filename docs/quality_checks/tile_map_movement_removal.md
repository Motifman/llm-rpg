# タイル上の移動・追跡・経路探索の削除

Issue #1862 の変更範囲5。スポット移動と追跡の領域・保存形式を維持する。

## テストリスト

- [x] タイル移動の実装と再公開を削除し、参照が残らない。
- [x] 本番のスポット移動・追跡の領域・保存形式・旧問い合わせの関連試験が通る。

- [x] 山村と避難訓練を各シード0〜2・40tickで比較し、全記録種別・観測種別・行動の件数が一致する。
- [x] 変更したPythonのruffとmypyが通る。

接続先スポットのプロバイダは旧問い合わせの試験にも使われるため残す。共通契約と移動例外は一括整理しない。

## 削除の境界と参照解析

削除対象は application/world の移動・目的地・結果組み立て・経路キャッシュ・追跡開始と継続の7サービス、移動の配線、ゲートの受け手、追跡専用例外、domain/world の経路探索・到着・マップ間移動・移動設定の7サービス、infrastructure/world のA*実装と再公開、計19ファイル。

削除前のsrc/tests/scriptsをASTで確認し、対象外の参照は経路探索の再公開1ファイルと専用試験14ファイルだけだった。本番を入口にパッケージの再公開も含めてたどると、経路探索2モジュールが再公開のため読み込まれるが、構築や呼び出しはない。再公開を除去してから実装を消した。

旧シミュレーションから移された追跡継続7件は、タイルの座標と可視物から経路を再計画する専用サービスの試験なので今回消す。追跡の領域、プレイヤーとモンスターの追跡状態、保存形式とスポット移動の試験は残す。

## 質感の所見

本番の移動、到着、モンスターの追跡と観測文には変更を加えない。世界内で知覚できる変化は意図していない。数値比較と関連試験でこの条件での維持を確認する。長時間の実LLMによる質感は未確認とし、今回呼び出さない。

作業ツリーに.envを置かず、検証専用のsitecustomizeでdotenv.load_dotenvを無効化した。smoke_stubは既定の無人島シナリオ・2tickを使い、山村と避難訓練の比較は各シード0〜2・40tickとした。通常のmake fuzz-scenarioに加え、同じrun_random_agentsのNullTraceRecorder.recordを一時スクリプトで収集する。
