## D2267. Being が出す区画を、古い run のプロンプトどおりに再現する

**何を**: #2271 (古い run のプロンプトを新しい世界で再現する) のうち、Being が文にする区画を、古い run (`var/runs/mine_v1_002`) のとおりに出す (#2267)。調整役とユーザーと決めた。

### 現在地の行は Being が書く

古い run の【現在地と周囲】は `現在地: 南の坑道 (初めて訪れた)` の行で始まる。初めて訪れたかは Being の記憶から決まるので、現在地の行は Being が書く。

- 世界は、場面の専用の欄 `Scene.here: Here(place, heading, text)` で渡す。`place` は場所の名前で、訪れた記録の鍵になる。`text` は現在地の行より下の本文 (説明・雰囲気・時刻・接続先・物・人) で、人の穴を持てる
- Being は【現在地と周囲】を、場面のほかの説明より先に、`現在地: {place}` の行と世界の本文で組む。古い run の【現在地と周囲】→【現在選べる対象引数】の並びに合わせるため
- 何も見えないとき (気を失っている、移動中など) は `here` を持たない。Being は【現在地と周囲】を出さない
- `here` の見出しは、場面のほかの説明や知らせの見出しと重ならない

**採らなかった案**:

- 世界が現在地の行まで本文に書き、Being がその行を探して (初めて訪れた) を書き足す: 世界の文の形に頼ることになる
- 世界が訪れた記録を持ち、(初めて訪れた) を世界の文に書く: #2271 で、訪れた記録は Being の記憶として持つと決めた
- 着いたことの観測から現在地を知る: 最初のターンや、snapshot から再開したあとは、着いた観測が届かない
