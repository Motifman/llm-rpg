## D2146. 行為の共通の流れ CarryOutAction

**何を**: 行為のユースケースが共通にたどる流れ (共通の前提 → 行為ごとの前提 → 世界を変える → 断られたら巻き戻して失敗を記録) を `CarryOutAction` に置き、移動と区画の出入りをこの形で作った (#2146、#1978 のステージ 7c)。後続の行為 (#2147〜#2149) はこの形をまねる。

| 何を | 決めたこと | 採らなかった案 |
|---|---|---|
| 行為ごとのユースケースが書くもの | `ActionSteps` の `unmet_precondition` と `change_world` だけ。`change_world` は行っているあいだの長さを返す。移動の長さは道を選んだ後でないと決まらないため | 長さを返す 3 つ目のメソッド。移動では道を 2 回選ぶ |
| 2・3 で断ったときの巻き戻し | application の中だけの例外で `CommandScope` に巻き戻させる。`CommandScope.refusals` に数えるのは集約が断ったもの (`error_code` のあるもの) だけ | 断りを戻り値で返して空の範囲を確定させる。巻き戻しの道が 2 つになる |
| コマンドの中身 | 行為の試み (`StartTravelCommand(attempt: TravelAttempt)`)。流れの 1 (ツール呼び出しを試みに変える) の結果をそのまま受ける | ID を持たせて、ユースケースで宣言を引く |
| 表に無い理由で断られたとき | `RefusalTexts.unlisted` の文を返す。`RefusalCode` は `ActionRefusal` に残るので、表の漏れは trace で追える | `hidden` の流用 (伏せた理由と区別できない)。例外で止める (run が落ちる) |
| 疲れと行っているあいだ | 疲れるのは体を使う行為だけ。行っているあいだは長さのある行為すべてに始める (action.md の action_durations のとおり) | Issue の本文どおり、体を使う行為だけ行っているあいだを始める |
| 去った人の行為 | 疲れず、行っているあいだも持たない (`PersonVitals.start_acting` が死んだ人には何もしない) | 生きていない人への `exert` を例外のままにする。去った人の移動が全部断られる |
| 移動の道 | 開いた通路のうち、通る条件が行う人について真のものだけをたどる。状態では道があるのに通る条件で塞がれたら、その条件の `failure_text` で断る。状態でも道が無ければ `NO_ROUTE` | 通る条件を見ない (condition.md の「通路の条件の理由は届ける」に反する) |

**残したこと**: 移動が途中で塞がれて引き返したとき、行っているあいだが元の到着の時刻まで残る。

**関連**: Issue #2146、#1978、D2053 (`RefusalTexts.world_state` の先送り)。
