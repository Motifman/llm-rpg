## D2268-8. 同じ場所にいる人を、世界の見た状態つきで 1 人 1 行に並べる

**何を**: 古い run の【現在地と周囲】にあった「同じ場所にいるプレイヤー:」の節を再現する (#2268 の 4 本目)。人の行は世界が書く。名前か見た目、倒れているか死んでいるか、疲れの様子、倒れた人の持ち物を、世界の身体の状態と見え方から決める。

古い run (mine_v1_002、ゲン、最初の場面):
```
同じ場所にいるプレイヤー: (倒れていない相手には give_item で所持品を直接渡せる)
  - "ミオ" (初めて会った) [殴りかかる → "strike", 持ち物を奪う (奪う品の名前を item に書く) → "pickpocket"]
同じ場所に居るモンスター: (このスポットにモンスターはいない)
```

| | 決まり | 古い run との違いと理由 |
|---|---|---|
| 人がいないとき | `同じ場所にいるプレイヤー: (他のプレイヤーはこのスポットにいない)` | 同じ |
| 見出しの案内 | `同じ場所にいるプレイヤー:` だけにする | 「(倒れていない相手には give_item で所持品を直接渡せる)」を出さない。【行動の候補】に give_item が、渡せる相手と品物の候補つきで並ぶため (ユーザーが決めた) |
| 人の名前 | 人の穴で渡し、Being が知っている名前か見た目で埋める | 同じ形 (古い run は名前だけ。新しい世界は知らない人を見た目で書く、D1928 系) |
| 「(初めて会った)」 | 出さない | 新しい世界は知らない人を見た目で書くので、初めてかどうかは名前か見た目かで読める。古い run の印は、名前を知らないのに名前で書いたうえで付けていて、読み違えを招いた (ユーザーが決めた) |
| 倒れている・死んでいる | `(倒れて動かない)` / `(死亡している)`。死んでいるほうを先に見る | 同じ (`764beb875` の `spot_graph_ui_context_builder.py:976-990`) |
| 疲れの様子 | 起きている人にだけ、疲れの段階の見た目 (`FatigueLevel.seen_as`) を `(疲れている)` の形で付ける。見た目を書いていない段階は何も付けない | 同じ文と段階 (古い run の `_FATIGUE_DISPLAY`。fatigued 未満は出さない)。古い run はコードの表、新しい世界はシナリオの疲れの段階に書く |
| 倒れた人の持ち物 | 倒れている人と死んでいる人にだけ、手の物も荷の中も `〔縄、ランプの油〕`、何も無ければ `〔手ぶら〕` | 同じ (古い run の 1001-1015 行)。起きている人の荷は見せない |
| 暗くて持ち物が見えないとき | `〔〕` を出さない | 古い run に暗がりの見え方は無い。持ち物が見えないのに「〔手ぶら〕」と書くと、持っていないことと取り違えるため |
| 並び | 起きている人が先、倒れている人と死んでいる人があと | 古い run は近くにいる者の並び順のまま。新しい世界は起きている人と倒れた体を分けて持つ |
| 停滞の様子 | 出さない | 古い run の停滞感の表出 (P-U4) に当たる仕組みが新しい世界に無い |
| 人に対する操作 `[殴りかかる → "strike", …]` | 出さない | 【行動の候補】に寄せる (ユーザーが決めた)。D2268-4 で 4 本目に回した人のいまできない操作も、ここには出さず、操作の案内と一緒に扱う |
| モンスターの行 | 出さない | 新しい世界にモンスターがいない。モンスターのいる世界ができたときに足す |

- 人の状態 (`Up` / `Down` / `Dead`) は `SpotContents.around` が身体の状態と疲れの規則から決め、見えた人 (`SeenPerson`) に移る。場面の文はそれを文にするだけにする
- 疲れの見た目を、疲れの段階の宣言 (`seen_as`) に置いた。古い run の段階 (fatigued / severe / exhausted) は新しい世界の疲れの段階 (60 / 85 / 100) と同じ梯子で、別の表を持つと段階と見た目がずれるため
- 言い回しは `ja_default.yaml` の `scene` に置き、穴の名前をちょうど書いているかを読み込みで確かめる
