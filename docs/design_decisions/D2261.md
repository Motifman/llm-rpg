## D2261. 目次を直すツールを、思い出すツールと同じ形で Being の側に移す

**何を**: 古い run の `episode_revise_index` (D1623-3) を、`episode_recall` と同じく Being の側に移し、新しい世界でも出す (#2261)。

### 古い run との違い

| | 古い run | 新しい Being |
|---|---|---|
| ツールの説明と引数 | `tool_catalog/memory.py` が持つ | `being/application/episode_index_revision_tool.py` に移した。古い run は移した先を使うので、文は 1 文字も変わらない |
| 引数の読み方 (空・文字列でない引数を断る、40 字で切る) | 古い run の executor が持つ | 移した先の `read_index_revision`。古い run の executor もこれを使う |
| 結果の文 | 直した・知らない呼び名・書き方の説明・直せなかった | 同じ文 |
| 直したターン | 世界には行為が無い。結果は観測に写さない (D1623-2) | 同じ。`ChooseAction` が `TurnSpentRevisingIndex` を返し、遊びの進行は世界に何も渡さない |
| 呼び出しの行 | `episode_revise_index(handle="ep_…", about=話題, recall_when=本文)` | 同じ |
| 直したことの記録 | trace の `episode_index_revision` (前と後の目次、切り詰め、断った理由) | 同じ中身を `TurnSpentRevisingIndex.revision` に返す。書き出しは #2233 |
| 出す条件 | 目次を出す設定でいつも出す | 環境が `OfferedBeingTools.episode_index_revision` に名前を入れたときだけ出す。新しい世界は目次と一緒に出す |

### 決めたこと

- **直した結果は、思い出したときと同じく、自分の 1 手の結果として短期記憶に残す**。直せなかったとき (知らない呼び名、書き方の崩れ、エピソードが断った) は、失敗の結果として残す
- **思い出したターンとは別の型 (`TurnSpentRevisingIndex`) を返す**。どちらも世界には行為を渡さないが、直したことの記録 (前と後の目次) を運ぶため
- **直せなかった結果にするのは、エピソードが直しを断ったとき (`EpisodeValidationException`) だけ**。古い run の executor はドメインの例外をすべて捕まえて失敗の結果にしていた。保存の失敗まで「目次を直せなかった」と本人に返すと、本人は自分の書き方が悪かったと読み、同じ直しを繰り返す。保存が落ちたら、ほかの記憶の書き込みと同じく `ChooseAction` ごと落とし、遊びの進行が選べなかったターンとして数える。続けば遊びの進行が run を止める
- **古い run の trace は古い run の executor が今までどおり書く**。Being に移したのは、ツールの形と引数の読み方と文だけ
