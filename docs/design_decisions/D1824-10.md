## D1824-10. 【直近の出来事】を Being の側でも作り、今の文と影で比べる

**何を**: Being の短期記憶から【直近の出来事】の本文を作る (`being/application/recent_events_text.py` の `recent_events_text`)。プロンプトは今の文のまま出し、プロンプトを組むたびに 2 つの文を比べて、違ったときだけ trace (`recent_events_shadow_mismatch`) に残す (`application/being/recent_events_shadow.py`)。fuzz はこの食い違いを穴として数える。切り替える (Being の側の文をプロンプトに出す) のは、食い違いが 0 であることを確かめてから。

文の作り方:

| 出来事 | 行 |
|---|---|
| 見聞きしたこと (`Perception`) | `- [時刻] 本文` |
| 結果のある試み (`Attempt`) | `- [結果の時刻] 結果の本文` と、1 手の心の声があれば `  心の声: …` の続き行 |
| 1 手を出せなかったこと (`Lapse`) | `- [時刻] 本文` |
| 結果の分からない試み | 行にしない |

行の順は集約の `recent()` に従う。出来事の種類は `ExperienceReader` で呼び分け、型を見分けない。

**比べ方**: 出来事の単位 (`- ` で始まる行と、呼び出し・心の声の続き行の塊) で比べる。今の短期記憶が古いターンを畳むまでは、2 つの文が全体で同じかを見る。畳んだあとと、Being の記憶を snapshot から戻した run では、今の文の出来事が同じ順で Being の文に含まれるかを見る (`compared_as` が `whole` / `subsequence`)。戻した Being の記憶は前の run から続くので、今の短期記憶と同じ範囲から始まらない。今の短期記憶はターンの区切りで外すので、外したターンの行動の結果は消え、その行動が起こした次のターンの観測 (「カンテラの灯を入手しました」など) は残る。時刻の順に並べると、残った行は Being の文の末尾にならず、途中が抜けた形になる。Being の側は `fold` をまだ呼ばないので、外したあとの文どうしは同じにならない。

2026-10-25 に fuzz (mine_village_v1 と station_drill、各 20 シード × 40 tick、でたらめに行動するスタブ。普段の設定と全部入りの profile の両方) で比べたとき、食い違いは 0 件だった。各 5 シードで数えると、全体の比較は 400〜800 回、畳んだあとの比較は 360〜656 回あった。

**同じ行動の繰り返しへの警告**: 環境からの知らせ (`EnvironmentNotice`) として写す。主体は自分、送り手は分からない。警告を出すかどうかは環境 (ゲーム) が行動の履歴から判定し、エージェントの外から届くため。今のプロンプトにも出来事の 1 行として出ている。

**退けた案**:
- 繰り返しの警告を Being の内側の記録として持つ: 警告を作るのは Being ではなく環境なので、Being の記録としては由来が合わない。出来事の型をもう 1 つ足すことにもなる
- 結果の分からない試みを行にする: 今の文に無い行なので、比べると食い違いになる。出すかどうかは切り替えるときに決める
- 影の比較を、今の文が Being の文の末尾と同じかで見る: 上の理由で、畳んだあとは末尾にならない
- 畳んだときに Being の側でも同じターンまでを忘れる: 外す規則は `fold` (いきさつが届いたときに外す) と決まっていて、それと別の外し方を足すことになる

**比べないもの**: 公開 SNS の投影 (`public_sns_projection`) がある世界では比べない。投影は観測の構造の情報で並べ替え、Being の側はその情報を持たないため。比べなかったことは Being ごとに 1 回だけ trace に残す。
