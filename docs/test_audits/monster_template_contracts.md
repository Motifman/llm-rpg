# モンスター定義の気質適用と温度設定を検査する

## 目的

`MonsterTemplate` と周辺の値オブジェクト7試験ファイル、89宣言を読み直した。
既定値、入力拒否、識別子の等価性、報酬や成長段階の公開値には独立した役割が
あるため、全宣言を保持する。修理は気質適用6宣言と温度設定2宣言に限定する。

基準は `ba942f5a9cad4b6d362c9e2ce59566cc8ce3396f`。

## 気質の6項目を、明示済みの値にも適用する

`apply_temperament` は反応、逃走猶予、逃走閾値、追跡距離、追跡時間、探索時間を
まとめて上書きする公開の作成補助関数である。元の試験は既定テンプレートだけを
入力し、一部の結果を検査していなかった。

- WARY以外の逃走閾値0、COWARDの追跡時間0、WARYの逃走猶予3を検査へ追加する
- 元の既定入力を残し、6項目を明示した入力も同じ6宣言に通す
- 数値0を未指定扱いする誤りと、既定値と一致する設定の上書きを省く誤りを検出する

期待値は公開設定を直接記述し、製品の私有プリセット表から生成しない。
全気質の適用成功、他の値の保持、元オブジェクトの不変性、適用後の個別変更、
異なる気質の結果の独立性は、それぞれ既存の主担当試験に残す。
適用成功の試験だけで、内部の初期化処理が再実行されたと断定はしない。

設定束を公開関数で適用する設計と、私有値を返す試験用関数を撤去した経緯は、
[導入変更](https://github.com/Motifman/llm-rpg/commit/d3cee04076357c05eb3b184a8d478d8344d7ef56)と
[レビュー対応](https://github.com/Motifman/llm-rpg/commit/99934480ce9ad4bb28078454fa48f04625c953e2)にある。

## 温度設定を受理した後の値も検査する

構築に成功するだけだった2宣言に、公開値の確認を足す。

- COLD〜WARM・被害量2の入力をそのまま残し、3つの設定値を保持することを検査する
- NORMALだけが快適・被害量1の入力をそのまま残し、設定値と、NORMALは快適、
  COLDは寒すぎ、WARMは暑すぎという判定を検査する

温度設定の既定値、逆順や型違いの拒否、両端を含む範囲、被害量0による無効化は
元の試験を保持する。[導入変更](https://github.com/Motifman/llm-rpg/commit/ac83b4f3a3a07559c4df1c51acda6a82aadd7dc2)が
設定と判定の契約の根拠である。

## 保持する主担当

- `test_growth_stage.py`: 13宣言。時刻・倍率・逃走補正・追跡可否・4段階上限
- `test_monster_id.py`: 3宣言。個体IDの正数・負数拒否・等価性
- `test_monster_template_id.py`: 3宣言。定義IDの正数・負数拒否・等価性
- `test_reward_info.py`: 4宣言。報酬値・ゼロ値・戦利品ID変換・負数拒否
- `test_monster_template.py`: 42宣言。文字列・視野・技能・生態・成長段階・飢餓・寿命・追跡設定
- `test_monster_temperament_preset.py`: 11宣言。気質の公開適用と設定の保持
- `test_monster_template_temperature.py`: 13宣言。温度比較軸・設定・不快判定

保存復元、温度によるHPと通知、追跡上限の実行は関連試験が別の故障を検査する。
これらを設定の全入力検査の代わりにはしない。関連試験の42件は今回の89宣言へ
重複計上しない。製品コードと共通の規則ファイルは変更していない。

## 検証

- 未編集基準: 所有89宣言の展開94件と関連42件、計136件成功
- 修理後と変異復元後: 所有100件と同じ関連42件、計142件成功
- 5種類の一時変異を所有7ファイルだけで比較し、旧94件では成功、修理後は意図した確認で失敗
  - 逃走閾値0を元の値へ戻す: 10件失敗
  - 逃走猶予3への上書きを省く: 1件失敗
  - COWARDの追跡時間0への上書きを省く: 2件失敗
  - 正の温度被害量を1へ丸める: 1件失敗
  - 一点の快適範囲をWARMまで広げる: 1件失敗
- 温度被害量の丸めは関連SQLite・温度実行試験でも検出される。ここでの比較は
  値オブジェクトの主担当にあった局所的な見逃しを示し、全体で未検出とは主張しない
- 一時変異した製品ファイルを全て元のバイト列へ復元し、SHA256一致を確認
- `ruff 0.16.8` の対象2ファイル検査、`git diff --check` は成功

安全な局所試験では対象作業木の`src`を読み、通信を禁止し、資格情報を除去した。
リポジトリ全件の試験はこの局所検証には含まれない。
