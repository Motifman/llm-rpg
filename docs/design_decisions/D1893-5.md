# D1893-5: 廃止した記憶の宣言だけを旧snapshotから取り除く

Issue #1893に従い、MemoryKindからSEMANTICを外す。旧snapshotの`declared_memory_kinds`にある`semantic`は、ファイルとSQLiteで共通に使うBeingSnapshotCodecで読み飛ばす。他の未知値を無視すると破損した宣言まで通るため、従来どおり例外にする。現役のSHORT_TERM / EPISODIC / MEMOの値、Beingの同一性と所属は変えない。

これは記憶本文の移行とは別の判断であり、`memory_payload_json`と既存の削除キー表には触れない。ファイル復元では保存前にcodecで宣言を検証し、廃止済みの宣言だけを取り除く。除去した宣言は出現数で数え、記憶本文の件数とは別に報告する。SQLiteの表・列・migrationは保ち、読み取り時に宣言を移行する。既存行を一括更新する方法ではファイルを扱えず、不要なDB変更も伴うため採らない。
