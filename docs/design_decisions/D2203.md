## D2203. 結末の知らせは本人に、時間帯の知らせは作者が書いた相手に届ける

**何を**: 作者が書く結末の知らせ (`OutcomeDeclaration.announcement`) と時間帯の知らせ (`DayPhaseDeclaration.announcement`) を、誰に、どの刺激として届けるかを決めた (#2203、親 #1978)。どちらも `PersonOutcomeDecidedEvent` と `TimeOfDayChangedEvent` が知覚に流さない一覧 (`NOT_PERCEIVED_EVENT_KINDS`) に入っていて、誰にも届いていなかった。廃坑の山村 v2 では、「ハルは昇降機で外へ出た」も「日が落ち、夜になった」も本人に届かない。実装は #2204 で行う。

例の場面: 夕方、ハルとサヨが籠に乗って昇降機が上がる。ゲンは坑道の奥にいて、アキは倒れて気を失っている。

| | 決まり | 例 |
|---|---|---|
| 1. 結末の知らせの受け手 | 結末が決まった本人だけに届ける | ハルには「ハルは昇降機で外へ出た」、ゲンには「ゲンは坑道に取り残された」が届く。ゲンに、ハルの結末は届かない。籠が上がる様子は、作者が出来事の知らせに書いて周りに伝える |
| 2. 気を失っている人の結末 | 目が覚めたときに、ほかのたまった知らせと同じく届ける (#2195 の `MissedNotices`) | アキは起きたときに「アキは坑道に取り残された」を知る |
| 3. 時間帯の知らせの受け手 | 作者が知らせごとに届く相手を書く。書き方は出来事の知らせ (`announcement_to`) の人の選び方 (`audience`、`PeopleSelection`) と同じ。書かなければ、起きている全員に届ける | 廃坑の山村 v2 では「空が白み、朝になった」に「屋外の場所にいる人」と書き、坑道の奥のゲンには届かない。「鐘が鳴り、夕刻を告げた」なら書かずに全員へ届ける |
| 4. 気を失っている人の時間帯 | 届けず、ためもしない。目が覚めたときの場面で分かれば足りる | アキが朝に目覚めても、「夜になった」は届かない |
| 5. すぐに動き直させるか | 結末は `Notable` (すぐに手番が来て動き直せる)。時間帯は `Background` (記憶に入るだけ) | ハルは外へ出たことをすぐ受け取る。夜になったことは次の手番で目に入る |

**どの刺激として届けるか**:

- どちらも世界の知らせ (`AnnouncementStimulus`) にする。居場所に関わらず届き、倒れている人の扱いが今の世界の知らせの決まり (`NoticedLater` でためる) に乗るため。本人の体の刺激 (`BodilyStimulus`) にすると、倒れていても届いてしまい 2. と食い違う
- 結末の知らせの相手は、結末が決まった本人 1 人。文の人のプレースホルダー (`{each_person}`) にも本人を当てる
- 時間帯の知らせの相手は、宣言の `audience` で選ぶ。倒れている人は、選ばれていても相手から外す。ためると、何時間も後に「夜になった」が届き、目覚めたときの時刻と食い違うため。相手を選んだ tick のうちに倒れた人もいるので、届けるときにも倒れている相手にはためない (`kept_while_fainted`)
- 目立ち方は作者が書かない。結末は `Notable`、時間帯は `Background` に決まっている (5.)

**あとから決めたこと** (文書を書く中で決まりに無いと分かり、調整役を通してユーザーが決めた):

| | 決まり | 例 |
|---|---|---|
| 死んだ結末 | 死んだ結末 (`Died`) には結末の知らせを出さない | ゲンが坑道で死んでも、結末の知らせは無い |
| 世界から外れた人 | 結末の知らせだけは、結末が決まって世界から外れた本人にも届ける。居場所の要らない受け手として扱う。外れた後の時間帯の知らせは届けない | ハルは外れた後でも「ハルは昇降機で外へ出た」を受け取る。その夜の「日が落ち、夜になった」は届かない |
| 気を失ったまま外れる人 | 世界から外れるときに、気を失っている間にたまった知らせと結末の知らせを、目が覚めたときと同じ順で渡す。表の 2 の「結末は後で必ず本人に届く」を保つため | アキは気を失ったまま「取り残された」に決まって外れ、そのまま世界が終わる。外れるときに、それまでにたまった知らせに続けて「アキは坑道に取り残された」を受け取る。目覚めていないので、「目が覚めた」の知らせと場面は渡さない。結末の知らせをためてから渡すため、`PersonOutcomeDecidedEvent` を刺激に変えて届ける受け手 (`CommittedEventsDistributor` の receiver) が、たまった知らせを渡すハンドラ (`DeliverNoticesOnLeavingHandler`) より先に動くことに頼る (#2204、配線は #2206) |
| 「起きている全員」の範囲 | 死んで去った人として動く人と移動中の人には届ける。結末が決まって外れた人には届けない | 夜になったとき、去ったゲンと、峠を移動中のサヨには届き、外へ出たハルには届かない |
| 屋外の場所にいる人 | いまは屋外の場所を `any_of` で並べて書く。屋外かを問う条件は、要るシナリオが出たら足す。並べた場所で選ぶので、移動中の人には届かない | v2 の朝の知らせは、屋外の場所 5 つを並べる。峠へ移動中の人には朝が届かない |
| 1 人に 1 つの決まりとの重なり | 「1 つの確定の範囲から 1 人に 1 つ」で数えるのは、同じものを別の感覚で知る刺激 (本人の体・見える・聞こえる) に限る。世界の知らせ (結末、時間帯、作者の `announcement_to`) は数えず、ほかと重なっても届く | `lift_leaves` の発火で、ゲンには籠の音と「ゲンは坑道に取り残された」の両方が届く。同じ tick の「腹が減ってきた」と「日が落ち、夜になった」も両方届く |
| 明るさの知らせとの重なり | 重なってよい。明るさが変わったときの「辺りが暗くなった」と、作者の時間帯の文の両方が届く。作者の文が明るさに触れないこともあるので、明るさの文は別に要る。重なりが気になれば作者が文を直す | 屋外の人には、夜になると「辺りが暗くなった」と「日が落ち、夜になった」の両方が届く |
| 時間帯の相手を選ぶところ | 刺激に変える役 (`StimulusTranslator`) が、その tick を進め終えた世界から、宣言の人の選び方で相手を選ぶ (D2330 で改めた。初めは `PassWorldTime` が時計を進めるときに選んでイベントに載せていた) | 朝になった tick の終わりに、屋外の場所にいて倒れていない人を選ぶ。その tick に飢えで倒れた人には届かない |

**採らなかった案**:

- 結末を世界の全員に届ける: 坑道の奥のゲンが、見ていない籠の中のことを知ってしまう
- 時間帯を屋外の場所にいる人に限る決まり: 空の様子を書いた文に合わせた決まりで、「鐘が鳴った」のような屋内でも聞こえる知らせに合わない。どこまで届くかはシナリオによるので、作者が書く
- 気を失っている人に時間帯をためておく: 目覚めたときに古い時間帯が届き、いまの時刻と食い違う
- 結末の知らせだけを `always_delivered` にする / 結末と時間帯の知らせを `always_delivered` にする: 作者の `announcement_to` など、ほかの世界の知らせは押し出されたままになる。世界の知らせを数えない形にすれば、種類ごとに例外を足さずに済む
- 作者の時間帯の文がある変わり目では、明るさの知らせを出さない: 作者の文が明るさに触れるとは限らず、暗くなったことが伝わらなくなる
