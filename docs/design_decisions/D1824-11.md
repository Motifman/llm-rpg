## D1824-11. 古いターンは、いきさつが届いたときに外す

**何を**: 短期記憶の集約 (`ShortTermMemory`) の `fold` と `add_backstory` を、2026-10-24 にユーザーが決めた形 ([#1824 のコメント](https://github.com/Motifman/llm-rpg/issues/1824)) にする。

| 振る舞い | すること | ためるイベント |
|---|---|---|
| `fold`: 範囲が `RECENT_TURNS` (20) に届き、まだ頼んでいない | 古い `FOLD_TURNS` (10) ターン分 (最初ならターン 10 まで) のいきさつを頼む。出来事は外さない | `FoldRequested` (範囲の出来事、今のいきさつ、範囲の終わり)。いきさつのハンドラとエピソードの書き起こしのハンドラが受ける |
| `fold`: 頼んでから `BACKSTORY_RETRY_TURNS` (10) 過ぎても届かない | 同じ範囲のいきさつを頼み直す | `BackstoryRequestedAgain`。いきさつのハンドラだけが受ける |
| `fold`: 範囲が `FORCED_FOLD_TURNS` (40) に届いた | いきさつを待たずに古い 10 ターン分を外し、続けて次の範囲を頼む | `FoldForced` (外した出来事)。trace に残す |
| `add_backstory`: 今のいきさつより後の範囲まで | いきさつを入れ、まとめた範囲までの出来事を外し、範囲の始まりを進める。頼んだ範囲まで届いたら頼みごとを済ませる | 無し |
| `add_backstory`: 今のいきさつと同じか前の範囲まで | 入れない | `StaleBackstoryDiscarded`。trace に残す |

外す範囲に、選んだまま結果の来ない 1 手があれば、結果の分からない試みとして一緒に外す (材料のイベントにも入る)。

いきさつ (`Backstory`) は、まとめた範囲の終わりのターン (`until_turn`) を持つ。集約は、届くのを待っている頼みごと (`BackstoryRequest`。範囲の終わりと、頼んだターン) を持ち、snapshot に入れる。

**なぜ**: いきさつを作る LLM の呼び出しは裏で走り、結果は次のターンの始めに入る (design_decisions D1837 の 4)。先に外すと、いきさつが届くまで、外した 10 ターン分が【直近の出来事】にも【ここまでのいきさつ】にも無くなる。

- 頼み直しをいきさつだけにするのは、同じ範囲のエピソードを 2 回書き起こさないため
- 頼み直しても範囲を変えないので、先に届いたいきさつが入り、遅れた同じ範囲は捨てればよい
- 上限 (40) は、いきさつが作れないまま【直近の出来事】が伸び続けないため。今の本番で要約が失敗したときに要約無しで外すのと同じ振る舞い
- 頼み直すまでのターン (10) は、上限まで待つ間に 1 回頼み直せる長さ

**足す前の snapshot**: 短期記憶の payload のキー (`being_short_term_memory`) は変えず、中の欄を足した。足す前の payload に欄が無ければ、頼みごとは無し、いきさつは書いたターンまでをまとめたものとして読む (`_memory_payload_codecs.py`)。ADDED_PAYLOAD_KEYS (design_decisions D1824-6) は payload のキーを足したときの手当てなので使わない。本番ではまだ誰も `add_backstory` を呼ばないので、いきさつを持つ snapshot は無い。書いたターンを範囲の終わりとみなすのは、いきさつが書いたときより後をまとめることは無いため。

**退けた案**: #1824 のコメントのとおり (外した出来事を別の場所に持つ、空白を受け入れる、エピソードの側で範囲を覚える)。

**まだしないこと**: `fold` はまだ誰も呼ばない。イベントのハンドラと、保存するときにイベントを配送器に渡す配線は次の PR。

**その後 (design_decisions D1824-17)**: 決まり (範囲の大きさ、待つ長さ、上限で外すこと) は変えずに、名前と形を CLAUDE.md の「コマンド・ユースケース・ドメインイベント・ハンドラ」に合わせた。

| この判断の名前 | 今の名前 |
|---|---|
| `fold(current_turn)` | `end_turn(turn)` |
| `BackstoryRequest(until_turn, requested_turn)` | `AwaitedBackstory(until_turn, since_turn)` |
| `FoldRequested` | `ShortTermMemoryRangeFilledEvent` |
| `BackstoryRequestedAgain` | `ShortTermMemoryBackstoryOverdueEvent` |
| `BACKSTORY_RETRY_TURNS` | `BACKSTORY_OVERDUE_TURNS` (10 のまま) |
| `FoldForced` | `ShortTermMemoryOldestTurnsDroppedEvent` |
| `StaleBackstoryDiscarded` (イベント) | ドメイン例外 `ShortTermMemoryStaleBackstoryException`。イベントは出さない |
| (無し) | `ShortTermMemoryBackstoryAddedEvent` |

**関連**: Issue #1824、design_decisions D1824-9、D1837。
