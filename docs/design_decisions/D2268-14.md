## D2268-14. いまできない操作を場面の物の行から外し、行動の候補にまとめて渡す

**何を**: D2268-4 で【現在地と周囲】の物の行の下に出していた「いまできない:」を外す。いまできない操作は、行動の候補 (`ActionChoice.unavailable`) で Being に渡し、Being が【現在選べる対象引数】の対象の下にまとめて出す (#2268、ユーザーが決めた)。表に出すのは Being の側 (#2240) の受け持ち。

```
- interact.how ("南の坑道の水門"):
    いまできる:
      "水門に油を差す"
    いまできない:
      "水門を開ける"（把手が錆びついて動かない）
```

| | 新しい世界 | 古い run との違いと理由 |
|---|---|---|
| いまできない操作の置き場所 | 【現在選べる対象引数】の対象の下 (Being が出す) | 違う。古い run は物・人・持ち物の行の下に出していた。できる操作は【現在選べる対象引数】、いまできない操作は【現在地と周囲】と別の節に散ると読みにくいので、1 か所にまとめる (ユーザーが決めた) |
| 出す操作 | 物・人・持ち物の、いまできない操作すべて | 古い run は物の状態か数で断られた操作を物の行の下に出し、ほかは操作の案内に残していた。まとめる場所が 1 つになったので、理由で分けない |
| 伏せる印の付いた操作 | 条件を満たさないあいだ、いまできないにも出さない | 同じ (D2268-4 のまま) |
| 【この世界の決まり】 | 操作の選び方の行に「いまできない操作は、【現在選べる対象引数】の「いまできない:」に理由とともに出る。」を足す | 違う。置き場所が変わったため |

- 世界は、物の状態か数で断られた操作を、場面に出すために行動の候補から外していた (`AvailableActions.offered_as_choices`)。この除外をやめ、すべて `ActionChoice.unavailable` に入れる。道筋は今の候補と同じ並び (interact なら 対象, 操作)
- 物の状態の条件かどうかの印 (`FailureReason.about_object_state` と条件の `is_about_object_state`)、物のいまできない操作の型 (`UnavailableObjectOperation`)、場面の言い回し (`unavailable` ほか 3 つ) は、使う場所が無くなったので消した
- マージの順: Being の側の PR (#2240 の実装役、【現在選べる対象引数】にいまできないをまとめる) を先にマージし、そのあとにこの変更をマージする。プロンプトから、いまできない操作がどこにも出ない時期を作らないため

**関連**: Issue #2268、#2271、#2240、D2268-4、D2268-12。
