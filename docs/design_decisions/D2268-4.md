## D2268-4. いまできない操作を物の行の下に出し、条件で切り替わる操作は条件を満たさないあいだ伏せる

**何を**: 古い run の【現在地と周囲】にあった、物の行のすぐ下の「いまできない」の行を再現する (#2268 の 2 本目の続き)。古い run がそれと組で使っていた「条件を満たさないあいだは候補ごと伏せる」印を、操作の宣言として足す。

| | 決まり | 例 (廃坑の山村 v2) |
|---|---|---|
| いまできない行 | 物の行のすぐ下に `      いまできない: {操作}（{理由}）` を「、」でつないで 1 行で書く。言い回しは `ja_default.yaml` の `surroundings_texts.scene` | 釣瓶の水が尽きると `  - "井戸の釣瓶" — 滑車に掛かった古い釣瓶。` の下に `      いまできない: 水を汲む（釣瓶は空のまま上がってきた。…）` |
| 出す理由 | 物の状態か数を見る条件 (`ObjectValueIsCondition`・`ObjectCountAtLeastCondition`・`ObjectCountGreaterThanCondition`・`ObjectStockAtLeastCondition`) で断られたときだけ出す。条件の型が `is_about_object_state` で答え、断られた理由 (`FailureReason.about_object_state`) が「かつ」「または」を通して引き継ぐ | 金庫を開けたあと (旗の条件)、缶を持っていないときの「燃料の缶を注ぐ」(持ち物の条件)、行っているあいだ (共通の決まり) は出さない |
| 出さない理由で断られた操作 | 行動の候補の `unavailable` に残す。5 本目で作る物の行の操作の案内 `[…]` に、選べる操作として出す (古い run と同じ)。5 本目が入るまでは場面に出ない途中の状態 | |
| 伏せる印 | 操作の宣言に `hidden_while_unmet` を置く。付いた操作は、自分の条件を満たさないあいだ、ほかに断る理由があっても候補ごと伏せる (場面にも行動の候補にも出ない)。既定は付けない | 山村 v2 の水門の開ける・閉じる (3 か所) と、閂の掛ける・外す (2 か所) の 10 の操作。閉じている水門には「水門を開ける」だけが出る |
| 人への操作 | 4 本目で人の行の下に出す。それまでは、Being の候補表が「いまはできない」を出さない (#2267) ので、理由はプロンプトに出ない | |

- `not` で包んだ物の状態の条件は引き継がない (出さない)。古い run に否定の形の状態の条件は無く、出すものを広げないため。「または」は、すべて偽の子のどれかが物の状態の条件なら引き継ぐ (文は「または」自身の文)。山村 v2 の操作には、どちらの形も無い

### 古い run がそうしていた理由 (一次情報)

- 物の状態・数の条件だけを「いまできない」に回す: `764beb875` の `src/ai_rpg_world/application/world_graph/spot_graph_current_state_builder.py:266` `_interaction_blocking_hints`。docstring に、`HAS_ITEM` は「他の表示や remediation と重複するため物体行では出さない」(持ち物は所持アイテムの欄で分かる)、`AT_SPOT_IS` は「物体の action 候補はその物体が在るスポットでしか表示されないので、場所を添えても常に自明」とある。状態・数の条件は「現在失敗している場合だけ failure_message を添え、action 候補自体は残す。候補集合を消すと存在しない操作名の発明につながるため」
- 伏せる印: `764beb875` の `src/ai_rpg_world/domain/world_graph/value_object/interaction_def.py:78` `hide_when_flag_preconditions_fail`。「世界フラグを解禁条件に使う操作を、不成立中は候補ごと伏せる。既定では失敗理由つきで残すため、時限ギミックのように操作の存在自体がまだ世界に現れていない場合だけ明示する」。判定は `src/ai_rpg_world/application/world_graph/hidden_interaction_filter.py:176`
- 「いまできない」の行: `spot_graph_ui_context_builder.py:824` (物の行の下に `      いまできない: …`)

### 古い run との違い

- 古い run の伏せる印は、旗の条件を満たさないときだけ伏せていた。新しい世界の印は、操作の条件 (旗に限らない) を満たさないときに伏せる。新しい世界の条件は旗・物の状態・持ち物などを 1 つの木で書くので、旗の部分だけを取り出す形にしていない。山村 v2 で印を付けた 10 の操作は、条件が旗だけなので、結果は古い run と同じになる
- 古い run の「いまできない」は `{操作} → "{識別子}"（{理由}）` だった。識別子は、物の操作の案内と一緒に 5 本目で足す
