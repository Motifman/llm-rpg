## D2231. Being が選んだ行動を、名前から行為の試みに戻して確定させる

**何を**: Being が選んだ行動 (`AgentMove`) を受け取り、行為の試みに戻して確定させる入口 `TakeChosenAction` を作った (#2231、親 #2212)。名前から試みに戻すのは、ゲームの世界の仕事にした。その人に何が見えているかを知っているのは世界だけだから (D2226)。引数の形と行動しながらの一言は、#2240 と調整役と決めた。

例: 事務所にいるゲンが、「金庫 / 番号を合わせて金庫を開ける / 1907」を選ぶ。

- 届く `AgentMove`: `tool_name="interact"`、`arguments={"target": "金庫", "how": "番号を合わせて金庫を開ける", "code": "1907"}`
- 世界は、いまできる行為の一覧から、金庫への `open_safe` の試み (番号はまだ無い) を選び、番号 1907 を入れて確定させる
- 金庫が開き、ゲンは起動鍵を受け取る。返事は `ActionDone()`
- 番号が 0000 なら、前提で断られる。返事は `ActionRefused` で、文は作者が書いた「ダイヤルを合わせて把手を引いたが、扉はびくともしない。」。同じ文が、断られた試みの記録 (`ActionAttemptFailedEvent`) から、本人の体の刺激として観測で届く

### 1. 引数の形

| 値 | 形 | 例 |
|---|---|---|
| 選択肢の道筋 (`PickOne` の連なり) | 値の名前ごとに平らに並べる。値の名前は、世界が `ActionChoice` に付けた名前のまま | `target`、`how`、`reach`、`to` |
| 文字の候補 (行き先・物・品物・操作の名前) | 名前の文字 | `"井戸"`、`"番号を合わせて金庫を開ける"` |
| 人の候補 | 人の印 | `{"person": 3}` |
| 操作の宣言にある引数 | 道筋と同じ段に平らに並べる | `"code": "1907"` |
| 話す中身 | 道筋と同じ段 | `"content": "金庫の番号を知っているか"` |
| 行動しながらの一言 | 道筋と同じ段の `say_inline` | `"say_inline": "少し休もう"` |

- LLM のツールの書式 (`details` のまとまりなど) は Being が外して返す。世界は知らない
- 道筋に合わない名前の引数は読まない
- シナリオの引数の名前に `say_inline` を使うと、`target`・`how` と同じく読み込みで止める (`DesignFlaw`)

### 2. 試みへの戻し方

| | 決まり | 例 |
|---|---|---|
| 照らし合わせる相手 | いまできる行為の一覧の試みを、行動の選択肢と同じ道筋 (`offered_as`) にして、引数と照らし合わせる。「いまはできない」試みも照らし合わせる | 金庫が開いたあとに「番号を合わせて金庫を開ける」を選ぶと、試みとして確定に回り、「金庫の扉はもう開いている。中は空だ。」で断られる |
| 同じ名前の品物 | 世界が一覧に並べた順で先のものを使う | 3 つあるカンテラの油を置くと、持ち物の並びで先の 1 つが置かれる |
| 値を書く | 文字の値は空白だけなら書いていないことにする。品物の引数は、候補の名前で選び、同じ名前なら先のものを使う。試みは自分で値を受け取る (`chosen_with`) | |
| 戻せないもの | 確定させず、`TurnGuidance` (人、文、時刻) を返す。観測にはしない。世界に何も起きない | 下の表 |
| 振り分け | 試みが、受け取る入口 (`ActionEntrances`) の自分の口を呼ぶ。application 層は試みの型を見分けない | |

案内の文:

| 場合 | 文 |
|---|---|
| 選択肢に無いツール名 (Being が止めるので、ふつうは届かない) | 「「fly_to」という行動は無い。」 |
| その行動で選べるものがいまは無い | 「いまは「拾う」で選べるものが無い。」 |
| 道筋の値を選んでいない | 「「行く」の「行き先」を選んでいない。」 |
| 場面に無い名前 | 「「行く」の「行き先」に「北の坑道」は選べない。」 |
| 場面にいない人 | 「「話す」の「相手」に選んだものは、いま選べない。」 人の印は内部の番号なので、文に戻さない |
| 書く文字が無い | 「「code」に書く文字が無い。」 |
| 一言を添えられない行動に添えた | 「「話す」には一言を添えられない。」 |

### 3. 行動しながらの一言

- ふつうの声で話す 2 つ目の試みにする。主の行為のあとに確定させる
- 主の行為が断られても出す。主の行為が案内になったときは出さない
- 返事は主の行為のものだけを返す。一言が断られた理由は、観測で届く
- 添えられる行動は、古い run に合わせる。話す・耳を澄ます・投票するには添えられない (`ActionChoiceKind.takes_inline_speech`)
- 空白だけの一言は、添えなかったことにする

### 4. 待つ・耳を澄ます

一覧には並ぶのに、受けるユースケースが無かった。最小の `Wait` と `Listen` を足した。前提は持たない。待つことは行っているあいだを作らない (`WorldRules` の決まり)。耳を澄ますことは、シナリオの行為の長さのあいだ行っていることになる。耳を澄ましたときに何が聞こえるかは、知覚の側で別に決める。

**採らなかった案**:

- 試みの型ごとの振り分けを application 層の対応表 (`type(attempt)` から入口) で持つ: 型で見分ける形になり、`tests/architecture/test_game_world_application_keeps_rules_in_domain.py` が見張る決まりに反する
- 操作の宣言にある引数を `details` で受け取る: LLM のツールの書式が世界に入り込む。書式を変えるたびに世界のコードを直すことになる
- 一言を主の行為の返事に混ぜる (「(添えた発言は届かなかった)」を足す): 断られた理由は観測で届くので、返事に重ねると同じことを 2 回伝える
- 場面にいない人の印を案内の文に出す: 印は内部の番号なので、エージェントに見せない
