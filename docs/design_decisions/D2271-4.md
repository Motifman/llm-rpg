## D2271-4. 【現在選べる対象引数】を引数ごとの段の形にし、いまできない候補を理由つきで同じ見出しの下に出す

**何を**: 【現在選べる対象引数】の、候補から選ぶ引数の行を「いまできる: / いまできない:」の段の形にそろえ、世界が渡す「いまはできない」(`ActionChoice.unavailable`) を、その候補が属する見出しの下に理由つきで出す (#2271)。ユーザーと調整役が決めた。

### 古い run との違い

| | 古い run | 新しい Being |
|---|---|---|
| 候補から選ぶ引数の行 | `- interact.target_label: "ミオ", "カンテラ"` の 1 行 | 見出し `- interact.target:` の下に「いまできる:」を置き、候補を 1 つ 1 行で並べる |
| いまできない候補 | 出さない | 同じ見出しの下の「いまできない:」に、`"名前"（理由）` で 1 つ 1 行 |
| いまできないものが無い見出し | — | 「いまできる:」だけを出し、「いまできない:」は出さない |
| いまできる候補が無い見出し | 行を出さない | いまできないものがあれば見出しを立て、「いまできる:」に「(なし)」と出す |
| 行動ごといまできないもの (行為の最中の探す・待つなど) | 出さない (古い run は行為の最中に頼まなかった) | `- explore: いまできない（手が離せない。今していることが済むまで待つしかない）` の 1 行 (#2268) |
| 自由に書く値の行 | 無い | 今までどおり `- interact.details.code ("番号を合わせて開ける"): 金庫の番号を書く` の 1 行 |
| 最後の注意書き | 「※ 一覧にあることは操作の成功を保証しない。…」 | 「※ 引数には「いまできる」の "" の中の文字をそのまま書く。「いまできない」は、（）の理由があるあいだは選んでも断られる。」を前に足す |
| ツールの説明 | — | 「候補のある引数には【現在選べる対象引数】の「いまできる」の文字をそのまま書く。」 |

### 決めたこと

- **候補から選ぶ引数の行は、すべて同じ段の形にする**。引数ごとに形が違うと、どちらの書き方で選ぶのかを読み分けさせることになる。いまできないものが無い見出しにも「いまできる:」を出し、見出しの有無で形が変わらないようにする
- **いまできない候補は、選べたなら選んだはずの見出しの下に置く**。金庫の「開ける」は `interact.how ("金庫")` の下、通れない行き先は `travel_to.destination` の下に出る。理由の句点は外して全角の丸括弧に入れる
- **契約の `UnavailableAction` に、道筋の最後の名前がどの引数の候補か (`argument`) を持たせる**。金庫の操作がどれもいまできないと、金庫は対象の候補に並ばないので、候補の並びからは置く見出しを決められない。1 つの段に候補から選ぶ引数が 2 つある行動でも、どちらの引数かが決まらない。世界は、道筋の最後の段の値の名前を入れる
- **行動ごといまできないもの (`picked` が空) は、行動の名前を見出しにした 1 行で出す** (#2268、ユーザーが決めた)。はじめは置く見出しが無いので出していなかった。すると、行為の最中に呼ばれた人には探す・待つが選べるように見え、選んで断られ、断られた結果が短期記憶に残った。形は `- explore: いまできない（理由）` で、理由の書き方は候補のいまできないとそろえる (末尾の句点を外して全角の丸括弧に入れる)。理由が複数あれば、渡された順に 1 つ 1 行で出す。引数のある行動 (travel_to) が行動ごといまできないときは、引数の見出しを立てずこの 1 行だけになる。ツールの一覧は毎ターン同じままで、変わるのは候補表だけ
- **いまできない候補に出る人も、番号の呼び分けに数える**。表に同じ見た目の人が 2 人出るので、番号が無いとどちらか分からない。理由の文にだけ出る人は、今までどおり数えない。いまできない候補に出る人を足すと、同じ見た目の人の番号が変わることがあるが、表と、書かれた名前を人に戻すところは同じターンの同じ呼び分けを使うので、名前が別の人に化けることは無い
- **いまできない名前を書いたら、Jev に選び直させず、そのまま世界に渡す** (表記の崩れだけは直す)。選び直しの候補はいまできるものだけなので、問えば別のいまできる候補に寄せられ、エージェントは断られる理由を受け取れない。世界が理由を付けて断る。いまできない名前かどうかは、同じ親の候補の下で見る。別の対象の下に書いた同じ名前は、今までどおり選び直しに回す。操作がどれもできず候補に並ばない対象 (物置) を書いたときも、選び直さずに渡し、その下に書いた操作の名前も、いまできない道筋の名前に表記を合わせる
- いまできない名前かどうかは、親の候補と名前の組で見て、引数の名前までは見ない。道筋の途中の名前には、どの引数の候補かが渡らないため。同じ親の下に候補から選ぶ引数が 2 つあり、同じ名前が別の引数でいまできないときにだけ取り違えるが、今の世界にその形の行動は無い
