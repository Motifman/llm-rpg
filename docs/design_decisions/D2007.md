## D2007. 時刻・天候・段階・集団の決定・終わりの集約と、中身の無かった型

**何を**: 世界の進み方の集約 `WorldClock`、`Weather`、`WorldStage`、`GroupDecision`、`WorldEnding` と、昼夜・天候の宣言を作った (#1978 の段階 3)。文書に中身が無かった型と、文書から決まらなかった振る舞いを、ユーザーと調整役と次のように決めた。

| 型・振る舞い | 決めたこと |
|---|---|
| `WeatherType` | 固定の列挙 8 種 (`CLEAR` / `CLOUDY` / `RAIN` / `HEAVY_RAIN` / `SNOW` / `BLIZZARD` / `FOG` / `STORM`)。既定の表と「書かなければ嵐と霧」を書けるようにするため |
| `WeatherState` | 種類だけ持つ。強さを読む所が文書に無い |
| `WeatherTransitions` | 今の天候ごとの、次の天候と重みの表。`roll` は `Probability`。既定の表は古いコードの `TRANSITION_WEIGHTS` |
| `Visibility` | 作らない。知覚は `obscures_sight` だけを読み、使う所が無い。`world_design.md` からも消した |
| `TimeOfDay` | 1 日の中の tick の位置 |
| `TimeOfDayChangedEvent` の前後 | `DayPhaseName`。`WorldStageChangedEvent` が `WorldStageId` を持つのと揃える |
| 今と同じ値への `Weather.change` / `WorldStage.enter` | 何もせず、イベントも出さない。遷移表で同じ天候が選ばれるのは普通で、同じ段階へ入る効果がもう一度発火しても世界を止めない |
| `NoAnnouncement` | `declaration/time_and_weather` に置く。ステージ 4 の出来事で共有が要れば動かす |
| `GroupDecision.start` | 開いているうちは断る。集計して閉じたら、新しい票でやり直せる |
| 空の投票する人・候補 | 断る |
| 抜けた人 (`withdraw_voter`) の票 | 数えない。倒れた人の票で決まらないようにする。全員抜けたら票の無い集計で `GroupDecisionUnresolvedEvent` |
| `abstain_allowed` が偽の棄権 | 断る |
| 開いていない決定への `close`、いない人・開いていない決定への `withdraw_voter` / `withdraw_choice` | 何もせず、イベントも出さない。状態が変わらない操作は断らない (world_state.md、#2011)。全員が投じて集計された後に締める出来事が発火したり、倒れてから死んだ人が 2 回外されたりしても、`CommandScope` ごと巻き戻らないようにする |
| 終わった世界への `WorldEnding.end` | 断る (Issue のとおり)。終わった世界はもう進まず、終わりの判定は 1 tick に 1 回なので、出来事の当て直しには当たらない |
| `withdraw_choice` で候補が 0 人になったとき | 開いたままにする。棄権できる決定なら棄権だけを受け、`close` で `GroupDecisionUnresolvedEvent` になる。棄権できない決定は `close` を待つ |

**実装で決めたこと**:

- 昼夜の段階の名前は重ならない (`DayPhaseNameDuplicatedException`)。`TimeOfDayChangedEvent` は名前で前後を持つので、同じ名前が 2 つあると変わったことを見分けられない。夜をまたぐ 1 日は、最初の段階より前の時刻を前の日の最後の段階として扱うので、同じ名前を 2 回書かずに済む
- 天候の宣言に、見通しの悪い天候の集合 `obscuring` を足した。「書かなければ嵐と霧」の既定は読み込む側が埋める
- `display_name` は `DisplayName` を返し、種類ごとに決まった日本語の呼び名にした
- `WorldTickAdvancedEvent` も前後の tick を持つ
- `ChoiceWithdrawnEvent` は、票を戻された人 (`returned_to`) を持つ。投じ直してもらう知らせに使える

**関連**: Issue #2007、#1978、#1975 のコメント「ステージ 3 の前に決めたこと」。
