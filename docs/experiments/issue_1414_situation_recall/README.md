# 状況の欄で引いた信念と、いまの cue で選んだ信念を並べる (#1414)

> `scripts/situation_recall_probe.py` と、それが呼んでいた状況の項目から引く想起は、#1631 の #__PR__ で消した。この記録の再現手順は、いまのコードでは動かない。

過去 run の想起の場面を組み直し、実 Jev に「次のターンの想起で残す欄」と「体の帯」を問い、
状況の欄で引いた 3 件 (新) と、いまの cue で選んだ 3 件 (旧) を並べた。

このページには 3 回分の結果がある。最初の 2 回は、項目を Jev に選ばせていた、いまはやめた形 (design_decisions D1414-8) の記録で、項目を「欄」、体の具合を「帯」と呼んでいた当時の言い方のまま残している。

- **5 問の形** (#1490 の形): 欄ごとに「残す / 捨てる」を問う。結果は `results_five_questions.json`。
  「結果」から「近似と限界」までの節はこの形の数字
- **1 問の形** (#1494 と #1495 のあと): 「次の判断にいちばん効く欄はどれか」の 1 問の確率の上位 2 つを
  採り、欄の値を Jev に見せる。メモ・記憶の道具の応答は「いま起きたこと」に入らない。結果は `results.json`。
  末尾の「1 問の形で回し直した結果」の節にまとめた
- **全部の項目を 1 本で引く形** (design_decisions D1414-8): Jev に項目を選ばせず、6 つの項目の値を全部
  つなげて 1 本で引く。Jev は呼ばない。結果は `results_plain.json`。末尾の「全部の項目を 1 本で引く形」の節

- 素材: `var/runs/v4coop_reasonfirst_003` (4 人、プロンプト 639 回)
- 場面: 人ごとに、連続 10 回のプロンプトを 1 窓。信念が 10 件以上ある場面のうち、体の危険を表す語が
  観測に多く出る窓を選んだ。計 40 場面
- Jev: 本番の清算と同じ state と問い (残す欄 5 問 + 体の帯 1 問) で、1 場面 1 回。同じ場面を 3 回問うて、
  計 120 回
- 引く側: 本番と同じ `SituationBeliefRecall` (2 字組の BM25) を手元で回した
- 再現: 5 問の形は、コミット 482c437c の `scripts/situation_recall_probe.py` で
  `--run-dir <run> --out results_five_questions.json`。いまの probe は新しい形で問う

## 分かったこと

1. **この形の問いでは、Jev は欄をほとんど捨てない**。残す確率は場面によって動く (自分の状態は
   0.51〜0.92、相手は 0.27〜0.75) が、ほとんどが 0.5 を超え、捨てたのは「相手」の 5 場面だけ。
   値が空の「未解決のこと」(この run には予期が無い) も 0.7 前後で残した。清算の state には直近の
   出来事の時系列はあるが、組み立てた欄の値は入っていない。「残す / 捨てる」の 5 問を独立に問うと、
   どれも残す側に寄る。Jev が欄を使い分けられないのか、問いの形が悪いのかは、この結果では
   分けられない
2. **同じ 3 件の繰り返しは、状況の欄で引く方式全体で減った**。特定の欄のおかげではない。
   「いま起きたこと」を抜いて引いても、同じ 3 件が続けて並ぶのは 4/36 で、旧の 16/36 には戻らない。
   連続する 2 回の重なり具合も、旧 0.66 に対して新 0.24、この欄を抜いても 0.27。この欄は 3 件を
   大きく動かす (抜くと 40 場面すべてで 3 件が変わる) が、繰り返しが減った主な理由とは言えない
3. **「いま起きたこと」に雑音が入っている**。メモ機能の応答 (「メモを追加しました（ID: ccd325…）」) や
   「【心の声】」が、自分の行動の結果や観測として入る。環境の出来事ではなく、ID のような文字列も含む
4. **体の帯は、この run では矛盾なく読めた**。カイがメモに書いた「空腹 82/100 (危険域)」から「危機」と読み、
   他人の空腹の話しか無いノアの場面では「分からない」と答えた。危機はカイの 5 場面に集中している。ただ、いまの信念の文に帯の語が無いので、帯の文で
   体に関わる信念は引けていない。#1454 の書き込み時のキーに帯の語が入ってから効く想定どおり

## 次にやること (提案)

ユーザーの判断で、次の 3 点を直す。

1. **欄の問いに、いまの欄の値を見せる**。清算の state に、そのターンの終わりの状況の欄を足す
2. **欄の選び方を、1 問の選択肢の確率で上位を採る形に変える**。「次の判断にいちばん効く欄はどれか」を
   1 問だけ出し、選択肢ごとの確率の上位 2 つを残す。閾値は持たない
3. **「いま起きたこと」から、メモ機能の応答と【心の声】を外す**。エージェント側の道具の出力で、
   環境の出来事ではない
4. 体の帯は、#1454 で書き込み時のキーに帯の語が入ってから、効くかを見直す

## 近似と限界

- 場面の時点の信念は、run の終わりの snapshot の信念のうち、trace に ID が最初に現れた時刻
  (または `created_at`) が場面より前のもの。snapshot の `created_at` は信念を改めると更新されるため
- この run には予期の仕組みが無いので、「未解決のこと」は空。目的も入れていない
- 欄を 1 つ抜く比較と「全部の欄」の比較は、帯を付けずに組んだ。そのため「自分の状態」は体の状態の
  観測が無い場面では空で、「未解決のこと」も空。この 2 欄を抜いても 3 件が変わらないのは、欄が
  効かないからではなく、欄が空だから
- 候補の信念は run の終わりの snapshot から組んだので、途中で消えた信念や統合された信念は入らない。
  旧の 3 件の ID はすべて snapshot にあったが、旧と新で候補の集合がそろっている保証は無い。旧と新の
  重なり (0.42) には、この差も混ざる
- 40 場面は 1 つの run の 4 人 × 連続 10 回で、窓は体の危険の語が多いところを選んだので、独立ではない。
  同じ場面を 3 回問うたのも独立ではなく、「3 回とも同じ」は Jev の答えがほぼ決まっていることを示す
  だけ。結論はこの run・この窓での話
- snapshot に欠けていた値は既定値で埋めた (確からしさ 0.5、重要度 5)
- 「やろうとしていること」の内心は、直近 1 件の行動のもの (本番の取り方と同じ)
- 旧の 3 件は trace の `semantic_passive_recall` の記録そのもの。新の 3 件は手元で計算したもの
- 費用: Jev の decision API は課金額を返さないので、金額は測れていない。120 回、state は平均 1,760 文字

## 1 問の形で回し直した結果

同じ 40 場面を、#1494 と #1495 のあとの形で回し直した (実 Jev 120 回、縮退 0 回、1 回 0.19 秒)。
素材の run の古い「【心の声】」は probe の側で外した。

| 見たもの | 5 問の形 | 1 問の形 |
|---|---|---|
| 選んだ欄 (120 回) | 相手 105、ほかの 4 欄はすべて 120 | やろうとしていること 109、いま起きたこと 116、自分の状態 15、相手 0、未解決のこと 0 |
| 選んだ欄の組 (40 場面) | ほぼ全部の欄 | やろうとしていること + いま起きたこと 34、自分の状態 + いま起きたこと 4、自分の状態 + やろうとしていること 2 |
| 確率 (1 位 / 2 位 / 3 位 の平均) | (欄ごとの二択) | 0.67 / 0.26 / 0.05 |
| 同じ場面を 3 回問うて同じ欄 | 40/40 | 37/40 |
| 全部の欄で引いた 3 件と違った場面 | 1/40 (相手を捨てた 5 場面のうち 1 つ) | 6/40 |
| 同じ 3 件が続けて並んだ割合 | 0/36 | 1/36 (旧 16/36) |
| 旧と重なった件数 (3 件中) | 0.42 | 0.47 |
| 危機・注意の場面の枠で、体に関わる信念が載った件数 | 旧 16 / 新 13 (48 枠) | 旧 16 / 新 11 (51 枠) |
| 「いま起きたこと」にメモ機能の応答が混ざった場面 | 14/40 | 0/40 |

### 分かったこと

1. **Jev は欄を選び分けるようになった**。値が空の「未解決のこと」は一度も選ばず、「自分の状態」を選んだ
   6 場面のうち 5 場面は帯が危機か注意だった。答えが揺れた 3 場面は、どれも「自分の状態」を選ぶかどうかの
   境目だった
2. **ただ、載る 3 件はほとんど変わらない**。全部の欄で引いた 3 件と違ったのは 6/40 場面だけ。欄の選び方を
   変えても、引く側の結果に届いていない。理由は 2 つと見ている
   - 「いま起きたこと」の値は長い文が 3 つで、問い合わせ文の大半を占める。2 字組の BM25 では、短い欄
     (相手の名前、帯の文) を足しても抜いても点がほとんど動かない
   - 2 つ目に採る欄の確率がとても低いことが多い。ノア (プロンプト 100) では 1 位の「いま起きたこと」が
     0.87 で、2 位の「やろうとしていること」は 0.06 (しかも値が空)。上位 2 つを固定で採るので、効かない欄が
     枠を取る
3. **体の帯はまだ効いていない**。カイの危機の場面で「自分の状態」(体の状態は危機) を 1 位に選んだが、
   いまの信念の文に「危機」の語が無いので、体に関わる信念は引けない。危機・注意の場面で体に関わる信念は、
   旧 16 → 新 11 と、かえって減った。#1454 で書き込み時のキーに帯の語が入るまでは効かない想定どおり
4. **同じ 3 件の繰り返しは、ほぼ無くなったまま** (旧 16/36 → 1/36)

### 次に考えること (提案)

- **欄ごとに引く**: 残した欄をつなげて 1 本で引くと、長い欄が点を決める。欄ごとに別の一覧で引いて混ぜずに
  持てば、欄を選んだことが結果に届く。これは #1414 の「平均に寄るので 1 本にしない」と同じ問題が、欄の中で
  起きている
- **採る数を確率で変えるか**: 1 位が大きく抜けているときに 2 つ目を採るかどうか。閾値を持たない決まり
  (design_decisions 234) との兼ね合いを決める必要がある

## 全部の項目を 1 本で引く形

項目の選択と体の具合の判定をやめ (design_decisions D1414-8)、2 字組が改行や記号をまたがないように直した
あと (design_decisions D1414-7) で、同じ 40 場面を引き直した。Jev も LLM も呼ばない。

- 再現: `uv run python scripts/situation_recall_probe.py --run-dir <run> --out results_plain.json`

| 見たもの | 旧 (いまの cue) | 全部の項目を 1 本で |
|---|---|---|
| 同じ 3 件が続けて並んだ割合 (人ごとの連続 10 回、36 組) | 16/36 | 2/36 |
| 続けての想起の 3 件の重なり具合 (連続する 2 回の Jaccard の平均) | 0.66 | 0.29 |
| 旧と重なった件数 (3 件中、40 場面の平均) | — | 0.45 |
| 何も載らなかった場面 | 0/40 | 0/40 |
| 場所を抜いて引いても上位 3 件が同じだった場面 | — | 30/40 |
| 体の危険の語が「いま起きたこと」にある 32 場面の 96 枠で、体に関わる語を含む信念が載った件数 | 26 | 16 |

体の危険の語と体に関わる語は、`situation_recall_probe.py` の `_DANGER` と `_BODY_BELIEF` の正規表現で
数えた。1 問の形の表の「危機・注意の場面」は Jev の判定で選んだ場面なので、この行とは母集団が違い、
比べられない。

### 分かったこと

1. **場所の名前は点をほとんど動かさない**。場所を抜いて引いても 30/40 場面で上位 3 件が同じだった。長い問い合わせ文の中で場所の名前は数文字しかない。場所を入れた検索と抜いた検索の 2 本をやめた根拠
2. **同じ 3 件の繰り返しは少ないまま** (16/36 → 2/36)。項目を選ばなくても、状況の項目で引くこと自体で減る
3. **体が危ない場面で、体に関わる信念は旧より減る** (26 → 16)。旧は見えているものの名前 (貝、焚き火など) で
   引くので、食べ物や治療の信念が載りやすかった。新は「いま起きたこと」の長い文が点を決めるので、体の
   語が 1 つ入っても押し負ける。体の具合の判定の文を足しても、信念の文に同じ語が無いので引けなかった
   (1 問の形の節の 3)。直すなら、信念を書くときの手がかり (#1454) か、語に分ける手法への差し替えで
   比べる
