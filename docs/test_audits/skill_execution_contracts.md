## 実呼出経路と主担当

プレイヤーは `PlayerSkillToolApplicationService` → `SkillCommandService` → `SkillExecutionDomainService` → 照準・変換 → `HitBoxFactory` を通る。モンスターも `MonsterSkillExecutionDomainService` から同じ変換を使う。

- 実行は公開 `execute_skill`。MP消費、再使用待ち、向き、生成位置と正確な拒否例外を保持する
- 照準は公開 `calculate_auto_aim_direction`。元の方向表をここへ移し、同座標では非阻止アクターを正当に重ねて対象選択まで通す
- 変換は公開 `calculate_spawn_params`。形状・速度の回転補助を直接呼ぶ7試験を、軸方向の表と斜めの生成結果試験へ統合する
- 通常経路では検査できない回転ガード2件は元の入口で保持する

自動照準による生成速度は上位の実サービス・実Factoryを通る既存試験が既に守るため、同じ検査を追加しない。実行成功試験のtick5は、発動硬直1tickを越えた再使用待ち10tick固有の証拠なので、上位の直後使用不可だけでは代替しない。

## 全宣言の判断

実行4件はすべて保持する。照準の射程、壁、自身・非アクター除外も保持する。

修理する4宣言:

1. `test_finds_nearest_enemy`: 近い東の対象を先に置く元行を残し、遠い南の対象が先の行を追加。挿入順の先頭を選ぶ回帰を検出する
2. `test_directions`: 東西南北、傾きの異なる南東2件、同座標の南という全7入力を公開照準へ移す
3. `test_rotate_complex_shape`: L字3点のNORTH/EASTを公開生成へ移し、集合と件数で余分なマスも検出する
4. `test_multi_segment_with_offsets`: 元の開始0/10・継続5/5・東向きオフセットを残し、異なる継続3/7と非空の攻撃者能力値が各区間へ渡る行を追加する

統合する7宣言:

- 相対座標と速度のSOUTH/NORTH/EAST/WEST回転
- NORTH速度の厳密な0.0/-1.0
- EASTへ回した速度0.25
- UP/DOWNでの元速度保持
- SOUTHEASTの格子座標と、小数速度・速さ1の保持

これらは元の(0,1,0)、速度(0,.25,0)、全方位と期待値を維持する。#1390の斜め速度が√2倍速になる不具合修理に由来するため、整数座標と小数速度の違いや厳密なゼロを省かない。

## 私的入口で保持する理由

#1395に由来する角なしUPの直接拒否は、公開UP経路が意図的に平面回転を迂回するため、同入力の公開拒否へ移せない。

Facingが30度を返すときの速度回転拒否も保持する。公開生成へ移すと先行する形状回転で拒否され、速度回転に到達しない。単に同じ例外が出ることを保存の証拠にはしない。第二読でこの移管案を撤回した。

基本威力1.5×区間倍率2.0=3.0の試験も、2入力の合成契約として保持する。単純な値や現在の呼出元数だけを理由に削除しない。テスト専用の製品入口を作らず、既存の補助処理も削除しない。

## 変異による検出力確認

同じ17種類の製品変更を、基準の27件と候補の31件へそれぞれ一つずつ掛けた。各実行は新しいバイトコード読込先とネットワーク遮断を使い、終了後に製品と試験を元バイト列へ戻した。

旧試験が通り、候補だけが意図した断言で失敗した6種類:

- 最も近い対象ではなく候補先頭を選ぶ
- 公開結果に未回転の形状を返す
- 公開結果に未回転の速度を返す
- L字へ余分な攻撃マスを加える
- 区間の継続期間を5へ固定する
- 攻撃者能力値を渡さない

旧新双方が失敗した11種類: 4方向への退行、同座標の既定変更、速度の整数丸め、北方向の微小速度漏れ、上下速度のゼロ化、座標の丸め忘れ、出現オフセットの回転忘れ、発動遅延の欠落、威力の加算、速度だけ30度を容認、角なしNoneの0度扱い。失敗理由と対象項目を照合し、収集エラーや別の拒否を検出成果に数えていない。

## 拒否原子性の切り分け

未編集のドメイン操作へ可変集約を直接渡すと、再使用待ち拒否前にMP消費と向き変更が残り、MP不足拒否でも向き変更が残った。一方、正式なInMemoryの保存実装とUoWを通す `SkillCommandService` では、同じ拒否理由まで到達して保存MP・向き・待ち状態・HitBox件数・確定通知が不変だった。

この結果を永続資源喪失の不具合とは扱わない。ドメイン操作単体にも原子性を要求するかは別の設計判断であり、今回の製品変更にはしない。元の精密な拒否例外試験は保持する。
