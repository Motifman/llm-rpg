## D2267. Being が出す区画を、古い run のプロンプトどおりに再現する

**何を**: #2271 (古い run のプロンプトを新しい世界で再現する) のうち、Being が文にする区画を、古い run (`var/runs/mine_v1_002`) のとおりに出す (#2267)。調整役とユーザーと決めた。

### 現在地の行は Being が書く

古い run の【現在地と周囲】は `現在地: 南の坑道 (初めて訪れた)` の行で始まる。初めて訪れたかは Being の記憶から決まるので、現在地の行は Being が書く。

- 世界は、場面の専用の欄 `Scene.here: Here(place, heading, text)` で渡す。`place` は場所の名前で、訪れた記録の鍵になる。`text` は現在地の行より下の本文 (説明・雰囲気・時刻・接続先・物・人) で、人の穴を持てる
- Being は【現在地と周囲】を、場面のほかの説明より先に、`現在地: {place}` の行と世界の本文で組む。古い run の【現在地と周囲】→【現在選べる対象引数】の並びに合わせるため
- 何も見えないとき (気を失っている、移動中など) は `here` を持たない。Being は【現在地と周囲】を出さない
- `here` の見出しは、場面のほかの説明や知らせの見出しと重ならない

**採らなかった案**:

- 世界が現在地の行まで本文に書き、Being がその行を探して (初めて訪れた) を書き足す: 世界の文の形に頼ることになる
- 世界が訪れた記録を持ち、(初めて訪れた) を世界の文に書く: #2271 で、訪れた記録は Being の記憶として持つと決めた
- 着いたことの観測から現在地を知る: 最初のターンや、snapshot から再開したあとは、着いた観測が届かない

### 訪れた記録を Being の記憶として持ち、着いた場所に (初めて訪れた) を付ける

**何を**: Being のドメインに、訪れた場所の記録 (`VisitedPlaces`。Being ごとに 1 つ) を置く。場所の名前は環境の中でだけ通じるので、環境の名前と組 (`VisitedPlace`) にする。

- 作業記憶は、場面の現在地 (`Scene.here.place`) を、今いる環境の名前で記録と照らし、まだ訪れていなければ現在地の行に `(初めて訪れた)` を付ける
- `ChooseAction` は、1 手を使ったら、その場所を訪れたと記録する。出していないツールの名前を呼んで失敗した 1 手と、思い出すツールの 1 手も含める。ツールを呼ばなかったターンは数えない。だから印は、着いたあと最初に 1 手を使うまで付き、使う前に組み直したプロンプトにも付く。古い run の #1596 と同じ決まりで、古い run も、失敗も含めて実行した手番の数で判定していた
- 手本の run (`mine_v1_002`、2026-10-10) では、同じ場所で 2 ターン続けて印が付いている。#1596 (2026-10-11 に直した) より前の run だからで、直したあとの決まりに合わせた (#2271 は、いまの古い run のコードを一次情報とする)
- Being の snapshot に `being_visited_places` として配線した。足す前の snapshot は、どこも訪れていないとして読む (`ADDED_PAYLOAD_KEYS`)
- 古い run の組み立て (`world_runtime`、実験の snapshot のセッション、スクリプト) にも保存先を通した。Being の snapshot を古い run と共有しているため。古い run の場面は現在地の欄を持たないので、記録は増えず、プロンプトは変わらない

**採らなかった案**:

- 古い run の出会いの記録 (`IEncounterMemory`) を使う: 古い run のプレイヤーの番号で引く記録で、Being の記憶ではない
- 記録を知り合いの保存先 (`AcquaintanceRepository`) に混ぜる: 人と場所は別の記録で、問い方も違う
