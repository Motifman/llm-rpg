## D2268-11. 【この場所の造り】の屋外の場所は、明るさを「昼は明るい」と書く

**何を**: 世界の前提の【この場所の造り】 (D2268-2) に載せる明るさを、屋外の場所だけ「昼は{明るさ}」と書く (#2268、ユーザーが決めた)。

```
  北の竪坑口 (昼は明るい) → 北の竪坑の底 まで 30 分 / 集会所 まで 30 分 / 雪の峠道 まで 60 分
  昇降機の乗り場 (暗い) → 下層の近道 まで 30 分 / 古い支柱の通路 まで 60 分
```

| | 決まり | 古い run との違いと理由 |
|---|---|---|
| 屋外の場所 | 昼夜のある世界では `(昼は明るい)` のように、シナリオに書いた明るさの前に「昼は」を付ける | 違う。屋外は夜や悪天候で一段暗くなる (`LightingConditions.lighting`) のに、地図は run のあいだ変わらず、シナリオの明るさのまま載る。夜の初めの場面で「(明るい)」と読むと、着いてから暗いことに驚く |
| 屋内の場所 | シナリオの明るさのまま | 同じ。屋内は時刻でも天候でも変わらない |
| 昼夜の無い世界 | 屋外もシナリオの明るさのまま | 同じ。暗くなる時刻が無い (ユーザーが決めた) |

- 言い回しは `ja_default.yaml` の `world_map.outdoor_lighting` に置いた
- 昼夜があるかで書き分けるのは、所要時間を分か手ぶんかで書き分けるのと同じく、昼夜の宣言 (`DayNightDeclaration` / `NoDayNight`) に問う
- 昼夜の無い世界でも悪天候では屋外が暗くなるが、ユーザーの決定どおり書き分けない

**関連**: Issue #2268、#2271、D2268-2。
