## D2022. 条件・効果・行為が指し合う約束と、テストで世界を読み書きする実装

**何を**: 条件・効果・行為・動詞の宣言を別々の PR で並べて作れるよう、指し合う部分の約束を先に入れた (#1978 のステージ 4 の土台)。`Condition`、`WorldFacts`、`Requirements`、`Subject`、`ConditionPath`、`ChanceOccasion` は `condition/` に、`Effect`、`WorldAggregates`、`EffectPath` は `effect/` に、`ActionAttempt` と `Trigger` は `action/` に置いた。並行する PR が同じファイルを触らないよう、3 つの `__init__.py` は空にした。文書から決まらなかったことは、ユーザーと次のように決めた。

| 型・振る舞い | 決めたこと |
|---|---|
| `Trigger` が指す、まだ無い宣言 | 宣言ごとに ID だけを答える Protocol (`FiredHappening`、`FiredReaction`、`CompletedJointAction`) を `action/trigger.py` に置き、きっかけはそれを持つ。#2026 の宣言は import せずに満たす。ID の型 (`HappeningId`、`ReactionId`、`JointActionId`) はここで作った |
| 「その人」(`EachPerson`) の受け渡し | `Trigger` の和に `EachPersonOf(outer, person)` を足し、外のきっかけを包んで渡す。`holds` / `apply` の引数は文書のまま |
| 主語を人に解く口 | `Subject.person_in(trigger)`。きっかけの型が `person_as(SubjectKind)` で自分の答えられる主語を答え、答えられない主語は `SubjectNotInTriggerException`。`compose` が `requirements()` で先に弾く前提で、ここに来るのは作り手の誤り。`NamedPerson` はきっかけを見ずに宣言の人を答える |
| 品物の主語 | `ThisItem.item_in(trigger)`。きっかけの型が `this_item()` で答え、答えられなければ `ItemNotInTriggerException` |
| `ConditionPath` / `EffectPath` | 根からの子の位置の並び。`root()` と `child(position)` だけを持ち、並びは外に出さない。同じ宣言の中の 2 つの偶然を、位置で別の機会にするため |
| `Requirements` の操作 | `nothing()` と `combined_with(other)`。Issue のテストリストの「2 つ合わせる」のため。主語の要求は `nothing()` から主語だけを変えて作る |
| `SubjectKind` | `ACTOR` / `TARGET` / `CHOSEN_BY_GROUP` / `NAMED_PERSON` / `EACH_PERSON` の列挙。主語の各型が自分の種類を `requirements()` に出す |
| `WorldFlags`・`ScenarioProgress`・`LatestActions` に頼る読み取り | `flag_is_raised`、`happening_last_fired_at`、`ticks_since_last_action` と `WorldAggregates.flags()` は、まだ Protocol に入れない。集約を作る #2027 で足す。呼ぶと断る仮の実装は、開発の都合をコードに残すので置かない |
| テスト用の世界の置き場所 | `tests/game_world/support/world_in_memory.py` の `world_in_memory`。#2080 で、SQLite のメモリ上の DB に集約を入れて作業単位 (`WorldSession`) を返す関数にした。本番のコードに、テストでしか使わないクラスを入れない。Protocol とのずれを止めるため、`tests/game_world/support` だけを mypy の対象に足した |
| テスト用の世界の偶然 | テストが `ChanceOccasion` ごとに出目を渡す。渡していない機会は `LookupError`。乱数を使わず、テストが flaky にならないようにする |

**実装で決めたこと**:

- `WorldFacts.weather()` / `world_stage()` と `WorldAggregates.weather()` / `world_stage()` は同じ名前で別の型を返すので、1 つのクラスで両方は満たせない。作業単位の `facts()` と `aggregates()` は同じ集約を共有する
- `WorldFacts.hunger_of` / `fatigue_of` を本物の集約から読むため、`PersonVitals` に `hunger()` / `fatigue()` を足した
- `CopresenceRequirement` は `WithPerson(person)`、`WithObject(obj)`、`WithGroundItem(item)` の 3 つ。モンスター・商人・市場の板は #1971 と取引の Issue で足す
- `NoWorldStages` を `declaration/progress/no_world_stages.py` に置いた
- 宣言がまだ無いあいだ、テストで行為を作れるよう `ActionAttemptForTests` を、出来事などの宣言の代わりに `HappeningForTests` などを `tests/game_world/support/` に置いた
