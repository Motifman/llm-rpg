# 動的引数候補表の質感確認

世界の説明には、場所の接続先や物体ごとの操作が従来どおり残る。その末尾に、
`travel_to.destination_label` や `interact.action_name` へ実際に書ける値だけが
短い表として再提示される。説明を読んで行動を考える余地は残しつつ、最後に
コピー可能な文字列へ着地できる形である。候補が無い局面には空の見出しを出さず、
二段階推論の評価段階にも行動候補を混ぜない。

表の対象は、現在の実行時情報から解決する対象引数に限る。自由文、数量、価格などを
網羅する一覧には見せない。表示名を受けるツールには表示名を、`P1` や `G1` のような
ラベルを直接受けるツールにはラベルを出し、表を写した値そのものが resolver で通る。
