## D1862-6. 旧タイルの時間進行と専用のモンスター行動を削除する

Issue #1862 の変更範囲4。本番はスポットのグラフで時間を進めており、
旧 `world_simulation_*.py` とそのモンスター行動・敵対対象の記憶は構築しない。
候補外からの import を AST で確認し、製品コードに残る参照は
`domain/world/service/__init__.py` の再公開だけだった。
再公開を先に外し、旧シミュレーションと専用依存・専用試験を削除する。

モンスターという名前だけで削除範囲を広げない。本番の
`spot_monster_behavior_tick_service`、`MonsterAggregate`、
`monster_behavior_state_machine` とスキル装備の値を残す。
状態異常・天候・時刻・`domain/pursuit` も維持する。
`behavior_action` と `domain/monster/action_resolver` は、
型だけの参照も専用依存内に閉じているため削除できる。

物理マップ本体まで同時に消す案は、移動・追跡など残る利用側を巻き込むため採らない。
共有に見える `world_simulation_builders.py` も旧試験1本だけの利用なので削除する。
旧試験内で残る追跡継続と当たり判定を直接検証する8件は専用試験へ移す。
将来、本番からの実際の呼出しや
候補外の型依存が見つかった場合は、この削除境界を見直す。
