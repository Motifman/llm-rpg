## D1469-3. シナリオのプレイヤーに一人称の欄を足し、Being の人柄と行動を決める LLM に伝える

**何を**:

- シナリオの `players[]` に `first_person` (任意) を足した。空でない文字列で書き、前後の空白は落とす。空白だけや文字列でない値は、読み込みで止める
- 起動時に Being を用意するとき、`Persona.first_person` に入れる。書いていなければ `None` のままで、仮の一人称は入れない
- `mine_village_v1` の 4 人の人物像と一人称を、ユーザーが決めた (2026-10-31)

| プレイヤー | 人物像 | 一人称 | シナリオで直したところ |
|---|---|---|---|
| ハル | 落ち着いた男 | 私 | 見た目を「測量具を背負った年かさの男」に、人物の文に「落ち着いた男」を足した |
| ミオ | 若い元気な女の子 | あたし | 見た目を「工具袋を腰に下げた若い女の子」に、人物の文に「元気な女の子」を足した |
| ゲン | (変えない) | 俺 | なし |
| サヨ | (変えない) | 私 | なし |

- ハルとミオの見た目は、名前を知らない相手に見せる呼び方 (design_decisions D1581) なので、ほかの人からの見え方も変わる

**なぜ**: 一人称が決まっていないと、いきさつとエピソードの書き手は本文の一人称を毎回選び直す。run `mine_v1_011_switched` では、エピソードの本文の一人称が「俺」と「私」で揺れていた。書き手は、一人称が決まっていれば名前の次の行で伝える (design_decisions D1469-2)。

**行動を決める LLM にも一人称を書き足した**:

- run `mine_v1_011_switched` では、ハルとミオは発言と inner_thought で「俺」しか使っていなかった (ハル 39 回、ミオ 40 回)。ゲン (「俺」34 回) とサヨ (「私」92 回) は、今回の一人称と合っていた。人物の文に一人称が無く、LLM が選んでいたため
- ユーザーは、その run に合わせずに人物像を決めた。書き手にだけ一人称を伝えると、行動を決める LLM は前と同じ一人称で話し続け、エピソードの地の文と引用した発言で一人称が食い違う
- 行動を決める LLM には、まだ `Persona` から一人称が渡らない。つなぎとして、各プレイヤーの `persona_prompt` の「話し方:」の行に「一人称は「…」。」を書き足した。値は `first_person` と同じにし、`tests/infrastructure/scenario/test_shipped_scenarios_first_person_in_persona.py` が同梱のシナリオで食い違わないことを見張る
- 人格の文を `Persona` から作るとき (#1339 / #1548) に、このつなぎは消す

**欄の名前**: `persona_prompt` の分割とキーの改名 (#1339 / #1548) は、ここではしない。一人称は人柄の 1 項目で、`Persona.first_person` と同じ名前にした。人柄を構造のある形に分けるときは、この欄もその形に移す。

**まだしないこと**:

- ほかのシナリオには一人称を書いていない
- `persona_prompt` を書かないプレイヤーの行動用の人格の文は、固定で「一人称: 私」を出す (`world_llm_prompt.py` の `_fallback_persona_block` と、`first_person` の無いキャラクター)。そのシナリオに `first_person` を書くと、書き手と行動を決める LLM で一人称が食い違う。`mine_village_v1` は全員が `persona_prompt` を持つので当たらない

**関連**: Issue #1469、design_decisions D1469-1、D1469-2、D1581。
