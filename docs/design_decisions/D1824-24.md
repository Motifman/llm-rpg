## D1824-24. 今の短期記憶とその要約を消し、世界の側のストアは並びを持たない

**何を**: プロンプトを Being の短期記憶から作るようにした (design_decisions D1824-22、D1824-23) ので、今の短期記憶を消した。

| | 中身 |
|---|---|
| 消した | 今の短期記憶 (`SummarizingShortTermMemory`)、その要約 (`ShortTermMemorySummaryService`)、要約の scheduler、要約の値オブジェクト (`L4MidSummary`)、インタフェース `IShortTermMemory` |
| 消した | `WorldLlmWiring.short_term_memory` と、手番の終わりに今の短期記憶のターンを閉じる処理 (`complete_turn`)。Being の短期記憶のターンは `run_phase_b` の `end_being_turn` が終わらせる (design_decisions D1824-21) |
| 消した | trace `short_term_summary_dropped` / `short_term_summary_generation_failed` / `short_term_summary_generated` / `short_term_memory_compacted` |
| 消した | 旧 3 形式の snapshot の decoder (`ShortTermMemorySubsystemCodec` など)。旧 3 形式は `migrate_legacy_recent_event_subsystems` で読む |
| 変えた | `UnifiedRecentEventStore` は、出来事の並びを持たない。未処理の観測と、直近の行動の結果 (`RECENT_ACTION_RESULTS_KEPT` = 20 件まで) だけを持つ。行動の結果を返す順 (時刻の新しい順、同じ時刻は先に足したものが先) は前と同じ。足した観測と行動の結果は、聞き手 (写す処理) に知らせる |
| 変えた | プロンプトを組む処理は、預かった観測を取り出してストアに足す。足すと写す処理が Being の短期記憶に書く |
| 変えた | snapshot の `recent_event_store` を v2 にした。未処理の観測と直近の行動の結果だけを持つ |
| 残した | 要約の LLM の呼び出しのインタフェース (`IShortTermMemorySummaryCompletionPort.complete_short_term_summary_json`)。いきさつの書き手 (`LlmBackstoryWriter`) が使う。費用の記録の component も `short_term_summary` のまま |
| 残した | 写す処理 (`PlayerShortTermMemoryCopy`)。ゲームの出来事を Being の短期記憶に入れる経路は、これしかない |

**なぜ**:

- 二重の経路は管理の手間が増えるだけなので、うまく動いたら今の経路を消す (#1824 でユーザーと決めた)
- 今の短期記憶を消すと、ストアの並びを畳む処理が無くなり、並びが際限なくたまる。並びを読むのはプロンプトだけだったので、並びを持つのをやめた (#1824 で決めた)

**直近の行動の結果を 20 件まで持つ理由**: 読むのは Phase A の起動判定 (`has_recent_same_failure`) だけで、新しい 2 件を読む。ただ、行動の結果は起きた時刻の新しい順に返すので、足した順と時刻の順がずれると、足した順の最後の 2 件だけでは新しい 2 件を取りこぼすことがある。今の短期記憶が持っていた範囲 (最大 20 ターン分、1 ターンに 1 件) と同じだけ残して、余裕を持たせた。

**古い snapshot**:

- v1 の `recent_event_store` (並びと要約を持つ) は、並びの中の行動の結果と未処理の観測だけを戻す。並びの観測と要約 (`mid_summaries`) は捨てる。直近の出来事は Being の snapshot の短期記憶が持つ
- 捨てた件数は trace に残さない。Being の snapshot を持たない古い run から再開すると、【直近の出来事】は空から始まる
  - 世界のキーをまるごと廃止したとき (design_decisions D1893) は `snapshot_load.removed_world_subsystems` に件数を残すが、これはキーは残したまま中身の一部を読まない形で、捨てたものは Being の snapshot が持つ内容と重なる

**関連**: Issue #1824、design_decisions D1824-7、D1824-21、D1824-22、D1824-23。
