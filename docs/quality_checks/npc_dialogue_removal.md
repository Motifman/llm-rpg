# NPC会話の木を削除したときの確認

Issue #1862 / 設計判断D1862-12。実LLMを呼ばず、既存のスポット世界の発言・観測・行動が維持されるかを確認する。

| 場面 | 変更前 | 変更後 |
| --- | --- | --- |
| 旧NPC会話の木 | 専用サービス・保存先・観測が残る | 本体と接続を削除 |
| NPC会話の終了 | 専用イベントでTALK_TO_NPCの進捗を更新できる | イベント・購読・専用進捗処理が無くなる |
| スポットでの発言・聞き取り | PlayerSpokeEventを配信し文面と手番を決める | 維持 |
| 撃破・所持品取得などのクエスト | 進捗を更新し、完了時に報酬を与える | 維持 |
| 既存の保存データ | TALK_TO_NPC・任意会話項目・会話テーブルが存在できる | 既存のenum・共通DTO・snapshot・migrationを維持 |

## 確認の範囲

削除前にsrc/testsのASTで70件の参照を調べた。会話の木の外側では、クエストの受け手・進捗処理・登録、観測の登録・配信先・文面と再公開、DIが読み込んでいた。旧LLMの会話ツールとタイルの問い合わせは先行PRで削除済みで、スポット本番に会話の木を構築する経路は無い。

構造試験で本体と専用保存先の不在、観測登録からの削除を確認する。クエスト購読試験では残る3種と受け手の接続を独立に列挙し、発言は既存の配信・文面・手番の試験で保証する。会話の木だけを保証していた専用試験は削除し、他の進捗・報酬の試験は残す。

## スタブ比較

比較用の一時出力は `/tmp/llm-rpg-1862-npc/`。作業ツリーに.envを置かず、検証用sitecustomizeでdotenv.load_dotenvを無効化する。profileはsmoke_stub、山村と避難訓練は各シード0〜2・40tick。通常のfuzz入口の実行に加え、同じrun_random_agentsのNullTraceRecorder.recordを一時的に収集し、全記録種別・観測種別別件数と行動件数を前後比較する。

smoke_stubは前後とも既定のsurvival_island_v3_coop・2tick・stubで成功し、全記録種別の件数が一致した。この短い実行の観測は0件なので、同等性は次の6試行で確認した。

| シナリオ | シード | 行動件数（前後一致） | 観測件数（前後一致） |
| --- | --- | ---: | ---: |
| mine_village_v1 | 0 / 1 / 2 | 142 / 139 / 145 | 92 / 127 / 84 |
| station_drill | 0 / 1 / 2 | 301 / 199 / 279 | 531 / 497 / 659 |

全6試行で例外と検出事項0件。合計は行動1,205件・観測1,990件で、全記録種別と観測種別別件数が一致した。発言・同席の聞き取り・品の受け渡し・戦闘不能・会議の観測も含む。これはスタブでの再現性の確認で、実LLMの質感を測った結果ではない。

## 試験と独立レビュー

関連試験1,476件成功。整形後に直接変更した試験137件も成功。変更Pythonファイルのruffとmypy（1,335ファイル）は成功した。削除パッケージを指定していたmypyの対象一覧は、その1行だけ外した。削除対象へのimportはsrc/testsのAST検査で0件で、文字列検索に残るモジュール名は削除を保証する構造試験の期待値だけである。共通DTOなど残す契約は別扱いにしている。

独立レビューはCRITICAL 0 / HIGH 0 / MEDIUM 0 / LOW 0件。レビュー側も構造・購読・進捗・発言観測など85件を実行し成功した。残すコードの変更は394行で、専用ファイルの削除と文書は別に数えた。

実LLMの対話の自然さと既存の会話保存データを新機能へ移す方法は未確認で、今回の削除の効果とは扱わない。
