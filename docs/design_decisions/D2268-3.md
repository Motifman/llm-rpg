## D2268-3. 【現在地と周囲】を古い run の行の形で書く (前半)

**何を**: 世界が場面として渡す【現在地と周囲】を、古い run の行の形にそろえる (#2268 の 2 本目の続き)。この節は前半で、場所の説明・雰囲気・天候・時刻・時刻帯・接続先・オブジェクトを扱う。同じ場所の人・持ち物・身体の状態は後半 (4 本目) で扱う。

| 行 | 決まり | 古い run との違いと理由 |
|---|---|---|
| 現在地 | 世界は書かない。場所の名前を Being に渡し、Being が `現在地: {場所} (初めて訪れた)` を書く | 訪れた記録は Being の記憶に置く (#2267)。世界は場所の名前と、その下の本文を渡す |
| 説明 | `  {説明}`。真っ暗なら説明の代わりに「真っ暗で、何も見えない。」 | 同じ |
| 雰囲気 | `雰囲気: 明るさ: {明るさ} / 音: {音} / 気温: {気温} / 匂い: {匂い}`。音と匂いは宣言にあるときだけ | 同じ。明るさは宣言の値ではなく、時刻・天候・灯りを合わせた今の明るさ (`LightingConditions`)。古い run も夜は屋外を一段暗く書いていた |
| 天候 | 屋外で天候のある世界だけ `天候: {天候}（屋外）` | 古い run は強さ (0.3 未満で「弱い」、0.7 より上で「激しい」) を付けていた。新しい世界の天候は強さを持たない。古い run の山村は強さ 0.5 で、どちらも付かないので行は同じ |
| 現在時刻 | `現在時刻: {Day 1 深夜 0:30}` (D2268 の 1 節の書き方) | 昼夜の無い世界では出さない。古い run は「現在時刻: 不明」と書いていた。時計の無い世界に時刻の行を置いても選ぶ材料にならないため |
| 時刻帯 | `時刻帯: {表示名}`、暗い時刻帯は ` (暗い)` を付ける | 同じ。時刻帯の表示名 (未明・朝など) をシナリオの `display` に書く。識別子 (predawn) を場面に出さないよう、書かないと読み込みで止める |
| 接続先 | `接続先:` の下に通路ごと `  - "{通路}" → "{行き先}"（通行可）` / `（通行不可 — {通路の状態}）` | 古い run の「通行不可 — 」のあとは通路の説明だった。新しい世界は通路の状態の名前 (「水に浸かっている」など) を書く。説明は通れるときも同じ文で、なぜ通れないかが分からないため。ここへ入ってくるだけの一方通行の通路は、出られないので載せない |
| オブジェクト | `オブジェクト:` の下に `  - "{名前}" ({見た目}) — {説明}`。見た目の無い物は括弧を付けない。何も無いと `オブジェクト: (ここには何も無い)`、暗くて見えないと `(暗くて何も見えない。灯りが要る)`、暗くても見える物だけが見えているときは一覧の頭に `  (暗い。灯りがなければ、見えるのはこれだけ)` | 古い run は行の末尾に `[水門を開ける → "open_gate_a"]` と操作を付けていた。操作の識別子を引数に渡す形 (#2268 の 5 本目) と一緒に足す。いまの interact は操作の表示名を引数にとるので、先に識別子を出すと選び方と食い違う |

- 古い run と違う 3 点 (最初の時刻、通れない理由、昼夜の無い世界の時刻) はユーザーが決めた。最初の時刻は、古い run が 0:30、新しい世界が 0:00 になる。古い run は最初の巡りが tick 1 から、新しい世界は tick 0 から始まるため。0 時の場面を見せてから時計を進めるほうが、時刻と場面が食い違わない
- いまできない操作を物の行の下に出す変更は、次の PR で出す。古い run は、水門や閂のように条件で切り替わる操作に「条件を満たさないあいだは候補ごと伏せる」印を付けていた。新しい世界にこの印が無いまま出すと、閉じている水門に「いまできない: 水門を閉じる」が出て、古い run と違ってしまう。印と一緒に出す
- 言い回しは共通の部品 `ja_default.yaml` の `surroundings_texts.scene` に、明るさ・気温・天候の言葉は `world_words` に置く。古い run の `world_vocabulary.py` と同じ言葉
- 行の言い回しは、埋める値をちょうど過不足なく書いているかを読み込みで確かめる。行き先の名前や天候を書き忘れても場面は書けてしまい、エージェントに必要な値だけが静かに消えるため
- 天候・時刻・時刻帯・今の明るさは、世界のドメインの `SceneConditions` が世界の事実から集め、行に書く。見えている周り (`VisibleSurroundings`) がそれを持ち、application 層は頼むだけにする
- D2241 の場面の形 (「物:」「行き先:」、通路の名前を出さない、同じ場所へ続く通路は 1 行) を置き換える。D2241 が通路の名前を出さなかった理由は、選ぶ名前 (場所) と違う名前が増えることだった。古い run は通路の名前と行き先の名前を `→` で並べ、選ぶのは行き先の名前と分かる形にしていたので、その形に戻す (調整役を通してユーザーと決めた)。通れない道は、場面でも状態の名前で分かるようにする
