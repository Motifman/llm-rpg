## D2271. 新しい世界で、Being にメモの引数を出し、【メモ】は引数を出しているときだけ出す

**何を**: #2271 (古い run のプロンプトを新しい世界で再現する) のうち、メモ帳を新しい世界で使えるようにする。調整役とユーザーと決めた。

### 古い run との違い

| | 古い run | この変更の前の新しい世界 | この変更のあと |
|---|---|---|---|
| 行動のツールの `memo` 引数 | あり | なし | あり |
| システムプロンプトの【メモの書き方】 | あり | なし | 古い run と同じ文 |
| 毎ターンの【メモ】 | あり | 空の見出しだけ出ていた (書く手段が無い) | あり。書いたメモが次のターンから出る |

### 決めたこと

- 新しい世界はメモの引数を出す。メモの書き込みと【メモ】の文は、Being の `ChooseAction` と `CurrentWorkingMemory` がすでに受け持っているので、渡す道具 (`OfferedBeingTools.memo`) に名前を入れるだけで足りる
- 【メモ】の区画は、メモの引数を出しているときだけ出す。【メモの書き方】とツールの引数はすでに `OfferedBeingTools` で出し入れしていて (#1616)、区画だけが引数の有無を見ずに出ていた。書けないメモ帳を見せると、エージェントは書く手段を探す
- 【思い出せる出来事】と思い出す道具は、エピソードの書き起こしの配線と一緒に出す。書き起こしが無いうちに出すと、目次が run の終わりまで「(まだ無い)」のままになるため

**関連**: Issue #2271、#1616、#1628、#1630。
