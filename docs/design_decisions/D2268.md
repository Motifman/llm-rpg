## D2268. 世界が渡す前提・場所の造り・場面を、古い run のプロンプトどおりに再現する

**何を**: 古い run のエージェントのプロンプトを、新しい世界で区画ごとに再現する (#2271) うち、世界が渡す区画を作る (#2268)。足りないものは世界のドメインの概念として作り、application 層で文を合わせない (ユーザーが決めた)。決まった言い回しは共通の部品 (ja_default.yaml) に置く。

### 1. 時刻の書き方を、古い run と同じ `Day 1 深夜 3:30` にする

| | 決まり | 例 (1 日 48 tick、0 時に始まる山村 v2) |
|---|---|---|
| 書き方 | `Day {何日目} {深夜 }{時}:{分}`。時は 0 を詰めず、分は 2 桁 | tick 7 は `Day 1 深夜 3:30`、tick 61 は `Day 2 6:30` |
| 深夜の印 | 0 時から 5 時台に「深夜 」を付ける | tick 11 (5:30) は深夜、tick 12 (6:00) は付かない |
| 置き場所 | 言い回し (`Day {day}`、`深夜 `、何時の前までを深夜とするか) は、共通の部品の `clock` に置く。世界の設計 (`WorldDesign.clock_wording`) が持ち、何日目と時:分の値 (`DayAndClockTime`) を書く振る舞いは `ClockWording.display` に置く | |
| 使うところ | 観測の時刻、行動の結果の時刻、いまの時刻 (`TellCurrentTime`) のすべて | |

- D2222 の 3 節の `1 日目 03:30` を置き換えた。何日目と時:分の割り出し方 (`DayNightDeclaration.day_and_clock_time_at`) は変えない
- 古い run の書き方は `world_runtime.py` の時刻の札と同じ。【この場所の造り】の移動の時間 (「10 分」) と同じ分の単位で読めるので、エージェントが「0:10 に出たなら 0:20 にしか着けない」と検算できる
