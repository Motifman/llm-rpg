## 参照と維持する経路

旧UI・実行器の専用試験3ファイルと、共通試験内の旧タイル用の定義・移動・採取・会話・スキル・利用可否判定・候補表の試験だけを除いた。構造検査は移動サービス2件が本番の読み込み先から外れた分だけ一覧を縮めた。旧シミュレーションや移動サービスの本体は触っていない。
