## D1924-2. 廃坑の山村の本命の profile は、考えの段階を minimal から low にする

**何を**: `memory_jev_mine_v1_v41_thinking_capped_being_memory` の `LLM_REASONING_EFFORT` を `minimal` から `low` に変える。出力の上限 (`LLM_MAX_OUTPUT_TOKENS` = 4096) は変えない。

**なぜ**:

- OpenRouter の公開のモデル一覧 (`GET /api/v1/models`、2026-10-31) で、`deepseek/deepseek-v4.1-flash` が受け付ける段階は `max` / `high` / `low` / `none` だった。`minimal` は入っていない。受け付けない値を送ったときに OpenRouter がどう扱うかは分からない
- run `mine_v1_011_switched` で上限に届いて切れた呼び出し 3 件を、段階ごとに 2 回ずつ送り直した。考えの長さは、`minimal` が 632〜4096 トークンで 6 回中 1 回が上限で切れた。`low` は 380〜3008 トークンで、切れなかった。回数が少なく、同じプロンプトでも長さが大きく揺れるので、`low` の方が短いとまでは言えない。変える理由は受け付ける値に合わせることで、切れる問題は D1924 の呼び直しで扱う
- 考えを止める (`none`) にはしない。考えは行動の質のために残す。同じ送り直しで、考えを止めた呼び出しが、初対面の相手を殴る行動を心の声無しで選んだことが 1 件あった

**どうしないと壊れるか**: 段階を `minimal` に戻すと、受け付けない値を送る run に戻る。`tests/scripts/test_the_mine_village_being_memory_profile_differs_only_in_memory.py` が段階と上限を見張る。

**比べるときの注意**: 2026-10-31 より前の run (`mine_v1_006`、`mine_v1_011_switched` など) とは考えの段階が違うので、比べるときはこの違いを差し引く。

**対象外**: ほかの profile の `minimal` は変えない。使うモデルが違い、そのモデルが受け付ける段階を確かめていない。
