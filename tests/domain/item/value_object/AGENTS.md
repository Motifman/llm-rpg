# 消費効果の試験を変更するとき

この規則は `test_item_effect.py` と `test_spoiled_consumption.py` に適用する。

- 腐敗ダメージの期待値は設計で定めた値を明示し、製品定数から独立させる。製品定数を読み直して期待値を作らない
- 効果の公開属性への代入拒否は、属性書換に対応する例外と拒否後の元値を確認する。無関係な例外で通したり、内部のdataclass構造を固定したりしない
- この2ファイルの構築試験は、小さいことや製品からの直接呼出がないことだけで削除しない。0量・蘇生率の両端・複合効果の入力形・基底生成拒否・入れ子合算の独立契約を確かめ、統合時も元入力を残す
