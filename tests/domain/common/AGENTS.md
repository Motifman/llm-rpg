# 集約診断と共通イベントの試験所有

- `warn_if_pending_events` の無音・警告内容・非消費は、その公開APIを直接呼ぶ試験が所有する。配送側の試験はこの診断を呼ばないので代替にしない
- 空時は対象のログ出力元の WARNING 以上の記録で判断し、特定の単語の不在だけで無音とみなさない
- 診断の総数と型別件数には、元の単一型入力に加えて総数と型数が異なる混在入力を使う。期待値を製品の集計処理から作らない
- 非消費は件数だけでなく、不変イベントの内容と順序を公開の `get_events` で確認する
- `BaseDomainEvent.create` の発生時刻の契約は共通生成APIが所有する。個別イベントの生成経路と観測側の時刻選択は、それぞれの入口に残す
- 呼出箇所がない公開の任意診断を、試験だけの補助入口と断定して廃止しない。公開APIの採否は別の設計判断にする
