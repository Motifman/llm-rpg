# タイル専用観測の削除（Issue #1862・範囲9）

## 前後の振る舞い

| 場面 | 変更前 | 変更後 |
| --- | --- | --- |
| 当たり判定・タイル採取・宝箱・物体への作用・場所の出入り | 本番は発行せず、登録・文面・配信規則だけ残る | 専用観測を持たない |
| モンスターの旧行動決定・タイル採食 | 本番の行動は別イベントで表す | 旧イベントは観測対象外 |
| モンスターの損傷・死亡・回復・出現 | スポットと本人に関する既存規則 | 維持 |
| モンスターの状態変化 | 本番は物理マップ未注入で配信先なし | 登録と文面を残し、配信先なしを明示 |
| 天候・時刻・会話・装備・所持品・追跡・休眠文脈 | 各専用規則 | 維持 |

物体の解決契約の試験は、削除した物理マップ実装の代わりに解決結果を返す代役を渡す。追跡の本人・対象への通知、重複除去、手番起動の試験を維持する。factoryの本番経路は従来から空の解決実装を使用していた。

## 参照と発行元

- `src/tests/scripts` の読み込み・型・文字列参照を確認してから、専用整形器2本・配信戦略2本・物理マップによる物体解決1本と再公開を削除。
- タイルの発行元は `PhysicalMapAggregate`、`MapTriggerEngine`、`world_object_component` と `MonsterAggregate.record_*`。旧行動決定の呼び出し側は削除済み。本番の作用・採取・移動・戦闘は `domain/world_graph/event` のイベントを使う。
- `ActorStateChangedEvent` は `MonsterAggregate.transition_to_passive_state` 等に残るため維持。`SpotWeatherChangedEvent` の文面と屋内配信抑制も維持。
- 会話本体とクエストの会話終了購読、物理マップ・当たり判定本体と保存先は後続の担当範囲。

## 試験リストと質感

- [x] 観測factoryに物理マップ・当たり判定の引数がない（変更前の失敗を確認）。
- [x] タイル専用18型に観測登録・配信先・文面がない。
- [x] 観測の網羅検査と残す配信・文面・本人通知・手番起動の試験を維持。

今回の目的は、エージェントが受け取る世界の質感を変えず、存在しないタイルの観測経路をなくすこと。短い動作確認だけで同等性を判断せず、山村と避難訓練の各シード0〜2・40tickについて、観測種別ごとの件数と行動件数、全記録種別を前後で比較する。実LLMは呼ばず、`.env` の読み込みは検証用の `sitecustomize` で無効化する。

## 検証結果

- 観測・イベント登録・構造・単独読み込みの関連試験1,160件と、本番実行環境・発言・モンスター遭遇・無効ツールの文面検査249件が成功。変更Pythonのruff、mypyの1,375ファイルも成功。
- 削除5モジュール・5クラスに対し、`src/tests/scripts` の2,798ファイルでASTと文字列の参照検査を実施し、残存0件。独立側でも相対読み込みを含む検査で0件。
- `make experiment EXPERIMENT_PROFILE=smoke_stub` の前後とも既定シナリオ・2tick・stub。解決済み設定を確認し、全記録種別の件数が一致。
- `make fuzz-scenario SCENARIO=data/scenarios/mine_village_v1.json SEEDS=0-2 FUZZ_TICKS=40` と `station_drill.json` を変更前後で実行し、各6試行とも成功・検出事項0件。同じ実行関数の記録を別途収集し、全記録種別・観測種別ごとの件数・行動件数が一致（観測1,990件、行動1,205件）。
- 独立レビューは初回CRITICAL 0 / HIGH 0 / MEDIUM 1 / LOW 1。削除済み整形器を単独読み込み試験が参照していた1件と、末尾余白3ファイルを修正。修正後は全重要度0件、独立側の関連236件が成功。

山村の発話・移動・品の受け渡し・採取作用とモンスターとの遭遇、避難訓練の倒れた人・会議・投票の観測種別と件数は変化しなかった。実LLMを使った文章や長期の物語の評価は今回行っていない。状態変化の配信を新設せず、報酬文面も変更しない。今回確認できた範囲では、世界の質感を変える差はない。
