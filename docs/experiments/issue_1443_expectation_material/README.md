# 信念の材料の件数の前後比較 (#1443)

過去 run `v4coop_0731_006` (遭難の島、4 人) の同じ場面で、予測の当否から信念に積む材料の件数を、#1443 の前後で並べた。

## 組み直し方

- 場面: 4 人それぞれの 1〜8 手目と 41〜48 手目。計 8 窓、64 手
- 前: run の trace に残った `belief_evidence` のうち `prediction_error` / `confirmation`。chunk の主観補完が書いた `prediction_error` から積んでいた
- 後: 各手の `expected_result` を、その手のターンに書いた予期として積んだ。実 Jev で清算し (#1440)、確定した出来事を本番の `ExpectationBeliefMaterialReceiver` に通した
- 頭にあった信念とエピソードは、その手の直前の `semantic_passive_recall` / `episodic_recall` の候補から組み直した
- 確からしさは trace に無いので、すべて「たぶん」。期限は 6 ターン、時系列は 4 ターン
- Jev の呼び出しは 58 回。縮退は 0 回

## 結果

| | 前 | 後 |
|---|---|---|
| 反証の材料 (`prediction_error`) | 16 | 16 |
| 支持の材料 (`confirmation`) | 0 | 9 |
| 数える単位 | chunk 15 個 | 予期 49 件 |

後の 49 件の行き先:

| 行き先 | 件数 | 材料になるか |
|---|---|---|
| 外れたで確定 | 16 | 反証 |
| 当たったで確定し、頭に信念があった | 9 | 支持 |
| 当たったで確定したが、頭に信念が無かった | 8 | ならない |
| 暫定の外れのまま窓が終わった | 5 | ならない |
| 暫定の当たりのまま窓が終わった | 2 | ならない |
| まだ分からないまま窓が終わった | 4 | ならない |
| 形の判定で外した (本人の行動 3、どう転んでも当たる 1、予期ではない 1) | 5 | ならない |

前の 16 件のうち、既定の文 (「予測していたが、行動の一部が失敗した。」) で上書きされたものは 0 件だった。この run では主観補完 LLM が空を返した chunk に失敗した行動が無かった。

反証の件数は同じ 16 件だが、中身が入れ替わった。前の 16 件には、次のような反証にならない文が入っていた。

- 「骨のナイフがないと予想した通り、釣竿の作成は拒否された」(エイダ、tick 8)。予期どおりの失敗を反証として積んでいた
- 「漂着物から何か使えるものは見つかるかもしれないと思っていたが、まさか火打ち石が見つかるとは」(エイダ、tick 4)。後では、同じ予期は当たったで確定した
- 「山道に戻れば流木が見つかると思っていたが、実際はまだ移動中で、見つかるかどうかは分からなかった」(ノア、tick 107)。分からないことを外れとして積んでいた
- tick 112 のノアの材料は、目的の文をそのまま写した文だった

## 数え直す手順

判定は `judgments.json` に保存した。件数はここから Jev を呼ばずに数え直せる。

```bash
uv run python scripts/expectation_belief_material_compare.py count --judgments docs/experiments/issue_1443_expectation_material/judgments.json
```

判定を取り直すときだけ Jev を呼ぶ (上の範囲で 58 回)。

```bash
uv run python scripts/expectation_belief_material_compare.py judge --run-dir ../../../var/runs/v4coop_0731_006 --starts 0,40 --turns 8 --out docs/experiments/issue_1443_expectation_material/judgments.json
```

## この比較が言えないこと

- 確からしさがすべて「たぶん」なので、ほぼ確実の外れを強い材料にする分岐は通っていない
- 組み直しの予期は `expected_result` の 1 手 1 件で、#1441 の書かせ方 (1 手に複数件、確からしさ付き) とは違う
- 窓は 8 手で、窓の終わりで暫定のまま残った 11 件は、続きを組み直せば確定しうる
