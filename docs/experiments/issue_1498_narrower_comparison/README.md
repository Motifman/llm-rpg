# 状況の想起で信念を絞る手法を、文字の 2 字組と形態素解析で比べる (#1498)

状況の 6 つの項目をつないだ 1 本の文で信念を引くとき (design_decisions D1414-8)、絞り込みの手法を
次の 3 つで並べた。Jev も LLM も呼んでいない。比べたあと、既定は 2 字組のままにし、形態素解析の 2 手法は
実装も依存も外した (「決めたこと」)。外す前の実装はコミット `ef0c3a06` にある。

| 名前 (`*_NARROWER` に書く値) | 語の作り方 |
|---|---|
| `char_bigram_bm25` (既定。いまのコードに残る唯一の手法) | 区切りの中の文字を 2 つずつ |
| `janome_bm25` (`ef0c3a06` にだけある) | Janome (IPADIC を同梱) で解析し、名詞・自立の動詞と形容詞を原形で残す |
| `sudachi_bm25` (`ef0c3a06` にだけある) | SudachiPy (辞書 sudachidict_core) の短い単位で解析し、名詞・動詞・形容詞・形状詞を正規化形で残す |

形態素解析の 2 つは、どちらも助詞・助動詞・記号・数・接尾辞を外す。語尾を決まりで消す処理は入れていない。

## 素材と母集団

- **40 場面**: `var/runs/v4coop_reasonfirst_003` (4 人)。人ごとに連続 10 回のプロンプトを 1 窓。選び方は
  `docs/experiments/issue_1414_situation_recall/` と同じで、2 字組の数字は #1497 の `results_plain.json` と一致した。
  場面ごとに上位 3 件を引くので、手法ごとに 40 回の想起、120 枠
- **信念を作る前の判定**: `var/runs` の全 snapshot から、同じ Being の信念のうち文字の上でよく似た 96 組
- **辞書に無い名前**: 作った名前 15 個と、この run の地名 3 個。1 つの名前につき、名前だけの切られ方と、
  3 つの文の中での切られ方、10 件の候補からの順位

組は文字の上の似かた (`difflib` の ratio 0.6 以上) で選んでいるので、2 字組に有利な母集団になっている。

### 辞書に無い名前 (`unknown_names.json`)

18 個のうち、3 つの手法とも名前で 1 位に引けたのは 16 個。崩れたのは次の 2 つ。

| 名前 | 2 字組 | Janome | Sudachi |
|---|---|---|---|
| ことは (ひらがなの人名) | 2 位。紛らわしい信念「怖いことはない」が「ことは」をそのまま含み、上に来た | 引けない。「こと」(名詞の非自立) と「は」(助詞) に切れて何も残らない | 2 位。「こと」だけが残り、紛らわしい信念と同じ語になる |
| 狼煙台 (この run の地名) | 1 位 | 1 位。「狼煙」+ 接尾辞「台」 | 引けない。文によって「狼 / 煙台」と「狼煙 / 台」に切れ方が変わり、問い合わせ文と信念の文で別の語になる |

ほかに分かったこと:

- カタカナの作った名前 (ザルクート、ミルティアなど 5 個) は、どちらの解析器も 1 語のまま残した。Sudachi は「ヴェルナ」を「ベルナ」に
  正規化するが、問い合わせ文と信念の両方が同じに変わるので当たる
- 漢字の作った名前は細かく割れる (Janome「灰 / 瀬」、Sudachi「蒼 / 鉤 / 湾」)。両側で同じに割れれば当たるが、割れた 1 文字は他の文の
  同じ字とも当たる
- Sudachi は「白骨谷」を「白骨」、「鳴砂の洞」を「鳴 / 洞」まで落とす (「谷」「砂」を名詞として返さない)。名前の一部が語から消える
- Sudachi は「みのり」を、名前だけのときは「みのり」、文の中では「実り」と切る。この確かめでは問い合わせ文と信念の文が両方「実り」に
  そろって当たったが、名前だけを書いた短い文とは別の語になりうる
- 2 字組は、名前と同じ文字の並びを含むだけの文 (「ことは」と「怖いことはない」) を見分けられない

## 分かったこと

1. **形態素解析に替えても、体が危ない場面で体に関わる信念は戻らない**。96 枠中、2 字組 16、Janome 14、Sudachi 12 で、むしろ減った。
   32 場面のうち 28 場面の問い合わせ文に「空腹」が入り、候補にも「空腹が危険域に達したら即座に食料を口にするべきだ」のような
   信念がある (下の実例)。それでも、人の名前や「川沿い」「ルート」「手記」を多く共有する信念が上に来る。体の信念が負けるのは、
   語の切り方ではなく、問い合わせ文が長く (この 32 場面の平均で 440 字)、体の語がその中の数語にすぎないことによる
2. **同じ 3 件が続けて並ぶ割合は、どの手法でも低いまま** (2〜3/36)。Sudachi は続けての想起の重なり具合が 0.41 と少し高い
3. **2 つの解析器どうしは似た 3 件を選ぶが、2 字組とは半分ほど違う** (1 場面あたり 3 件中 1.5 件が重なる)。手法の差は、語の作り方より
   どの語に点が付くかで出ている
4. **場所の名前は語に分けたほうが当たり、人の名前は 2 字組のほうが当たる**。この run の人の名前 (エイダ、カイ、ノア、リオ) と
   場所の名前 6 つは、どちらの解析器でも、名前だけのときと「(名前)は昨日ここに来た」の文の中とで同じ語に切れた。差は切り方の失敗ではなく、
   他の語との点の取り合いで出ている。場所の名前で語に分けたほうが当たる理由は、この集計では分けられていない
5. **辞書に無い名前は、どちらの解析器でも大半は扱える**が、ひらがなの名前と、文によって切れ方が変わる漢字の名前で、名前がまったく
   当たらない場合がある。2 字組には「まったく当たらない」場合は無く、紛らわしい文と見分けられない場合だけがある

## 実例: 体の信念が候補にあるのに載らない (リオ、プロンプト 102、観測拠点跡)

やろうとしていること: 「空腹は29まで戻したが、カイは92で限界だ。まずは全員で食料を確保してから、風向きと山頂ルートを決める。」
いま起きたこと: カイが「空腹93」と言い、全員で隠し入江に戻って貝を焼くと話した。ノアも「腹を満たしてから川沿いルートで山頂を目指す」と言った。

候補にある体に関わる信念: 「空腹が危険域に達したら即座に食料を口にするべきだ」「リオは干潟で貝を採れると言っている」など 5 件。

| 2 字組 | Janome | Sudachi |
|---|---|---|
| カイは火起こし道具一式を持っている | カイは火起こし道具一式を持っている | リオは干潟で貝を採れると言っている |
| ノアは川沿いルートを推した | リオは干潟で貝を採れると言っている | ノアは川沿いルートを推した |
| カイが手記から川沿いルート安全と読んだ | ノアは川沿いルートを推した | 隠し入江への移動は仲間の合意を得て進める |

どの手法でも、「空腹が危険域に達したら…」は 3 件に入らない。人の名前と「川沿い」「ルート」を共有する信念が上に来る。

## 決めたこと

ユーザーと次のように決めた (design_decisions D1498)。

- **既定は 2 字組のままにし、形態素解析の 2 手法は実装も依存も外す**。比べた記録 (この README、`results.json`、
  `unknown_names.json`) は残す。実装はコミット `ef0c3a06` にあり、下の「再現」の手順で動かせる
- **体に関わる信念が減った件は、いまは手を打たない**。理由は次の 2 つ
  - 前の想起の 26 件が、その場面に合った信念だったかは読んでいない。減ったことが悪くなったことかは、まだ分からない
  - 語に分けても戻らなかったので、効きそうなのは長い問い合わせ文に強い手法になる。埋め込みを、#1454 (エピソードの側の引き方) の
    比較に入れて試す。信念の検索も同じ `ITextCandidateNarrower` の差し替えで試せる

選んだ理由:

- 体に関わる信念 (この Issue の動機) は、形態素解析では戻らなかった。残る差は問い合わせ文の組み方の問題で、語の切り方を替えても解けない
- 同じ 3 件の繰り返しは 2 字組が同じか少なく、信念を作る前の判定の相方と人の名前の当たりは 2 字組が同じか多かった
- 形態素解析が上回ったのは場所の名前 (42 組中 25 → 32 / 36) だけ
- 辞書に無い名前で「まったく当たらない」場合が、2 字組には無く、解析器にはある。環境を取り換える前提 (#1436) では、この失敗のほうが重い
- 依存が増える。Janome は wheel で 19.7 MB、初期化に 1.8 秒。Sudachi は辞書 sudachidict_core が 72 MB

## 再現

形態素解析の手法は、いまのコードには無い。実装を外す前のコミット `ef0c3a06` を別の worktree に取り出して回す。
`var/runs` はリポジトリの外 (worktree から見て `../../../var/runs`) を指す前提で、パスは手元に合わせる。

```bash
git worktree add /tmp/llm-rpg-1498 ef0c3a06
cd /tmp/llm-rpg-1498
uv sync --locked --extra dev
uv run python scripts/situation_recall_probe.py \
    --run-dir <var/runs への絶対パス>/v4coop_reasonfirst_003 \
    --narrowers char_bigram_bm25,janome_bm25,sudachi_bm25 \
    --out docs/experiments/issue_1498_narrower_comparison/results.json
uv run python scripts/narrower_unknown_name_probe.py \
    --out docs/experiments/issue_1498_narrower_comparison/unknown_names.json
# --narrower を char_bigram_bm25 / janome_bm25 / sudachi_bm25 に替えて 3 回回す
uv run python scripts/jev_belief_create_gate_measure.py --runs-dir <var/runs への絶対パス> --port stub \
    --narrower janome_bm25 --jev-limit 0
```

2 字組だけの数字は、いまのコードの `scripts/situation_recall_probe.py` (`--narrowers` の既定) でも同じに出る。

## 近似と限界

- 場面の時点の信念、行動結果の時刻などの近似は Issue #1414 のスクリプトと同じ (スクリプトの冒頭)
- 体に関わる信念は正規表現で数えた。載った信念がその場面に合っていたかは読んでいない。前の想起の 26 件も同じで、件数の差が良し悪しの差とは限らない
- 正規表現では「リオは怪我をしていても率先して動けるリーダー格だ」も体に関わる信念に入る
- 品詞の残し方は 1 通りしか試していない。動詞を外す、名詞だけにする、といった変え方で数字は動きうる
- 素材は 1 本の run の 4 人だけ。名前の多くはカタカナの短い人名と、普通の語でできた地名で、辞書に無い名前の確かめは 18 個 (作った名前 15 個、この run の地名 3 個) にとどまる
